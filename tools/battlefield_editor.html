사용법 · 게임에 적용하는 방법

① 배경 48종 중 하나를 고릅니다. ② 내 포켓몬/상대를 선택한 뒤 발판 중심을 누르거나 포켓몬을 끌어서 옮깁니다. 숫자는 배경 셀 내부 좌표입니다. 방향키는 1px, Shift+방향키는 5px씩 움직입니다.

③ 게임 구도 미리보기로 전환해 실제 게임의 배경 카메라·포켓몬 배율·발 위치를 비교합니다. 이 모드는 편집하지 않습니다. 아군 발 높이를 약 565px로 맞추기 때문에 배경도 이동합니다. 편집 모드로 돌아가면 배경 전체가 다시 보입니다.

④ 수정 좌표 JSON 저장을 눌러 battlefield_layouts.json을 보관하세요. 다른 배경으로 바꿔도 이 파일에 48개 배경의 수정 내용이 모두 들어갑니다. JSON을 불러오면 이어서 수정할 수 있습니다.

⑤ 내려받은 JSON을 보내주시면 게임에 적용하겠습니다. 직접 적용하려면 게임을 종료하고 프로젝트의 data/battlefield_layouts.json을 이 파일로 교체한 뒤 다시 실행하세요. 배경 PNG나 스프라이트를 바꿀 필요는 없습니다.

포켓몬 종류 선택은 크기 확인용이며 게임 파티를 바꾸지 않습니다. UI 영역은 겹침 확인용 간단한 가이드입니다. 실제 카드·HP UI 전체를 실행하는 게임 화면은 아닙니다. 배경·386종 앞뒤 스프라이트가 파일 안에 들어 있고 외부 요청을 하지 않습니다.

브라우저가 허용하면 임시 자동 저장을 사용합니다. 모바일 파일 미리보기 앱에서는 실행되지 않을 수 있으니 HTML 파일을 내려받아 JavaScript를 지원하는 브라우저로 여세요. 중요한 수정은 JSON으로 보관하세요. 사천왕은 같은 타입의 방을 공유하므로 한 방을 수정하면 해당 타입 후보 모두에 적용됩니다.
