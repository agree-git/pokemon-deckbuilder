# 전투 날씨

비·눈·쾌청·모래바람을 **양쪽에 적용되는 하나의 전장 상태**로 사용한다. 날씨마다 공용 트레이너 카드 1종이 있으며 보상과 상점에서 얻는다. 기본 비용 1, 강화 비용 0이다. 초기 덱에 자동으로 추가하지 않는다.

| 날씨 | 실제 효과 |
|---|---|
| 비 | 물 공격 피해 ×1.5, 불꽃 공격 피해 ×0.5 |
| 눈 | 얼음 타입의 물리 방어 ×1.5. 지속 피해 없음 |
| 쾌청 | 불꽃 공격 피해 ×1.5, 물 공격 피해 ×0.5 |
| 모래바람 | 바위 타입의 특방 ×1.5. 턴 종료 시 양쪽 출전 포켓몬에게 최대 HP의 1/16 피해. 바위·땅·강철은 피해 면역 |

모든 날씨는 **5턴**이다. 사용한 턴도 포함해 상대 행동과 상태 처리가 끝날 때 한 번씩 줄어든다. 다른 날씨를 사용하면 교체하고 같은 날씨를 다시 사용하면 5턴으로 갱신한다. 수동·기술 자동·기절 강제 교대와 상대 포켓몬 교대는 날씨를 해제하거나 남은 턴을 추가 소비하지 않는다. 전투가 끝나면 해제하고 다음 전투는 맑은 기본 상태로 시작한다.

원작 기술 **비바라기 #240·쾌청 #241·모래바람 #201·싸라기눈 #258**에도 같은 효과를 연결했다. 싸라기눈은 이번 요청의 **눈 규칙**으로 통일하며 얼음 피해를 주지 않는다. 날씨 기술 역시 소유자의 기술 카드이므로 다른 동료의 카드를 쓰면 그 동료로 자동 교대한다. 특성·날씨별 기술 위력/명중/회복의 예외 규칙은 아직 추가하지 않았다. 바이옴의 자동 초기 날씨·적의 날씨 변경 행동도 이번 범위에는 없다.

## 계산·연출

- 물리/특수 방어 보정은 종족값·레벨·능력 단계로 얻은 방어값에 적용한 후 내림한다. 비·쾌청은 직접 공격 피해의 마지막 배율에 적용한다. 상성 무효는 0을 유지한다.
- 보호막 전환처럼 고정된 보호막 수치를 피해로 바꾸는 카드는 비·쾌청 배율을 받지 않는다. 화상·독·씨앗도 날씨 피해 배율과 별개다.
- 모래바람 피해는 최대 HP의 1/16을 내림하고 최소 1이다. 보호막을 관통하고 대기 멤버에게는 적용하지 않는다. 화상·독·씨앗 전용 유물을 발동시키지 않는다.
- 모래바람의 양쪽 피해를 모두 처리한 뒤 승패/교대를 판정한다. 새로 출전한 상대는 같은 턴의 모래바람을 다시 맞지 않는다. 마지막 양쪽 멤버가 동시에 쓰러지면 기존 규칙인 아군 전멸 우선 판정을 따른다.
- 상단 날씨 아이콘·이름·남은 턴, 전체 설명 툴팁, 손패 피해 수치와 적 공격 예고, 카드 사용 전 날씨 예고를 연결했다. 적용→각 피해→남은 턴/종료를 순서대로 표시한다.
- 별도 전장 레이어에서 배경과 포켓몬 위에 날씨를 합성하고 기술 VFX·HUD는 위쪽에 둔다. 상단 바와 손패 영역은 제외하며 하단에서는 입자·색조를 서서히 옅게 한다. 1920×1080 UI를 유지하고 날씨 도형만 3px 격자에 맞춘다.
- **비:** 선명한 앞/뒤 빗줄기·바닥 물결·푸른 흐린 조명. **눈:** 크기·속도가 다른 눈송이·차가운 옅은 안개. **쾌청:** 왼쪽 위 광원의 층진 후광·그곳에서 펼쳐지는 빛줄기·대각선으로 이어지는 렌즈 플레어. **모래바람:** 황갈색 조명·가로 먼지층·빠르게 흐르는 모래 알갱이.
- 날씨 변경/종료는 약 **0.55초** 동안 자연스럽게 전환한다. 같은 날씨로 HUD를 갱신해도 전환을 다시 시작하지 않는다. 고정 산술식만 사용하며 시각 연출은 전투 자원·게임 난수·저장·사용자 보정 배경 좌표를 바꾸지 않는다. 네 날씨 SVG 아이콘은 프로젝트에서 직접 제작했고 기존 승인 타입 아이콘은 유지한다.

기존 v3 저장의 `powers`에 날씨 ID와 남은 턴을 저장한다. 최대 한 종류·1~5턴만 허용하고 예전 날씨 없는 저장도 그대로 읽는다. 카드 사용 미리보기와 단계별 재생은 날씨 사본을 사용한다.

[처음 추가한 날씨 카드·전투 화면](https://github.com/agree-git/pokemon-deckbuilder/blob/concept-review-2026-10-17/review/build-concepts/README.md#날씨)에서 확인할 수 있다. Godot 4.7.2/Linux의 규칙·디스크 저장/복원·화면·실제 X11 포인터 검사를 수행했다. 세부 검증은 [진행 현황](progress.md)을 따른다. 기존 적 난도·경험치·보상 경제 조정은 보류한다.

## 전장 연출 보강 검증

[최신 야외·실내 날씨 화면 8장과 ZIP](https://github.com/agree-git/pokemon-deckbuilder/blob/weather-field-review-2026-10-17/review/weather-field/README.md)에서 각 날씨를 비교할 수 있다. 같은 파티로 배경과 날씨만 바꾼 연출 검토 장면이며 정상 챔피언 대진을 보여주는 자료는 아니다.

Godot 4.7.2/Linux: 실제 렌더러 97개(화면 픽셀·움직임·전환/종료·왼쪽 위 광원·UI 보호·두 배경·세 창 비율), 헤드리스 전장 31개, 실제 X11 날씨 카드 33개/12클릭, 기존 날씨 규칙/저장/획득 121개와 전투 연출 28개를 확인했다. 검사 도중 배경 좌표·전투 스냅샷·시드 난수가 유지되는지도 비교했다. 기존 연출 테스트는 마지막 장면과 오디오를 종료한 뒤 믹서 정리를 기다리도록 정리했다. Windows 실행은 별도다.

```bash
godot --headless --path . --script res://tests/test_weather_field.gd
# 실제 디스플레이의 1920×1080 렌더링 및 픽셀 검사
godot --path . --rendering-method gl_compatibility --audio-driver Dummy --script res://tests/test_weather_field.gd
python3 tools/test_native_pointer.py --probe native_weather_probe
```
