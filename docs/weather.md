# 전투 날씨

비·눈·쾌청·모래바람을 **양쪽에 적용되는 하나의 전장 상태**로 사용한다. 날씨마다 공용 트레이너 카드 1종이 있으며 보상과 상점에서 얻는다. 기본 비용 1, 강화 비용 0이다. 초기 덱에 자동으로 추가하지 않는다.

| 날씨 | 실제 효과 |
|---|---|
| 비 | 물 공격 피해 ×1.5, 불꽃 공격 피해 ×0.5 |
| 눈 | 얼음 타입의 물리 방어 ×1.5. 지속 피해 없음 |
| 쾌청 | 불꽃 공격 피해 ×1.5, 물 공격 피해 ×0.5 |
| 모래바람 | 바위 타입의 특방 ×1.5. 턴 종료 시 양쪽 출전 포켓몬에게 최대 HP의 1/16 피해. 바위·땅·강철은 피해 면역 |

모든 날씨는 **5턴**이다. 사용한 턴도 포함해 상대 행동과 상태 처리가 끝날 때 한 번씩 줄어든다. 다른 날씨를 사용하면 교체하고 같은 날씨를 다시 사용하면 5턴으로 갱신한다. 수동·기술 자동·기절 강제 교대와 상대 포켓몬 교대는 날씨를 해제하거나 남은 턴을 추가 소비하지 않는다. 전투가 끝나면 해제하고 다음 전투는 맑은 기본 상태로 시작한다.

원작 기술 **비바라기 #240·쾌청 #241·모래바람 #201·싸라기눈 #258**에도 같은 효과를 연결했다. 싸라기눈은 이번 요청의 **눈 규칙**으로 통일하며 얼음 피해를 주지 않는다. 날씨 기술 역시 소유자의 기술 카드이므로 다른 동료의 카드를 쓰면 그 동료로 자동 교대한다. 특성·날씨별 기술 위력/명중/회복의 예외 규칙은 아직 추가하지 않았다. 바이옴의 자동 초기 날씨·적의 날씨 변경 행동도 이번 범위에는 없다.

## 계산·연출

- 물리/특수 방어 보정은 종족값·레벨·능력 단계로 얻은 방어값에 적용한 후 내림한다. 비·쾌청은 직접 공격 피해의 마지막 배율에 적용한다. 상성 무효는 0을 유지한다.
- 보호막 전환처럼 고정된 보호막 수치를 피해로 바꾸는 카드는 비·쾌청 배율을 받지 않는다. 화상·독·씨앗도 날씨 피해 배율과 별개다.
- 모래바람 피해는 최대 HP의 1/16을 내림하고 최소 1이다. 보호막을 관통하고 대기 멤버에게는 적용하지 않는다. 화상·독·씨앗 전용 유물을 발동시키지 않는다.
- 모래바람의 양쪽 피해를 모두 처리한 뒤 승패/교대를 판정한다. 새로 출전한 상대는 같은 턴의 모래바람을 다시 맞지 않는다. 마지막 양쪽 멤버가 동시에 쓰러지면 기존 규칙인 아군 전멸 우선 판정을 따른다.
- 상단 날씨 아이콘·이름·남은 턴, 전체 설명 툴팁, 손패 피해 수치와 적 공격 예고, 카드 사용 전 날씨 예고를 연결했다. 적용→각 피해→남은 턴/종료를 순서대로 표시한다.
- 비·눈·모래 입자와 날씨별 색조는 고정 산술식으로 그린다. 시각 연출은 게임 난수와 사용자 보정 배경 좌표를 바꾸지 않는다. 네 날씨 SVG 아이콘은 프로젝트에서 직접 제작했다. 기존 승인 타입 아이콘은 유지한다.

기존 v3 저장의 `powers`에 날씨 ID와 남은 턴을 저장한다. 최대 한 종류·1~5턴만 허용하고 예전 날씨 없는 저장도 그대로 읽는다. 카드 사용 미리보기와 단계별 재생은 날씨 사본을 사용한다.
