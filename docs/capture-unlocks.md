# 전설·환상 포획과 스타팅 해금

## 사용자 요구사항

- 전설·환상 포켓몬은 쉽게 획득할 수 없게 한다.
- 한 번 포획에 성공하면 **그 진화 계열의 가장 미진화한 포켓몬**을 다음 원정의 스타팅으로 영구 해금한다. 진화체 그대로는 스타팅에 추가하지 않는다.
- 포켓몬 범위는 1~3세대 원종 386종이다. 현재 전설·환상 21종은 일반 출현 풀과 관장 파티에서 제외했다.

아래는 이 요구사항을 구현하기 위한 설계 제안이다. 현재 카탈로그에는 전설·환상 구분과 이벤트 후보, `VisualCatalog.starter_species_id()`의 미진화 해금 대상 계산이 있다. 전용 이벤트·영구 저장·스타팅 선택 화면은 아직 구현하지 않았다.

## 희귀 포획 제안

낮은 확률로 반복 출현시키기보다 **발견 조건 → 전용 보스전 → 제한된 포획 기회**로 획득 과정에 목표를 부여한다.

1. 타입 배지, 특정 경로의 단서, 소모 도구 등 조건을 만족해야 전용 이벤트가 열린다. 정확한 조건과 희귀도는 종별 콘텐츠 단계에서 정한다.
2. 원정당 전설·환상 이벤트에 한 번 도전한다. 환상은 추가 단서나 더 엄격한 조건을 요구하는 후보로 둔다.
3. 일반 적보다 강한 전투에서 체력 감소·브레이크 같은 포획 조건을 달성한 뒤 전용 포획 도구로 시도한다. 조건과 남은 기회는 UI에서 보여준다. 단순 초저확률 반복 파밍을 핵심으로 삼지 않는다.
4. 이벤트·포획 결과는 원정 시드와 도전 기록으로 고정하며 화면 재진입·재시작으로 기회를 재추첨하지 않도록 저장한다. 영구 도감과 진행 저장을 함께 구현할 때 검증한다.

## 포획 도감과 스타팅 제안

- 실제 포획 성공 시 잡은 종의 ID를 도감에 저장하고, 스타팅 해금 ID는 진화 전 종을 끝까지 따라가 가장 미진화한 종으로 변환한다. 같은 진화 계열을 여러 번 포획해도 스타팅 항목은 하나다.
- 예: 리자몽 → 파이리, 보만다 → 아공이, 샤미드/블래키 → 이브이, 라이츄 → 피츄. 아기 포켓몬도 현재 1~3세대 범위에 있으면 미진화 스타팅으로 취급한다.
- 4세대 이후의 진화 전 종은 현재 범위에 넣지 않는다. 예를 들어 로젤리아의 스타팅은 로젤리아, 잠만보의 스타팅은 잠만보다. 원정 중 잡은 진화체의 모습은 유지하며 다음 원정 스타팅만 변환한다.
- 파티가 가득 차서 포획한 포켓몬을 풀어주거나 이후 원정에 실패해도 이미 달성한 해금은 유지한다.
- 전투 승리·스프라이트 프리뷰·관장 격파만으로는 해금하지 않는다. 진화만으로 얻은 종의 해금 여부는 별도 규칙으로 결정한다.
- 다음 원정의 스타팅 화면에서 해금된 미진화 종을 보여준다. 새 계정의 기본 스타팅 세 종은 처음부터 선택 가능하게 하는 방식을 기본안으로 둔다.
- 전설·환상도 포획했다면 선택할 수 있되, 높은 편성 비용과 총비용 제한으로 반복 플레이의 균형을 잡는 방식을 추천한다. 구체적인 비용·초기 파티 인원수는 스타팅 화면과 함께 조정한다.
- 디스크에는 버전과 포획 ID 목록을 저장하고 손상·중복·범위 밖 ID를 검증한다. 원정 재시작은 도감을 초기화하지 않는다.

새 전술 전투에 포획을 연결한 뒤 도감 저장과 스타팅 선택을 한 흐름으로 구현한다. 386종 모두의 플레이어용 기술·특성·성장 수치가 아직 완성된 것은 아니므로, 카탈로그 등록과 스타팅 플레이 지원 범위를 구분한다.
