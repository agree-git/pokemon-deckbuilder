# 희귀 조우·포획과 스타팅 해금

1~3세대 원종 386종을 사용한다. 전설·환상 21종은 일반 야생 출현과 관장 파티에서 제외하며, 정식 원정의 **단서 조사 → 조건 달성 → 선택한 야생 전투 1회 → 제한된 포획**으로 얻는다. 브레이크나 초저확률 포획 반복은 사용하지 않는다.

## 세 등급

| 등급 | 배지 / 단서 | 포획 HP | 몬스터볼 | 에너지 | 기존 야생 대비 레벨 |
|---|---|---|---|---|---|
| 준전설 | 각각 3개 | 15% 이하 | 3개 | 2 | +5 |
| 환상 | 각각 5개 | 15% 이하 | 3개 | 2 | +5 |
| 초전설 | 각각 7개 | 10% 이하 | 5개 | 3 | +8 |

레벨 상한은 100이다. 초전설은 환상보다 늦게 도전하며 조사·전투·포획 자원 조건도 더 엄격하다. 준전설·초전설은 이번 게임의 편성 분류로 다음 종을 사용한다.

- **준전설 11종:** 프리져·썬더·파이어, 라이코·앤테이·스이쿤, 레지락·레지아이스·레지스틸, 라티아스·라티오스.
- **환상 4종:** 뮤·세레비·지라치·테오키스.
- **초전설 6종:** 뮤츠·루기아·칠색조·가이오가·그란돈·레쿠쟈.

## 플레이 흐름

1. 야영지의 **휴식·강화 → 희귀 조우**에서 이번 원정의 대상과 조건을 확인한다. 대상 한 종은 원정 시드로 고정되며 팝업·재방문·이어하기로 바뀌지 않는다.
2. **단서 조사**를 선택하면 단서 하나를 얻고 해당 야영지의 주 행동을 소비한다. 그 야영지에서는 휴식이나 카드 강화를 할 수 없다. 가방·상인·만남·장비는 별도로 이용한다. 필요한 개수까지만 조사할 수 있다.
3. 단서·배지·포획용 볼을 준비한 뒤 **다음 장소가 야생 전투인 야영지**에서 도전한다. 다음 야생 한 번을 해당 대상과의 전투로 바꾸고 강화를 사용하는 적 전술을 적용한다. 트레이너·관장·리그 전투는 바꾸지 않는다. 예약 후 출발 버튼을 눌러 이동한다.
4. 상대를 쓰러뜨리지 않고 등급별 HP 조건까지 낮춘 뒤 C 또는 포획 버튼을 사용한다. 조건이 맞으면 **확정 포획**하고 해당 볼과 에너지를 한 번만 소비한다. 남은 HP·에너지·볼이 모자라면 자원과 상태를 바꾸지 않고 이유를 표시한다. 포획 버튼의 `보유/필요 볼`과 툴팁에서 비용을 확인한다.
5. 세 등급은 **원정당 한 번의 도전**을 공유한다. 포획하거나 쓰러뜨리거나 전멸하면 이번 원정에서 다시 도전하지 못한다. 쓰러뜨렸을 때는 보통 전투 보상을 받고 포획 도감은 해금하지 않는다. 예약 시부터 도전 기록을 저장한다.

전체 경로는 그대로 **69전투·68야영지**다. 해당 야생의 경험치·골드·일반 선택 보상과 뒤의 캠프를 유지한다. 따라서 기존 챔피언 직전 Lv.100 목표나 체육관/사천왕 편성을 변경하지 않는다. 초전설은 7번째 배지 이후 남은 야생에서 도전해야 하므로 리그로 떠나기 전에 조건을 준비한다. 대상별 전용 대사·별도 유적 그래픽·특성·전용 보상은 후속 콘텐츠다.

## 영구 해금

성공하면 잡은 종 ID를 별도의 포획 도감에 저장하고 **해당 계열의 가장 미진화한 종**을 다음 원정의 스타팅으로 영구 해금한다. 진화체를 포획해도 다음 스타팅은 미진화체다. 예: 리자몽 → 파이리, 보만다 → 아공이, 샤미드/블래키 → 이브이, 라이츄 → 피츄. 아기 포켓몬도 1~3세대 범위에 있으면 포함하며 이후 세대의 진화 전 종은 넣지 않는다.

준전설·환상·초전설도 실제 포획하면 스타팅 선택에 추가되며 **Lv.5**로 시작한다. 원정 파티가 가득 차서 포획한 종을 풀어주거나 이후 전멸해도 해금은 유지한다. 최대 3마리 선택 규칙과 기본 스타팅 세 종은 그대로다. 영구 도감과 원정 저장은 별개이며 전투 승리·진화·미리보기만으로 포획 해금을 주지 않는다.

예전에 제안했던 스타팅 비용/예산 제한은 구현하지 않았다. 희귀 스타팅의 반복 플레이 균형은 수동 플레이로 검토할 항목이다.

## 저장과 검증

선택 필드 `rare_hunt`는 시드와 일치하는 대상·조사한 야영지 목록·예약한 전투 위치·포획 성공 여부를 저장한다. 별도 난수기로 생성하므로 경로·손패·보상 난수는 바뀌지 않는다. 기존 v3는 대상 미조회 상태로 그대로 이어하며 화면을 읽는 것만으로 저장 필드를 추가하지 않는다. 기본 경로와 방문한 상점도 보존한다.

포획은 성공 행동에서 원정 ID 목록과 영구 도감에 기록하므로 정산·파티 교체 전 종료해도 이어간다. 잘못된 종·중복/미소비 야영지 단서·조건 미달 전투 예약·포획 기록 불일치를 검증한다.

검증 명령(Godot 4.7.2):

```bash
godot --headless --path . --script res://tests/test_rare_encounter.gd
godot --headless --path . --script res://tests/test_rare_encounter_ui.gd
godot --headless --path . --script res://tests/test_rare_campaign.gd
python3 tools/test_rare_process.py
# DISPLAY와 XTest 사용 가능 시 실제 포인터/키 입력
python3 tools/test_native_pointer.py --probe native_rare_encounter_probe
```

규칙 검사는 21종의 등급·예약·비용·포획·풀어주기·재실행·실패 조건을 다룬다. UI/프로세스 검사의 HP 경계는 명시적 테스트 상태이며 희귀전 전체를 수동으로 공략했다는 뜻은 아니다. 별도로 준전설 프리져(시드 24)·환상 뮤(16)·초전설 뮤츠(14)를 처음부터 진행하며 조사·상점 구매·실제 카드로 HP를 낮춘 포획을 달성하고 각각 69전투와 엔딩까지 확인한다. 이 자동 플레이는 HP·경험치·볼·에너지를 직접 바꾸지 않는다. 기존 저장의 회귀 검증도 별도로 수행한다.
