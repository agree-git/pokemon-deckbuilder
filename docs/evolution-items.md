# 돌·통신 진화와 야영지 재료

1~3세대 원종의 **돌 진화 21개·통신 진화 12개**, 총 33개 경로를 지원한다. 조건 없는 레벨 진화 135개는 기존처럼 경험치 정산 중 자동 처리한다. 이번 재료 진화는 야영지에서 직접 선택하며 레벨을 무료로 올리지 않는다.

## 획득과 사용

새로 방문한 상인은 기존 보급품 세 종류 옆에 진화 재료 한 종류를 한 개 판매한다. 현재 파티와 조건 없는 다음 레벨 진화에서 사용할 재료를 우선 후보로 삼는다. 예를 들어 피카츄는 천둥의돌, 캐이시는 윤겔라가 사용할 연결의끈을 받을 수 있다. 후보가 없으면 전체 재료에서 하나를 고른다. 시드·장소로 독립 추첨하고 전투·보상 난수와 경로를 바꾸지 않는다. 판매 후 재입고하지 않으며 재진입·저장 복원·파티 변경으로 재추첨하지 않는다.

`야영지 → 가방 → 재료 → 대상 동료` 순서로 사용한다. 재료는 그림·이름·개수로 표시하고 보유한 진화 재료만 가방에 나타난다. 가방이 길면 세 열 목록을 스크롤한다. 대상 팝업에 현재·진화 후 스프라이트와 이름을 보여준다. 진화할 수 없는 종과 기절한 동료는 이유를 표시하고 선택을 막는다. 결과 팝업은 새 모습을 짧게 확대하며 확인할 때까지 뒤의 행동을 막는다. Esc로 선택 취소·결과 닫기가 가능하다.

진화는 UID·레벨·경험치·배운 기술·카드 사본과 강화·장비를 보존하고 이름·타입·스프라이트·종족값을 바꾼다. 기존 성장과 같이 잃은 HP의 절대량을 보존하되 살아 있는 멤버는 최소 HP 1이다. 무료 회복으로 집계하지 않는다. 재료 한 개만 소비하고 휴식/강화 행동은 그대로 남긴다. 성공한 사용과 진화 선택은 원정 기록에 남는다. 진화는 포획이 아니므로 새로운 스타팅을 해금하지 않는다.

현재 기술을 새 종의 초기 기술로 자동 교체하거나 과거 레벨의 기술을 소급 지급하지 않는다. 이후 레벨업부터 진화형의 에메랄드 기술표를 따른다. 대상 버튼 툴팁에서 진화 후 배울 기술을 확인한다. 라이츄처럼 이후 레벨업 기술이 없는 경우 필요한 기술을 먼저 배운 뒤 진화할 수 있도록 안내한다. 기술 되살리기·기술머신은 아직 없다.

## 저장과 남은 조건

기존 v3 저장을 유지한다. 재료 개수는 가방, 판매 재료는 야영지의 선택 필드 `evolution_offer`, 남은 재고는 기존 `stock`에 저장한다. 성공 후 한 번 알리고 자동 저장한다. 이전에 방문했던 상인은 기존 진열 그대로이며 이후 처음 방문하는 상인부터 재료를 판매한다. 결과 연출 중 종료해도 종과 소비한 재료는 복원하고 연출을 다시 정산하지 않는다.

이 문서의 범위는 돌·통신이다. [친밀도·시간대 진화](friendship.md)는 누적 친밀도와 실제 레벨업으로 별도 지원하며 이브이의 에브이/블래키도 포함한다. [능력치 비교·개체 분기·빈 슬롯 추가 합류·아름다움](special-evolution.md)도 각 조건으로 지원한다. 파랑포켓블록은 아름다움을 올리는 별도 간식이며 즉시 진화 재료로 처리하지 않는다. 4세대 이후 종과 지역폼도 추가하지 않는다.

## 검증

```bash
godot --headless --path . --script res://tests/test_evolution_items.gd
godot --headless --path . --script res://tests/test_evolution_items_ui.gd
python3 tools/test_evolution_process.py
# X11 세션 활성화 후
LIBGL_ALWAYS_SOFTWARE=1 python3 tools/test_native_pointer.py --probe native_evolution_items_probe
```

규칙 검사는 고정 원본 CSV와 33개 기본형 경로·재료의 일치, 각 진화의 데이터·HP·카드 소유권 보존과 저장, 잘못된 대상·잔량·장소·중복 사용의 무변경, 상인의 독립 난수·매진·이전 저장 호환을 확인한다. 실제 X11 검사는 세 창 비율의 스크롤·취소·대상 선택, 통신/분기 진화·모달·자동 저장을 확인한다. 별도 Godot 프로세스 세 개로 구매 후 종료 → 이어하기와 진화 → 다시 종료 후 다음 전투를 검증한다.
