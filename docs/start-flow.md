# 시작 화면과 스타팅 선택

F5 실행은 `scenes/main_menu.tscn`의 시작 화면이다. 일반 플레이는 **새 원정 → 스타팅 선택 → 원정 시작**으로 이어진다. 기존 9개 장소 원정과 단일 전투 시험은 비교·회귀 검증용 씬으로만 보관하고 일반 원정의 메뉴와 F2/F3/F4 전환에서 제거했다. 개발용 아트 랩도 에디터에서 직접 실행한다.

## 스타팅과 이어하기

- 처음에는 이상해씨·파이리·꼬부기가 해금되어 있다. 스타팅은 **1~3마리**, 같은 종을 중복 선택할 수 없다.
- 선택 순서가 파티 순서이며 첫 번째 포켓몬이 먼저 출전한다. 선택을 다시 누르면 해제한다. 한 마리도 선택하지 않으면 출발할 수 없다.
- 이름·도감 번호 검색과 미해금 포함 필터를 제공한다. 스타팅 목록에는 진화 계열별 가장 미진화한 종만 표시한다.
- 원정 시드로 정해진 첫 바이옴에서 야생 포켓몬 한 마리를 상대한다. 이후 8개 지역과 리그를 진행하며 파티 최대 인원은 세 마리다.
- 원정 메뉴 또는 전투 밖의 홈 버튼으로 시작 화면에 돌아간다. 게임을 종료한 뒤 다시 실행해도 `이어하기`로 현재 전투·지도·보상·휴식·기술 교체·포획 합류 결정을 이어간다.
- 새 원정 편성을 취소하고 돌아와도 진행 중인 원정을 유지한다. 새 편성을 확정하면 새 원정으로 교체한다.

## 포획과 영구 도감

각 바이옴의 야생 전투에서 포획할 수 있다. 시작 몬스터볼은 두 개이며, **적 체력 25% 이하·에너지 1·몬스터볼 1개**가 필요하다. 조건을 만족하면 확정 포획하고 남은 야생 적이 있다면 같은 턴과 자원을 유지하며 전투를 계속한다. 포획은 에너지나 카드를 환급하지 않는다. 트레이너·관장·사천왕·챔피언 포켓몬은 포획할 수 없다. 야영지에서 몬스터볼을 보충한다.

성공 즉시 실제 잡은 종을 영구 도감에 기록하고 미진화 스타팅을 해금한다. 전투를 마친 뒤 합류 또는 풀어주기를 고른다. 파티가 가득 찼으면 기존 멤버 한 마리와 교체할 수 있다. 합류한 포켓몬은 만났을 때의 레벨·최대 체력·해당 레벨의 원작 기술로 시작하며, 교체해 내보낸 멤버의 기술·부상은 제거하고 지닌 물건은 가방에 돌려준다. 합류한 멤버의 기술 카드를 추가하며 공용 카드·유물은 유지한다. 원정 실패·방출·원정 재시작은 도감을 초기화하지 않는다.

`PlayerProfile`이 `user://collection.json`에 버전과 포획 ID 목록만 저장한다. 해금 스타팅은 이 기록에서 계산하므로 진화체를 잡아도 기본형 하나만 추가된다. 임시 파일에 쓴 뒤 교체하고 유효한 이전 파일은 `.bak`에 보관한다. 로드 시 버전·범위·중복을 검사하며 기본 파일 손상 시 백업을 읽는다.

**포획 도감과 현재 원정을 각각 자동 저장한다.** HP·경험치·덱·지도·전투 자원·야영지 진행도 게임 종료 후 유지한다. 새 원정을 확정하거나 재시작하면 원정 슬롯만 초기화하며 영구 도감은 유지한다. 손상 복구와 호환 규칙은 [저장 문서](persistence.md)를 참고한다.

## 현재 전투 콘텐츠

386종에 원작 성장 그룹과 에메랄드 레벨별 기술표를 연결했다. 진화는 레벨 조건에 따라 자동 진행하며 기술이 네 개면 교체하거나 포기한다. 실제 피해·에너지·효과는 전술 전투용 수치로 적용하며 원작 전체 배틀 엔진의 재현은 아니다. [성장과 야영지](growth.md)를 참고한다. [무작위 8개 지역과 리그](full-campaign.md)를 플레이할 수 있다. 특수 진화와 전설·환상 이벤트는 후속 개발이다.

```bash
godot --headless --path . --script res://tests/test_start_flow.gd
godot --headless --path . --script res://tests/test_start_ui.gd
# 실제 OS 마우스로 시작·편성·포획·도감·합류·관장전·새 스타팅까지 검사
LIBGL_ALWAYS_SOFTWARE=1 python3 tools/test_native_pointer.py --probe native_start_probe
```
