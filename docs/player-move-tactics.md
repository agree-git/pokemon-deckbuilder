# 기술 카드 추가 보완 · 원정 v11

현재 새 원정v12는 능력·타입 교환과 공격 복사를 더해 누적371기술이다. [최신 범위/각색/남은 항목](player-move-exchange.md)을 먼저 확인한다. 아래 내용과 목록은 게시 당시 범위다.

원작과 차이가 있어도 특징을 잘 살린다는 사용자 기준으로32개 카드를 추가 보완했다. v10의311개 중 안개제거1개를 확장하고31개 기술을 더해 **누적342기술**이다. [v10 기본 규칙](player-move-cards.md)은 유지한다. 기존v1~v10 저장은 이전 효과를 사용하고 새v11만 플레이어 효과3을 선택한다.

## 실제 효과와 각색

| 분야 | 적용 기술 | 카드 전투 동작 |
|---|---|---|
| 설치 | 스텔스록·압정뿌리기·독압정·끈적끈적네트 | 현재 상대는 그대로 두고 다음 상대의 실제 입장에 적용. 스텔스록은 최대HP⅛×바위 상성, 압정1/2/3겹은 접지 대상HP⅛/⅙/¼, 독압정1/2겹은 독3/5회, 네트는 스피드-1 |
| 설치 예외/제거 | 비행·독·강철 타입 / 안개제거·고속스핀·킬러스핀 | 비행은 접지 설치3종 회피, 중력은 접지. 독 타입 입장은 독압정 흡수, 강철은 독 면역. 안개제거는 양쪽 스텔스록/장막과 새 상대 설치4종 제거. 스핀은 기존 자기 설치/구속 해제, 킬러스핀에 독3회 추가 |

| 반복/금지 | 앙코르·사슬묶기·트집 | 앙코르는 직전 사용 기술만3상대턴 허용, 사슬묶기는 직전 기술4상대턴 봉인, 트집은4상대턴 같은 기술의 연속 성공 금지. 막힌 예고는 실패 후 기존 다음 칸 진행 |

| 전술 밀어내기 | 울부짖기·날려버리기·드래곤테일·배대뒤치기 | 승인 파티 순서/마지막 대표를 유지하면서 상대의 현재 예고를 다음 칸으로 밀어냄. 충전/연속 행동 준비 해제, 상대당 아군턴1회. 한 칸뿐인 전술에는 비용 없이 사용 거절 |
| 교대 보조 | 순간이동·막말내뱉기·썰렁개그 | 이번 턴 다음 수동 교대 비용0. 막말내뱉기는 상대 공격/특공-1과 연계하며 방어에 막히면 교대 혜택도 없음. 썰렁개그는 눈5턴 추가 |

| HP 조정 | 아픔나누기·힘흡수 | 양쪽 현재HP 평균으로 조정(각 최대HP 상한), 또는 상대의 감소 전 실제 공격 능력치만큼 회복 후 공격-1. 자신에게 생기는 HP 증가는 기존 회복 감소 유물 적용 |

설치로 다음 상대가 연속 기절해도 손패·에너지·턴·승인 파티 순서를 유지하고 실제 기절/승패를 처리한다. 전투 시작 전에 설치를 소급하지 않고, 저장을 불러와도 현재 상대에게 입장 피해를 다시 주지 않는다. 상대 교체는 기존 기절/순차 출전 흐름을 따르며 새 자발 교대 AI는 추가하지 않는다.

인계는 카드를 쓴 턴의 다음 교대만 대상으로 하며, 해당 턴을 끝내면 인계 예약은 사라진다. 교대를 강요하는 추가 선택창은 만들지 않는다. 원작의 즉시 강제 교대·앙코르의 행동 순서 변경·맹독 누적·구속 지속 횟수 추첨은 위 카드 규칙으로 각색했다.

대상 효과는 보호/대타/공중과 실제 타입 무효를 따른다. 음성/대타 관통 플래그는 유지한다. 배턴/꼬리자르기에는 살아 있는 대기 동료가 필요하고 HP/구속/중복 대타 조건이 맞지 않으면 자원/카드/UID/RNG를 바꾸지 않고 거절한다. 회복봉인은 공격 자체를 취소하지 않으므로 흡수 공격의 피해는 유지한다.

## 호환성과 구현

`PlayerTechniques`가 효과1/2/3을 분기한다. v10의 `PlayerMoveCards`/`PlayerMoveRules`와 JSON은 바이트 그대로며 v11은 별도 `PlayerMoveTactics`와 `player_move_tactics_v11.json`을 덧씌운다. 기존 `move_context`와 별도로 선택 `technique_context`를 저장한다. 설치 겹수/UID/턴/금지 기술/인계 소유자·단계를 검증하고 다른 원정 버전의 새 상태 주입을 거절한다.

이전v10 실제 콘텐츠 지문 `7dfcdedd7bc0ccd814d896a7a0dc71e3ebbaf79a127c08a94d37713a1d1c106f`을 명시 수용한다. 같은 시드의v10/v11 경로/RNG·69전투 보스 정의·승인137대진 파티와 마지막 대표는 동일하다. BGM·도감·TM 호환표·배경 좌표·보상/성장/가격은 수정하지 않는다.

PokéAPI의 기존 고정CSV4종/원작 기술 설명을 대조했다. 생성기 `tools/import_player_move_tactics.py`는 v10 JSON과 원본CSV SHA256을 검사한 뒤 결정적으로32카드 오버레이를 생성한다. 추가 이미지/음원·새 특성/PP/성별/실제 명중률 시스템은 없다. v11 JSON도 게시 후 동결하며 후속 변경은 다음 버전으로 확장한다.

v11 JSON SHA256: `ee46cbac553dd2736ff20c4781205c3024fe39e4ef52b8c1761a54d95666ab53`.

## 남은 범위

기술 복사/추첨·변신 전체, 광범위 타입/능력 교환, 특성/PP 조작, 실제 트릭룸 턴 순서, 코트체인지의 양쪽 설치 교환 등은 여전히 단순 카드 변환으로 남는다. 전체919기술의 원작 고유 효과를 완성했다는 뜻은 아니다. 실제 창 검사는 기술 작업을 마친 뒤 일괄 진행하며 EXE/export/Windows CI는 계속 보류한다.
