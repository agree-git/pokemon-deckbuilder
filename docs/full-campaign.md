# 정식 원정: 배지 8개와 챔피언 도전

F5의 새 원정은 **무작위 바이옴 8곳 → 배지 8개 → 무작위 사천왕 4명 → 무작위 챔피언 1명 → 챔피언 등극**으로 이어진다. `CampaignRoute`가 시드로 경로와 인물을 정하고 `TacticalJourney`가 체력·덱·경험치·포획·야영지·배지를 유지한다. 기존 5개 장소 햇살숲 원정과 9개 장소 비교 원정은 개발용 검사에만 남긴다.

## 경로와 대진

18개 타입 중 서로 다른 바이옴 8개를 뽑는다. 각 지역은 **야생 5회 → 일반 트레이너 1회 → 엘리트 트레이너 1회 → 해당 타입 관장 1회**, 총 8전투다. 각 전투 뒤에 야영지를 거쳐 다음 전투로 이동한다. 관장은 그 지역의 마지막 전투이며 6마리를 모두 이겨야 배지 한 개를 받는다. 일반 트레이너는 2마리, 엘리트 트레이너는 HP·공격이 더 높은 3마리, 야생은 1마리다. 관장 편성은 [18개 타입 데이터](gyms.md)를 사용한다.

Lv.5 스타팅의 공격 기술이 대부분 노말이므로 고스트·바위·강철 지역은 첫 방문에서 뒤로 미룬다. 첫 두 야생은 고스트 복합타입을 제외한 해당 지역의 흔한 후보에서 뽑는다. 이후 지역은 8:3:1의 종별 출현 가중치를 사용한다. 전설·환상은 일반 출현에서 제외한다.

배지 8개를 모으면 사천왕 네 명을 차례로 상대한다. 사천왕은 **5마리**, 챔피언은 **6마리**다. 사천왕전 사이와 챔피언 직전에는 야영지가 있다. 자동 회복은 없으며 휴식·구매·가방을 이용하고 직접 출발한다. 전체 경로는 **137개 장소: 전투 69회와 야영지 68회**다.

`data/league.json`에는 전 지방의 사천왕 후보 31명과 챔피언 후보 11명을 작성했다. 챔피언을 먼저 한 명 추첨하고, 그 인물과 이미 배정된 관장을 제외한 사천왕 후보에서 서로 다른 네 명을 추첨한다. 목호처럼 두 역할의 후보인 인물도 같은 원정에 중복 등장하지 않는다. 같은 전문 타입의 서로 다른 사천왕이 뽑힐 수 있다.

포켓몬은 **1~3세대 원종 #001~386**만 사용한다. 다른 지방 인물도 해당 범위의 종으로 타입·전술을 표현한 게임용 파티를 사용한다. 원작 버전의 파티를 그대로 재현하지 않는다. 전설·환상과 한 파티 내 중복 종은 제외한다. [인물별 보스 전술](boss-tactics.md)을 적용했으며 인물 초상·대사·전용 카드·고유 보상은 후속 콘텐츠다.

경로·야생·트레이너·리그 대진은 원정 시드로 고정하고 전투 드로우·카드 보상의 난수와 분리한다. 화면 재진입과 같은 시드 재시작으로 대진이 다시 바뀌지 않는다.

## 전투·포획·성장

- [기술·도구·트레이너 통합 덱과 자동 교대·유물](tactical-combat.md)을 사용한다. 적도 한 마리씩 출전하고, 적 교체 시 손패·에너지를 새로 지급하지 않는다.
- 현대 **18개 타입과 복합타입**을 적용한다. 약점 ×2·저항 ×0.5·무효 ×0이며 복합타입은 곱해서 ×4·×0.25도 발생한다. 실제 피해와 예고·기술 미리보기에 같은 계산을 쓴다. HUD에 두 타입 아이콘, 기술 툴팁에 상성 배율을 표시한다. 지속 피해·상태 효과는 전술 게임용 규칙을 유지한다.
- 각 지역 야생 전투에서 포획할 수 있다. 적 HP 25% 이하·에너지 1·몬스터볼 1개가 필요하다. 관장·사천왕·챔피언과 지역 트레이너의 포켓몬은 포획하지 못한다. 시작 볼은 2개, 떠돌이 상인을 만난 야영지에서 35골드에 4개까지 구매한다.
- 포획 즉시 계열의 가장 미진화한 종을 영구 스타팅으로 해금한다. 합류·교체·방출 선택과 새 멤버의 만난 레벨·기술을 유지한다.
- 경험치는 종별 원작 성장 곡선의 Lv.5~100 필요량을 68회의 챔피언 이전 전투에 배분한다. 각 전투의 가중치는 `(전투 번호 + 4)² × 역할 가중치`이며 역할은 야생 4·일반 트레이너 5·엘리트 트레이너 6·관장 8·사천왕 9다. 누적 가중치 차이로 0.1 XP까지 정산해 마지막 사천왕 승리에서 Lv.100 필요량에 도달한다. 현재 레벨을 강제로 올리거나 부족분을 보충하지 않는다.
- 기절한 멤버는 해당 전투 보상의 30%만 받는다. 종별 곡선 차이를 배율로 보정하므로 계속 생존한 스타팅은 종에 관계없이 챔피언 직전에 Lv.100이 된다. 늦은 포획·교체·기절 이력에 따라 달라질 수 있다.
- 관장 순서별 레벨은 **18·29·40·50·60·70·80·91**, 사천왕은 **94·96·98·100**이다. 각 지역 일반 적은 지역의 시작 레벨부터 관장 레벨까지 차례대로 오른다. 챔피언의 **6마리 모두 Lv.100**이다. HP·행동 위력도 레벨과 전투 종류에 맞춰 오른다.
- 모든 야영지에서 방문당 한 번 **전원 HP 50% 회복·기절 회복·부상 제거 또는 카드 한 장 강화** 중 하나를 선택한다. 지닌 물건 장착·가방·만남은 별도 이용하며 상인이 있으면 유료 카드 제거도 가능하다. 추가 만남은 시드로 정한 **상인 35%·특별 이벤트 35%·아이템 발견 20%·고요한 야영지 10%** 중 하나다. 상인은 항상 볼과 무작위 회복템 2종을 판매한다. 다시 화면을 열어도 재고나 이벤트를 다시 뽑지 않는다.
- 특별 이벤트는 치유의 샘(HP 25% 회복 또는 좋은상처약), 전술가(50골드로 분석/견제 카드), 낡은 가방(볼 2개 또는 60골드)이다. 발견 보급품은 회복템 또는 볼이다. 선택·획득은 한 번만 처리하며 지나칠 수 있다. 휴식과 가방·전리품 확인은 별도로 이용한다.
- 전투와 야영지 사이에 **0.85초 이동 장면**을 표시한다. 현재 배경 위에서 파티가 짧게 걸어가고 도착 위치와 진행 바를 보여준다. 연출 중 입력·중복 이동을 차단하고 도착 시 다음 화면을 연다. 지도는 지역의 8전투를 4×2로 표시하며 전투 후 야영지 표시를 붙인다.

자세한 성장·아이템 규칙은 [성장과 야영지](growth.md)를 따른다. 모든 기술의 원작 명중·PP·날씨·확률 효과를 구현한 배틀 시뮬레이터는 아니다.

## 배지·리그·종료 조건

관장전 전체 승리 시 바이옴·타입·관장 ID·이름·단계를 배지 기록에 저장한다. 같은 전투의 재정산으로 배지·경험치·전리품을 중복 지급하지 않는다. 배지 8개 확인 후 사천왕 0~4승을 순서대로 확인하고 챔피언전에 진입한다.

**8번째 관장이나 4번째 사천왕 승리는 최종 승리가 아니다.** 챔피언의 파티까지 쓰러뜨리고 기술 학습 선택을 마치면 명예의 전당 결과를 표시한다. 전멸하면 그 자리에서 원정 실패다. 실패한 전투에는 경험치와 전리품을 주지 않는다.

지도는 현재 지역의 장소들과 8개 바이옴의 배지 진행을 보여준다. 리그 지도는 추첨된 네 사천왕과 챔피언 대진을 표시한다. 전투·원정 화면의 배경과 타입 아이콘도 현재 지역을 따른다. 결과에서 같은 시드 또는 새 시드로 재도전할 수 있다.

**원정을 자동 저장하며 종료 후에도 이어하기가 가능하다.** 전투 자원·난수·성장·보상 선택·야영지 재고까지 복원하며 백업에서 복구할 수 있다. [저장 규칙](persistence.md)을 참고한다. [공통 적 역할과 행동 예고](enemy-tactics.md), [인물별 보스 전술](boss-tactics.md)을 적용했다. 분기 확장, 특수 진화·희귀 포획과 보스 전용 카드는 후속 범위다.

## 검증

```bash
godot --headless --path . --script res://tests/test_camps.gd
godot --headless --path . --script res://tests/test_camp_ui.gd
godot --headless --path . --script res://tests/test_campaign.gd
godot --headless --path . --script res://tests/test_campaign_ui.gd
# X11 그래픽 세션에서 실제 OS 마우스·키보드로 전체 원정 완주
LIBGL_ALWAYS_SOFTWARE=1 python3 tools/test_native_pointer.py --probe native_campaign_probe
```

모델 검사는 100개 시드의 경로 재현·타입 중복 방지·6마리 관장·인물 중복 방지·출현 범위, 복합타입·무효, 리그 진입 제한과 30개 시드의 승리/전멸과 기본 정책의 완주 수를 확인한다. 공개 행동만 사용하며 완주 검사에서 HP·에너지·승패를 덮어쓰지 않는다. UI 검사는 지도·배지·야영지 서비스·기술 교체·리그·엔딩·재시작을 실제 입력 경로로 연결한다. 기존 짧은 원정의 90회 완주 검사도 유지한다.

`test_camps.gd`는 386종의 챔피언 직전 Lv.100 경험치 예산·기절 시 성장 지연과 모든 야영 이벤트의 중복 방지를 확인한다. `test_camp_ui.gd` / `native_camp_probe`는 실제 시간으로 진행되는 이동 애니메이션과 입력 차단, 상인·특별 이벤트·발견·휴식·출발을 검사한다.
