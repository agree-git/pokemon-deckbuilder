# 포켓몬 × 로그라이트 덱빌딩 게임 기획안

가제: 포켓몬 원정대 / 버전: 0.3 / 방향: 싱글플레이 포켓몬 팬게임

## 확정한 콘텐츠·아트 범위

- **포켓몬은 1~3세대 원종 386종(#001~386), 관동·성도·호연까지** 사용한다. 체육관 관장·사천왕·챔피언 인물의 출신 지방은 제한하지 않는다. 4세대 이후 포켓몬·지역폼·메가진화는 현재 범위에서 제외한다.
- 정식 원정은 **무작위 바이옴 8곳 → 타입별 관장 6마리 파티 격파와 배지 8개 → 전 지방 무작위 사천왕 4명 → 무작위 챔피언 1명 → 플레이어 챔피언 등극**으로 끝난다. 확정 규칙·추첨 초안·콘텐츠 제약은 [정식 원정 진행](full-campaign.md)을 따른다.
- 화면과 UI 기준 해상도는 **1920×1080**이다. 캐릭터, 전투 배경, 기술·상태 이펙트의 그래픽 스타일만 **도트 그래픽**으로 통일한다. 전체 화면을 저해상도로 렌더링하지 않으며 텍스트와 UI는 네이티브 해상도로 그린다. 스프라이트는 최근접 보간과 정수 배율 확대를 사용한다.
- 전투 화면은 슬레이 더 스파이어의 정보 배치를 참고한다. 상단 자원, 중앙 아군·적과 행동 예고, 하단 에너지·트레이너 손패·더미·턴 종료로 구성하고 내 파티는 왼쪽, 상대 파티는 오른쪽 가장자리에 작은 초상 목록으로 둔다. 고정 기술은 아군 옆 왼쪽 패널에 모아 손패와 분리한다.
- 지역은 타입별 18개 바이옴을 아트·데이터로 먼저 준비한다. [바이옴별 등장 포켓몬](biomes.md)에 초안을 기록한다. 전설·환상 포켓몬은 일반 출현에서 분리한 이벤트 후보로 둔다.
- 타입 정보는 현대 분류와 복합타입을 사용한다. 악타입을 포함한 18개 바이옴을 실제 해당 타입의 종으로 채우고, 관장은 전설·환상을 제외한 서로 다른 6종을 편성한다. [타입별 관장 파티](gyms.md)를 참고한다.
- 파이리·이상해씨 대 뚜벅쵸의 첫 교체 전투에서 시작해 지도·휴식·강화·첫 진화·보스로 이어지는 [9개 장소의 짧은 원정](short-expedition.md)을 구현했다. 아래의 정식 기획 규모와 현재 구현 범위는 구분한다. 현재 규칙과 미정 항목의 결정은 [첫 전투 규칙](battle-rules.md)을 따른다. 386종 에셋·165종 기술 연출·18개 배경은 콘텐츠 제작용 기반이며 모든 포켓몬·기술의 전투 규칙 구현을 뜻하지 않는다.
- 전설·환상은 쉽게 획득하지 못하도록 일반 출현과 관장 편성에서 제외한다. 포획에 한 번 성공하면 해당 계열의 가장 미진화한 종을 다음 원정의 스타팅으로 영구 해금한다. 진화체 그대로는 스타팅에 추가하지 않는다. [희귀 포획과 스타팅 해금](capture-unlocks.md)의 요구사항과 구현 전 설계 초안을 따른다.

## 현재 전투 방식 시험

F5 기본 실행은 **포켓몬 고정 기술 + 공유 트레이너 카드 덱 + 브레이크·연쇄 격파**를 사용하는 [5개 장소 전술 원정](tactical-journey.md)이다. 전투 3회·회복/훈련 2회·트레이너 카드 보상을 거쳐 민화의 풀타입 6마리 파티를 이기면 배지 1개를 받고 짧은 원정을 끝낸다. F4로 단일 전술 시험, F3로 기존 9개 장소 원정을 플레이할 수 있다. [전투 규칙과 조작](tactical-combat.md)을 참고한다. 새 방식은 각 기술을 포켓몬당 턴 1회 사용하고, 서로 다른 전술로 빈틈 3을 채워 행동 취소·다음 공격 2배·환급을 만든다. 브레이크한 적을 직접 격파하면 추가 환급을 받고 같은 턴에 다음 적을 공격한다.

아래 4~6절의 기술 카드·포획 시 덱 추가·기절 시 소유 카드 제거는 **기존 짧은 원정의 설계**다. 새 방식의 손패에는 공용 트레이너 카드만 있으며 기술은 고정 버튼이다. 새 원정은 트레이너 카드 보상과 최대 체력 훈련을 연결했으며 포획·기술 학습·진화는 후속 단계다. 정식 원정 목표는 유지한다.

## 1. 한 문장으로 설명하는 게임

최대 세 마리의 포켓몬으로 원정대를 구성하고, 기술 카드를 사용해 싸우며 야생 포켓몬을 포획하고 진화시키며, 무작위 바이옴 8곳의 배지를 모아 사천왕과 챔피언을 넘어 새 챔피언이 되는 로그라이트 덱빌딩 게임.

핵심은 **“포켓몬을 모으는 일이 곧 덱을 만드는 일”**이다. 카드 전투를 반복하는 동안 파티의 구성, 교체 순서, 기술 조합이 함께 성장한다.

## 2. 플레이 경험과 기본 구성

| 항목 | 기획 기준 |
|---|---|
| 플랫폼 | PC, 마우스 중심 조작 |
| 화면 | 2D 전투 화면과 분기형 원정 지도 |
| 파티 | 최대 3마리, 전투에는 1마리씩 출전 |
| 덱 | 파티 전체가 사용하는 하나의 공유 덱 |
| 한 판 | 바이옴 8곳과 리그에 맞춰 노드 수·플레이 시간 재산정 |
| 승리 | 배지 8개 획득 후 무작위 사천왕 4명과 챔피언 1명을 이겨 챔피언 등극 |
| 체육관 | 각 바이옴 마지막 스테이지, 해당 타입 관장의 6마리 파티 |
| 리그 인물 | 전 지방에서 사천왕 4명과 챔피언 1명 무작위 선정 |
| 패배 | 파티의 포켓몬이 모두 기절 |
| 반복 동기 | 다른 포획 결과와 기술 보상으로 새로운 조합 완성 |

탐험을 시작할 때 스타팅 포켓몬 한 마리를 선택한다. 같은 스타팅을 골라도 어떤 포켓몬을 포획하고 어떤 기술을 익히느냐에 따라 운영 방식이 달라진다.

## 3. 한 판의 흐름

1. 스타팅과 원정 시드를 정하고, 무작위로 선정된 바이옴 8곳의 원정을 출발한다.
2. 각 바이옴에서 경로와 전투·포획·휴식·성장을 선택한다.
3. 바이옴 마지막 스테이지에서 해당 타입 체육관 관장의 6마리 파티를 이기고 배지 1개를 획득한다. 관장은 어느 지방 출신이어도 된다.
4. 바이옴 8곳을 통과해 배지 8개를 모으면 리그를 연다.
5. 전 지방에서 무작위로 선정한 사천왕 4명을 차례로 이긴다.
6. 전 지방에서 무작위로 선정한 챔피언 1명을 이기고 플레이어가 챔피언에 등극한다.
7. 챔피언 등극 또는 파티 전멸로 원정을 종료하고, 다음 도전에서 새 파티와 덱을 시작한다.

현재 한 지역의 9개 장소 원정은 전투·성장·승패를 검증하는 프로토타입이다. 정식 원정의 8개 바이옴과 리그는 후속 구현이며, 바이옴당 노드 수와 총 플레이 시간은 새 구조에 맞춰 다시 조정한다.

## 4. 전투 규칙

### 4.1 턴과 자원

- 턴 시작 시 에너지 3을 받고 카드 5장을 뽑는다. 에너지는 파티가 공유한다.
- 남은 손패는 턴 종료 시 버린다. 뽑을 카드가 부족하면 버린 더미를 섞는다.
- 기술 카드에는 사용 포켓몬, 에너지 비용, 기술 타입, 효과가 표시된다.
- 포켓몬 전용 기술은 해당 포켓몬이 출전 중일 때만 사용할 수 있다.
- 트레이너 공용 카드는 어느 포켓몬이 출전해도 사용할 수 있다.
- 적의 다음 공격량, 방어, 강화, 교체 여부를 미리 보여준다.

### 4.2 교체

매 턴 첫 교체는 무료이고, 추가 교체에는 에너지 1이 든다. 교체할 수 있는 대상은 살아 있는 대기 포켓몬이다. 교체해도 손패와 남은 에너지는 유지된다.

따라서 한 턴에 첫 포켓몬의 기술을 사용한 뒤 교체하고 두 번째 포켓몬의 기술을 사용할 수 있다. 방어로 얻은 보호막은 사용 포켓몬에게 귀속되며, 남은 보호막은 플레이어 턴 시작 시 제거된다. 공격을 받아낼 포켓몬까지 고려해서 턴을 끝내야 한다.

### 4.3 체력과 기절

체력은 전투 사이에도 유지된다. 출전 포켓몬이 기절하면 남은 포켓몬을 선택해 즉시 출전시키며 이 교체는 무료 교체 횟수를 사용하지 않는다.

기절한 포켓몬의 카드는 현재 전투에서 손패와 모든 더미에서 제외한다. 이미 사용한 기술 효과는 유지한다. 기절할 때마다 비용 1, 효과 없음의 공용 ‘부상’ 카드 1장을 원정 덱에 추가한다. 기절로 덱을 얇게 만드는 전략에 손실을 부여하기 위한 초안이며, 테스트 후 조정한다.

휴식에서 회복을 선택하면 살아 있는 포켓몬의 최대 체력 30%를 회복하고, 기절한 포켓몬은 최대 체력 30%로 부활한다. 이때 해당 포켓몬의 부상 카드도 제거한다.

### 4.4 상성과 상태이상

첫 버전은 불꽃·물·풀의 순환 상성과 중립인 노말만 구현한다. 약점은 기술 피해 ×1.5, 저항은 ×0.75로 시작한다. 상성은 공격의 기술 타입과 방어 포켓몬 타입으로 계산하고, 상태이상의 지속 피해와 보호막에는 적용하지 않는다. 소수 피해는 내림한다.

첫 버전의 지속 효과는 화상과 씨뿌리기로 제한한다. 두 상태 모두 대상 진영의 행동 종료 후 2 피해를 주고 3회 발동 후 해제된다. 씨뿌리기는 적용한 포켓몬이 살아 있으면 체력을 2 회복한다. 대상이 대기 중이어도 자기 진영의 턴 종료 시 발동한다. 같은 효과를 다시 걸면 중첩하지 않고 남은 횟수만 3회로 갱신한다. 지속 피해는 상성과 보호막을 무시하며 화상→씨뿌리기 순서로 처리한다. 상태는 전투 종료 시 해제된다.

## 5. 파티와 덱을 연결하는 방법

### 5.1 초기 덱과 기술 학습

초기 덱은 공용 카드 6장과 스타팅 전용 카드 4장, 총 10장으로 시작한다. 공용 카드는 공격·방어·드로우 같은 기본 기능을 맡고, 전용 카드는 포켓몬의 운영 방식을 만든다.

예를 들어 불꽃 스타팅은 화상과 추가 공격, 물 스타팅은 보호막과 다음 턴 준비, 풀 스타팅은 씨뿌리기와 체력 유지에 집중한다. 종별 특성은 처음에는 한 가지씩 고정한다.

전투 승리 보상은 현재 파티가 배울 수 있는 기술 카드 3개 중 하나를 고르는 방식이다. 보상은 넘길 수 있다. 처음에는 기술을 새 카드로 추가하는 방식만 사용하고, 상점의 카드 제거로 덱을 다듬는다.

### 5.2 포획

야생 전투에서는 **쓰러뜨려 기술 보상을 받을지, 포획해 파티를 바꿀지** 선택한다.

- 야생 전투는 첫 버전에서 적 한 마리만 등장한다.
- 적 체력이 최대 체력의 25% 이하이면 포획 버튼이 활성화된다.
- 에너지 1과 몬스터볼 1개를 사용하면 확정 포획하고 전투가 끝난다.
- 포획한 전투에서는 일반 기술 카드 보상을 받지 않는다.
- 트레이너의 포켓몬과 보스는 포획할 수 없다.
- 시작 몬스터볼은 2개로 두고 상점과 일부 이벤트에서 추가 획득한다.

포획 성공 시 잡은 포켓몬의 기본 기술 카드 2장이 덱에 추가된다. 첫 버전에서는 체력을 최대치로 회복해 합류시킨다. 이는 새로운 포켓몬을 즉시 활용할 수 있게 하는 편의 규칙이다.

파티가 가득 차면 기존 포켓몬 한 마리를 내보내거나 새 포켓몬을 풀어준다. 몬스터볼은 어느 쪽이든 소모된다. 기존 포켓몬을 내보내면 그 포켓몬 전용 카드와 연결된 부상 카드가 모두 제거된다. 공용 카드는 유지된다.

### 5.3 진화

전투 승리 또는 포획으로 전투를 마치면 파티 전체에 경험치를 지급한다. 정산 시 살아 있는 멤버는 정상 경험치의 100%, 기절한 멤버는 **30%**를 받는다. 현재 기본 보상 1 기준으로 각각 1과 0.3이며 소수 경험치는 누적하고 표시한다. 출전 여부·막타 여부로 보상을 나누지 않는다. 일정 경험치에 도달한 포켓몬은 휴식 장소에서 진화할 수 있다.

휴식 장소에서는 회복, 카드 한 장 강화, 포켓몬 한 마리 진화 중 하나만 선택한다. 진화는 단순한 체력 증가보다 **특성 변화와 전용 기술 변화**에 무게를 둔다. 기존 전용 카드 한 장을 진화 기술로 바꾸며, 카드 수는 늘리지 않는다. 카드 강화는 카드 한 장의 수치나 비용을 개선하는 별도 기능이다.

첫 프로토타입의 진화는 스타팅 세 종만 지원하고 경험치 기준은 4로 시작한다. 진화 전후 체력은 최대 체력이 바뀌면 기존 체력 비율을 유지한다.

## 6. 실제 전투 예시

불꽃 포켓몬과 풀 포켓몬을 보유한 상태에서 불꽃 포켓몬이 출전 중이라고 가정한다.

| 순서 | 행동 | 에너지 변화 | 의미 |
|---|---|---|---|
| 1 | 불꽃 포켓몬의 ‘불씨’ 사용 | 3 → 2 | 4 피해와 화상 부여 |
| 2 | 풀 포켓몬으로 첫 교체 | 2 → 2 | 무료 교체 활용 |
| 3 | 풀 포켓몬의 ‘씨뿌리기’ 사용 | 2 → 1 | 지속 피해와 회복 준비 |
| 4 | 공용 ‘방어’ 사용 | 1 → 0 | 출전 중인 풀 포켓몬에게 보호막 5 |
| 5 | 턴 종료 | 0 | 풀 포켓몬이 예고된 공격을 받고 적 행동 종료 후 지속 효과 발동 |

이 예시는 손패에 위 세 카드가 들어왔을 때 가능한 연계다. 매 턴 같은 행동을 반복하는 고정 콤보가 아니라, 손패·상성·남은 체력·적 행동에 따라 교체 순서를 결정한다.

## 7. 원정 지도와 보상

| 장소 | 주요 기능 | 선택의 대가 |
|---|---|---|
| 야생 전투 | 기술 보상 또는 포획 | 포획하면 해당 전투의 기술 보상 포기 |
| 트레이너 전투 | 기술 보상과 돈 | 체력 소모 |
| 강한 트레이너 | 높은 보상과 도구 | 강한 공격으로 기절 위험 증가 |
| 휴식 | 회복·강화·진화 중 하나 | 다른 성장 기회 포기 |
| 상점 | 카드 제거, 몬스터볼, 도구 구매 | 한정된 돈 사용 |
| 이벤트 | 파티나 덱을 바꾸는 선택 | 체력, 돈, 카드 등의 비용 |
| 체육관 | 바이옴 마지막 스테이지, 해당 타입 관장의 6마리 파티, 승리 시 배지 1개 | 배지 8개를 모아야 리그 해금 |
| 사천왕 | 전 지방 무작위 4명과 순서대로 전투 | 모두 이겨야 챔피언전 해금 |
| 챔피언 | 전 지방 무작위 1명과 최종전 | 승리하면 플레이어가 챔피언 등극 |

도구는 카드와 별도로 지속 효과를 주는 원정 장비다. 초기에는 포켓몬별 장비 슬롯 없이 파티 공용 도구만 사용한다. 예를 들어 첫 교체 후 보호막 3, 포획으로 합류한 포켓몬의 기본 기술 한 장 강화, 휴식 회복량 증가 등을 시험할 수 있다.

완성형 지역 테마는 숲, 해안, 화산처럼 잡을 수 있는 포켓몬과 적 조합이 예상되는 장소로 구성한다. 한 타입이 모든 전투를 압도하지 않도록 체육관에도 약점을 보완하는 포켓몬이나 행동 패턴을 넣는다.

## 8. 이 게임에서 재미를 만들 선택

| 선택 | 고민할 내용 |
|---|---|
| 포획과 기술 보상 | 새로운 파티원이 필요한가, 현재 덱의 완성도를 높일 것인가 |
| 파티 추가 | 상성과 기술 선택지는 늘지만 전용 카드가 분산되는가 |
| 교체 순서 | 공격을 연결할 것인가, 남은 체력을 보존할 것인가 |
| 회복과 진화 | 지금 살아남을 것인가, 이후의 전투를 준비할 것인가 |
| 기술 획득과 넘기기 | 좋은 카드라도 원하는 조합을 뽑기 어렵게 만드는가 |
| 파티 교체 | 지금까지 강화한 기술을 포기할 만큼 새로운 조합이 좋은가 |

가장 먼저 검증할 차별점은 포획 자체의 수집량이 아니라, **포획 이후 같은 손패를 다른 방식으로 운용하게 되는 변화**다.

## 9. 첫 프로토타입 범위와 정식 원정의 구분

아래 숫자는 한 지역의 핵심 전투를 확인하기 위한 초안 상한이며 정식 원정의 8개 바이옴·리그 분량이 아니다. 현재 구현 상태는 [짧은 원정](short-expedition.md), 새 정식 목표는 [정식 원정 진행](full-campaign.md)을 따른다.

| 항목 | 첫 구현 범위 |
|---|---|
| 지역 | 1개, 8~10개 노드, 15~20분 목표 |
| 포켓몬 | 스타팅 3종과 추가 야생 3종 |
| 진화 | 스타팅 3종과 첫 진화 3종, 총 6개 모습 |
| 타입 | 불꽃·물·풀·노말 |
| 카드 | 공용 6종 + 기본 전용 18종 + 진화 전용 3종 = 27종 |
| 특성 | 기본 종별 1개, 진화 특성 변화는 3개 이내 |
| 적 | 일반 전투 구성 6개, 강한 트레이너 1개, 보스 1개 |
| 상태 | 화상, 씨뿌리기 |
| 도구 | 5개 |
| 이벤트 | 3개 |
| 저장 | 원정 진행 상태와 설정 저장 |

카드 ‘종류’와 덱에 넣는 ‘장수’는 별개다. 초기 덱의 공용 6장과 전용 4장은 일부 카드의 중복으로 구성할 수 있다.

첫 버전에서는 개체값·노력치·성격·성별·교배·복잡한 날씨·온라인 대전은 제외한다. 원정 중 성장과 카드 선택만으로도 충분히 조합이 달라지는지 먼저 확인한다. 원정 밖 성장은 도감과 기록으로 시작하고, 새로운 스타팅과 콘텐츠 해금은 추후 확장한다. 영구 능력치 증가는 넣지 않는다.

## 10. 구현 순서와 검증 기준

1. **전투 한 판:** 포켓몬 1종, 카드 약 6종, 적 1종으로 드로우·에너지·버리기·행동 예고·승패를 구현한다. 먼저 카드 선택만으로 재미가 있는지 확인한다.
2. **교체 전투:** 아군 2종으로 공유 덱과 교체를 넣는다. 교체 때문에 할 수 있는 행동이 늘어나는지, 사용 불가 카드 때문에 답답한지 확인한다.
3. **포획:** 체력 조건, 몬스터볼, 파티 합류, 카드 추가와 파티 교체를 연결한다. 잡은 직후 플레이 방식이 달라지는지 확인한다.
4. **짧은 원정:** 지도, 전투 보상, 휴식, 체력 유지, 패배 후 재시작을 만든다. 경로와 성장 선택이 다음 전투에 영향을 주는지 확인한다.
5. **진화와 콘텐츠:** 진화, 특성, 상점, 도구, 보스를 넣고 첫 프로토타입 분량으로 늘린다.
6. **정식 원정:** 적 6마리 파티 전투 → 바이옴 8곳과 관장·배지 → 사천왕 4명과 챔피언 1명 → 챔피언 등극을 연결한다. 장기 진행 저장과 원정 길이·회복·난이도 조정을 함께 검증한다.

구현 일정은 사용 엔진, 개발 인원과 기존 경험을 정한 뒤 산정한다. 그 전에 포켓몬이나 카드 종류부터 대량 제작하지 않는다.

## 11. 주요 위험과 조정 방향

- **손패 막힘:** 대기 포켓몬 카드가 지나치게 많으면 행동이 제한된다. 발생 턴을 기록하고, 공용 카드 비율·무료 교체 횟수·전용 카드 수를 조정한다.
- **무료 교체 과다:** 매번 같은 순서로 교체하게 되면 적의 공격 예고와 종별 특성을 바꿔 실제 선택이 생기는지 확인한다. 교체를 강제로 보상하는 도구는 신중하게 추가한다.
- **포획이 항상 정답:** 파티 확대와 체력 회복이 너무 유리하면 포획의 에너지·몬스터볼 비용, 보상 손실, 합류 체력을 조정한다.
- **상성이 카드 전략을 압도:** 특정 타입만 맞추면 이기는지 확인한다. 기술 타입을 다양하게 제공하고 상성 배율과 보스 구성을 조정한다.
- **기절로 덱 압축:** 부상 카드의 손실이 충분한지 확인한다. 벌칙은 의도적 기절을 막되 패배한 원정을 회복 불가능하게 만들지 않아야 한다.

전투 로그에는 승패, 턴 수, 교체 횟수, 손패에서 사용하지 못한 전용 카드 수, 포획 여부와 파티 구성을 남긴다. 정식 밸런스 수치는 이 데이터를 바탕으로 결정한다.

## 12. 첫 버전의 성공 조건

첫 프로토타입에서 확인해야 할 것은 다음 세 가지다.

1. 교체가 단순한 상성 대응을 넘어 카드 연계를 만든다.
2. 새로운 포켓몬을 잡으면 다음 전투의 선택이 달라진다.
3. 패배해도 다른 파티와 덱으로 다시 시도할 이유가 있다.

이 세 가지가 성립하면 지역·포켓몬·카드를 확장한다. 성립하지 않으면 콘텐츠를 늘리기 전에 공유 덱과 교체 규칙부터 수정한다.
