# 친밀도·시간대 진화

친밀도 220 이상인 포켓몬이 경험치로 **실제로 레벨업할 때 자동 진화**한다. 1~3세대 원종의 친밀도 진화 9개 경로를 지원한다. 진화 재료·골드·야영지 행동을 추가로 소비하지 않는다.

| 포켓몬 | 진화 결과 | 추가 조건 |
|---|---|---|
| 피츄 | 피카츄 | 없음 |
| 삐 | 삐삐 | 없음 |
| 푸푸린 | 푸린 | 없음 |
| 골뱃 | 크로뱃 | 없음 |
| 토게피 | 토게틱 | 없음 |
| 루리리 | 마릴 | 없음 |
| 럭키 | 해피너스 | 없음 |
| 이브이 | 에브이 | 준비한 원정 시간이 낮 |
| 이브이 | 블래키 | 준비한 원정 시간이 밤 |

경로와 낮·밤 조건은 고정 `pokemon_evolution.csv`의 기본형 진화와 대조한다. 최신 원본 CSV의 일부 문턱은 160이지만 현재 게임은 **3세대 기준 220**을 사용한다. 획득량과 초기값은 원정 길이에 맞춘 게임용 규칙이다.

## 친밀도 획득

| 행동 | 변화 |
|---|---:|
| 새 스타팅·새로 포획한 멤버 | 70으로 시작 |
| 전투 승리·포획 정산, 생존 멤버 | +8 |
| 승리 정산에서 기절한 멤버 | -10 |
| 생존 상태의 실제 레벨업 | 레벨당 +2 |
| 야영지의 주 행동으로 휴식 | 전원 +5 |

범위는 0~255다. 출전·막타 여부와 무관하게 파티원에게 적용한다. 기절한 멤버는 생존 레벨업의 +2를 받지 않으며 기존 30% 경험치를 그대로 받는다. 친밀도 감소 후에도 220 이상이고 경험치로 레벨이 오르면 기절 상태를 유지한 채 진화할 수 있다. 전멸에는 승리·레벨업 보상을 주지 않는다.

휴식은 부활한 동료에게도 +5를 주지만, 카드 강화 선택·가방 회복약·무료 시간대 변경은 친밀도를 올리지 않는다. 휴식/강화는 기존대로 야영지당 한 번이므로 화면 재진입이나 반복 클릭으로 친밀도를 쌓을 수 없다. 같은 전투의 재정산도 추가 보상을 주지 않는다.

휴식으로 220을 넘더라도 즉시 진화하지 않는다. 다음 실제 레벨업을 기다린다. Lv.100은 더 레벨업할 수 없으므로 그 전에 조건을 갖춰야 한다. 친밀도는 현재 진화 조건에 사용하며 은혜갚기 등 기술 위력 연동은 이번 범위가 아니다.

## 원정 시간과 화면

새 원정은 낮으로 시작한다. `야영지 → 휴식·강화`의 작은 **낮 / 밤** 버튼으로 다음 전투의 시간을 준비한다. 선택한 시간은 금색으로 표시하며 이후 바꾸기 전까지 유지한다. 시간 선택은 HP·경험치·친밀도·골드·재고·휴식 횟수를 바꾸지 않는다.

이는 이브이의 진화 분기를 준비하는 원정 설정이다. 실제 컴퓨터 시각을 읽거나 기다리게 하지 않으며, 배경·출현·전투 피해를 시간에 따라 바꾸지 않는다. 전투·기술 학습·보상 중에는 시간대를 바꾸지 못한다. 이브이의 [돌 진화 세 갈래](evolution-items.md)도 유지하므로 먼저 돌을 사용하면 해당 종으로 진화하고 친밀도를 보존한다.

친밀도 진화 대상은 기존 파티 목록에 `친밀 215/220`처럼 진행을 표시한다. 이름 툴팁에서 정확한 값·문턱·진화 결과·현재 시간·획득 규칙과 경험치를 확인한다. 자동 진화는 기존 성장 요약에 현재 종과 새 종으로 표시한다. 새 HUD 패널을 늘리지 않는다.

레벨을 차례로 처리하므로 한 번에 많은 경험치를 얻어도 각 단계의 진화·기술 습득을 잇는다. 예를 들어 높은 친밀도의 주뱃은 Lv.22에 골뱃, 다음 레벨업에 크로뱃으로 진화한다. 같은 한 레벨에서 두 번 진화하지 않는다. UID·경험치·카드 소유권·강화·장비와 잃은 HP를 보존하며, 진화 후 기술은 새 종의 에메랄드 레벨표를 따른다. 네 기술이 차면 기존 기술 교체/포기 화면을 사용한다.

## 저장 호환과 범위

v3 저장을 유지하며 포켓몬의 선택 필드 `friendship`과 원정의 선택 필드 `time_of_day`에 기록한다. 성공한 행동 이후 자동 저장한다. 이전 저장에서 필드가 없으면 화면과 새 성장 계산은 70·낮을 기본으로 삼고, 읽기·복원·미리보기만으로 필드를 추가하지 않는다. 이미 지나간 전투의 친밀도를 소급 지급하거나 읽는 순간 진화시키지 않는다.

실제 친밀도 행동을 한 멤버와 변경한 시간부터 새 상태를 저장한다. 재실행 시 선택한 밤과 친밀도를 복원하므로 다음 레벨업의 분기가 바뀌지 않는다. 저장 검사는 친밀도 정수 0~255와 `day`/`night`를 확인한다. 새 원정으로 초기화하면 친밀도 70·낮으로 돌아간다. 포획 도감과 미진화 스타팅 해금은 기존 규칙을 유지한다.

이번 추가 범위는 친밀도·시간대다. 배루키의 능력치 분기·개무소의 랜덤 분기·껍질몬 추가 합류·빈티나의 아름다움 등은 후속 범위다. 4세대 이후 종·지역폼은 추가하지 않는다.

## 검증

```bash
godot --headless --path . --script res://tests/test_friendship.gd
godot --headless --path . --script res://tests/test_friendship_ui.gd
python3 tools/test_evolution_process.py --friendship
# X11 세션 활성화 후
LIBGL_ALWAYS_SOFTWARE=1 python3 tools/test_native_pointer.py --probe native_friendship_probe
```

규칙 검사는 9개 경로의 문턱·레벨업·분기·능력치/기술 보존·기절과 30% XP·휴식/정산 중복 방지·새 포획·돌 분기·기존 저장과 잘못된 필드를 확인한다. 실제 X11 검사는 세 창 비율의 시간 선택·휴식·자동 저장과 실제 카드 전투 후 이브이/피츄/루리리의 자동 진화·기술 교체·보상을 확인한다. 별도 Godot 프로세스 세 개로 준비 후 종료 → 이어하기와 실제 전투/진화 → 다시 종료 후 다음 야영지를 검증한다.
