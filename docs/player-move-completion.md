## 전체919 분류와 필요한 파일

새 `audit`의 상호 배타적 분류는 기본 카드203 / 특징 반영516 / 명시 각색198 / 효과 없음2종이다. 과거의 ‘특징/각색586개’와 분류 기준이 달라 증감 수로 비교하지 않는다. 기본203을 미구현 개수로 세지 않는다. 해당 ID의 `audit`, `moves`, `deltas`, `removed`, `policy_notes`만 조회한다.

- `player_move_completion.gd`:정의/복사 보정·조건/공통 위력·동료 회복·주요 상태 보존·회복 정책·교대/기절 정리.

기초 사실은 [Pokémon Showdown 고정 moves.ts](https://github.com/smogon/pokemon-showdown/blob/7b02eb39878f4b486f658a752b38c161379bd352/data/moves.ts),기존 고정 PokéAPI 자료 및 버전별 카드 정의와 대조했다. 원본 SHA256 `61ab107dae9628d79ac61da16c72e8565f6a1211874298e00c77c5c0ac9755a7`,기존 MIT 고지 유지.
