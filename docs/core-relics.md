# 원정의 핵심 유물

일반 파티 유물 10종에 **핵심 유물 5종**을 추가했다. 관장전을 이기면 핵심 유물 셋을 제시하며, 원정 전체에서 하나만 선택한다. 일반 유물은 계속 함께 모을 수 있다. 선택한 핵심의 효과와 대가는 이후 전투에서 파티 전체에 적용한다.

| 핵심 유물 | 효과 | 대가 |
|---|---|---|
| 순환 엔진 | 매 턴 첫 기술 자동 교대 시 2장 뽑기 | 첫 턴을 포함한 턴 시작 드로우 4장 |
| 고정 조준경 | 턴 시작 출전 멤버의 첫 기술 비용 -1, 최소 0 | 수동 교대 비용 2. 기술·강제 교대는 계속 무료 |
| 침식 촉매 | 적의 화상·독·씨앗 매회 피해 +50% | 기술 카드의 직접 공격 피해 -20% |
| 잔류 방벽 | 아군 턴 시작에 각 살아 있는 동료의 남은 보호막 절반 보존 | 카드의 HP 회복량 -50%. 야영지 회복은 유지 |
| 비상 보급함 | 매 턴 첫 소진 도구 사용 시 에너지 +1, 2장 뽑기 | 첫 턴을 포함한 턴 시작 드로우 4장 |

## 선택과 보상

다섯 종류에서 중복 없이 셋을 원정 시드·관장 위치로 추첨한다. 현재 조합에 맞는 후보가 항상 나오는 것은 아니다. 페이지 재진입과 이어하기는 이미 제시한 후보를 바꾸지 않는다. 하나를 받으면 이후 보상에 다른 핵심 유물을 제시하지 않는다. 일반 야생·트레이너 보상의 유물 풀에도 핵심은 섞지 않는다.

선택하지 않고 넘기면 다음 관장에서 다시 기회를 받는다. 마지막 관장에서도 넘기면 핵심 없이 리그를 진행한다. 덱에 없는 효과를 즉시 지급하거나 기존 공용 유물을 잃지는 않는다. 최초 핵심 선택을 마친 이후의 관장은 기존 카드·기술·유물/장비 혼합 보상을 제공한다.

선택 화면은 아이콘과 함께 효과·대가를 나눠 표시한다. 전투 메뉴에는 핵심을 가장 위에 표시하고, 11개 유물을 모아도 메뉴 버튼을 가리지 않도록 목록을 스크롤한다. 손패의 고정 조준경 할인 비용과 툴팁도 현재 상태를 반영한다.

## 세부 전투 규칙

- 스피드 에너지는 기존대로 턴 시작 한 번, 빠르면 4·그 외 3이다. 핵심 효과가 턴 중 스피드를 다시 판정하거나 지급한 에너지를 되돌리지 않는다.
- 순환 엔진은 기술 소유자가 바뀌는 자동 교대에만 발동한다. 수동·강제 교대는 제외한다. 릴레이 발전기 등의 기존 효과와 함께 사용할 수 있다.
- 고정 조준경의 대상은 턴 시작 출전 UID로 고정한다. 교대해도 바뀌지 않으며 원래 비용 0인 첫 기술에도 그 턴의 첫 기술 기회를 사용한다. 해당 첫 기술을 쓰지 않았으면 돌아와 사용해도 할인한다. 수동 교대는 2를 먼저 지불하고 강제 교대는 지불하지 않는다.
- 침식 촉매는 소모전 작전의 가산 후 지속 피해를 1.5배로 만든다. 아군의 상태 피해·혼란·상태 회수에는 이 배율을 적용하지 않는다. 직접 기술 피해는 기존 자속·상성·추가 피해 계산 후 0.8배다. 면역 피해 0을 보존한다.
- 잔류 방벽은 적 행동과 상태 피해를 처리한 뒤 실제 다음 아군 턴에 남은 보호막을 절반으로 줄인다. 카드 회복은 치유의 방울 등의 가산 후 절반이며 씨앗 흡수·지닌 물건의 턴 종료 회복은 별도다. 전투 종료 후 보호막을 다음 전투에 이월하지 않는다.
- 비상 보급함은 카테고리가 도구이고 사용 후 소진되는 카드에만 발동한다. 소진 트레이너는 제외한다. 카드 비용을 먼저 지불할 수 있어야 하며 보급함 에너지로 선결제하지 않는다. 보급 벨트와 드로우를 합산한다.

비율 계산은 내림하고, 면역 0 외 양수 피해·회복은 최소 1이다. 손패 최대 10장과 기존 소진/버리기 규칙을 유지한다. 턴당 제한은 같은 턴의 적 교체·재실행으로 초기화하지 않으며 실제 다음 아군 턴에 초기화한다. 피해·회복 미리보기와 적용은 같은 계산을 사용하고 기존 단계별 연출에 발동을 표시한다.

## 저장 호환

저장 버전·콘텐츠 지문은 유지한다. 핵심은 기존 `relics`, 턴당 발동 여부는 `turn_flags`, 할인 대상은 저장된 턴 시작 출전 UID로 보존한다. 새 표식이나 개체값·노력치를 추가하지 않는다. 중복 핵심 보유·이미 핵심을 보유한 상태의 추가 핵심 보상은 저장 검사와 보상 행동에서 거부한다.

기존 원정에 핵심이 없으면 다음 새 관장 보상부터 선택할 수 있다. 이미 저장된 관장 보상과 진행 중 전투는 그대로 복원하며 강제로 후보를 바꾸지 않는다. 그러므로 기존 관장 보상 화면을 이어한 경우에는 그 다음 관장에서 기회를 받는다.

## 검증과 남은 범위

```bash
godot --headless --path . --script res://tests/test_core_relics.gd
godot --headless --path . --script res://tests/test_core_relics_ui.gd
python3 tools/test_core_relics_process.py
# 실제 X11 입력
LIBGL_ALWAYS_SOFTWARE=1 python3 tools/test_native_pointer.py --probe native_core_relics_probe
```

효과·대가·발동 제한·미리보기·반올림·상성 무효·기존 효과 조합·중복 선택·이전 보상 보존과 저장/복원을 검사한다. 별도 Godot 프로세스 세 개로 실제 첫 관장 보상 → 이어하기/선택/다음 전투의 행동 → 재실행/승리/중복 정산 방지를 확인했다.

실제 X11 검사 39개·마우스 클릭 7회·휠 입력으로 세 창 비율의 보상 선택, 11개 유물 메뉴의 끝 항목 접근과 버튼 겹침 방지를 확인하고 1920×1080 화면을 검토했다. 끝 목록은 모든 일반 유물을 부여한 표시 전용 픽스처이며, 세 관장 보상은 공개 행동으로 실제 승리해 도달했다.

[관동 파티 120개 측정](measurements/campaign-core-relics.md)에서 완주 114개는 핵심 다섯 종류에 따라 최종 구성이 나뉘었다. 일반 유물 10종은 완주 시 여전히 같은 풀로 수렴한다. 핵심 한 개 선택이 운영 분기를 만들었지만 일반 유물 풀·보상 가치와 주제별 최적 전투 정책, 다른 파티·포획 운영·수동 밸런스는 후속 작업이다. 현재 검증은 Linux/Godot 4.7.2이며 Windows 검증은 별도다.
