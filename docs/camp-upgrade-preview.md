# 야영지 카드 강화 비교

`야영지 → 휴식·강화 → 카드 강화 선택`에서 카드를 고르면 현재 카드와 강화 후 카드를 나란히 표시한다. 비용·카드 효과·기술의 소유 포켓몬을 실제 카드 그림으로 비교한 뒤 `이 카드 강화`를 누른다.

강화 후 표시는 보상·전투와 같은 `TacticalContent.definition()` 규칙으로 만든 임시 카드다. 고정 설명을 별도로 복사하지 않으므로 위력·보호막·회복·드로우·에너지·비용 감소 등 실제 강화 결과를 따른다. 기술에는 동료 이름과 스프라이트를 유지한다. 전투 대상에 따른 피해량은 달라지므로 기술 위력·분류와 비율 효과를 표시한다.

비교 화면을 열거나 `목록으로`·닫기·Esc를 누르는 동안 원정 카드·HP·경험치·골드·난수·야영지 행동은 바뀌지 않는다. Esc는 비교 화면에서 카드 목록으로, 목록에서 야영지로 한 단계씩 돌아간다. 비교 중에는 아래 화면의 휴식·출발·다른 카드 입력을 가린다.

확정은 선택한 카드 UID로 기존 공개 강화 행동을 호출한다. 그때도 야영지 여부·주 행동 사용 여부·카드의 존재와 강화 가능 여부를 다시 검사한다. 성공하면 한 장만 강화하고 휴식·조사와 공유하는 주 행동을 사용한 뒤 기존 자동 저장을 실행한다. 비교 화면 자체는 저장하지 않으며 재실행하면 강화가 확정된 상태만 이어진다.

새 능력치 측정에서 육성 운영은 전투 턴을 줄이는 경우와 휴식을 포기해 더 일찍 전멸하는 경우가 모두 나타났다. 비교 화면은 강화의 실제 효과와 야영지 행동 비용을 함께 확인하도록 추가했다. [측정 조건과 한계](balance-measurements.md)를 참고한다.

## 검증

```bash
godot --headless --path . --script res://tests/test_upgrade_preview_ui.gd
godot --headless --path . --script res://tests/test_deck_ui.gd
# X11 세션의 실제 OS 입력
LIBGL_ALWAYS_SOFTWARE=1 python3 tools/test_native_pointer.py --probe native_upgrade_preview_probe
```

Godot 4.7.2에서 실제 X11 검사 27개·포인터 입력 21회와 Esc 세 번을 통과했다. 1280×720·1024×768·1280×800에서 보호막·드로우·기술 카드를 확인하고, 확정 버튼의 위/중앙/아래 클릭·취소·Esc·모달 차단·자동 저장을 검사했다. 1920×1080 비교 화면도 검토했다. 기본 덱 UI 33개·상인 UI 27개·야영지 UI 48개 검사도 통과했다. Windows 실행 검증은 별도다.
