# 튜토리얼 입력 제한·스테이지 카드 이동

2026-10-20 사용자: 튜토리얼은 지정 버튼 외 누르지 못하게,지역 내4×2격자는 화살표로 연결한 카드 가로 스크롤로 변경하고 한 번에4개 표시. 수정·main 반영만,새 빌드 요청 아님.

## 튜토리얼

- `scripts/ui/tutorial_input_gate.gd`: 전체 포인터 shield,`TutorialUI.input_targets`의 현재 Control 영역에만 동적으로 구멍을 낸다. 부모 clip 영역과 카드의 자체 hit 영역도 확인한다. 외부 클릭·휠 차단,금지 버튼 tooltip도 열리지 않음.
- `tutorial_ui.gd`: 정보 단계는 다음/연습 나가기,전투 단계는 지정 카드·턴 종료·포획,야영은 휴식 또는 강화 열기→선택 가능한 카드/카드 스크롤→강화 확정만 허용. 닫기/취소/설정/가방·다른 메뉴는 차단. 키보드도 Tab은 허용 버튼 사이만,Enter/Space는 허용 포커스 버튼만,C는 포획 단계/Enter는 종료 단계만. Esc 연습 나가기·F11 전체화면은 유지.
- 강화 선택/확정에서도 안내·테두리를 표시한다. 완료 화면의 홈/스타팅 선택은 허용한다. 기존 `tutorial_battle_view.gd`/`tutorial_camp_view.gd`의 실제 행동 허용 검사도 유지. 실제 원정은 채택/변경하지 않는다.

## 이동 카드

- `journey_stage_strip.gd`: ScrollContainer,카드260×280/간격50/viewport1190×312. 4카드+3간격=1190. 같은 지역 전투8개(리그5개)를 기존순서 그대로 배치하고 사이마다→. 진행/완료·레벨·야영/챔피언 정보·보스 전술 tooltip/희귀 정체 숨김 유지.
- `tactical_journey_ui.gd::_map`: 가로 스크롤바·좌우4개 이동 버튼,현재 스테이지가 포함된4개 구간으로 자동 스크롤. 끝에서 버튼 비활성. 기존 실제 이동 버튼/다음 전투 준비/지역 배지 요약 유지. 경로/난수·단계는 화면 탐색으로 바뀌지 않는다.
- 게임코드 `.uid` 포함,새 에셋·배경 좌표·데이터 JSON/경제·저장/버전·workflow 불변. PLAY_GUIDE 반영.
