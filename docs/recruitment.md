# 포획 후 합류 미리보기

포획 정산 후 **합류할 기술 카드 확인** 또는 **동료와 교체 확인**을 누르면 편성을 확정하기 전에 덱 변화를 확인한다. 빈자리가 있으면 합류, 세 마리가 있으면 선택한 동료와 교체한다.

- 새 동료의 스프라이트·레벨·HP, 교체 대상과 현재/합류 후 덱 장수를 표시한다.
- **추가되는 카드**에는 실제 배운 기술의 카드 얼굴·비용·효과·소유 포켓몬을 표시한다. 기존 합류 규칙대로 알려진 기술당 한 장이며, 기술이 하나면 같은 기술 두 장을 넣는다. 미리보기만으로 기술을 새로 배우거나 카드 UID를 발급하지 않는다.
- **빠지는 카드**에는 떠나는 동료 소유의 모든 카드와 연결된 부상을 표시한다. 실제 강화 상태를 유지하며 길어지면 가로 스크롤로 확인한다. 공용 카드와 다른 동료의 카드는 남긴다.
- 떠나는 동료의 지닌 물건은 가방에 반환하며 화면에서 이름을 알려 준다. 빈자리에 합류할 때는 기존 동료·장비·카드가 빠지지 않는다.
- **이 편성으로 합류**만 실제 파티/덱 변경과 자동 저장을 실행한다. **목록으로**, 닫기, 바깥 클릭, Esc는 포획한 동료를 대기 상태로 남기고 자원·난수·경험치·카드를 바꾸지 않는다. 목록에서 다른 교체 대상을 다시 비교하거나 풀어줄 수 있다.

포획 시 이미 볼·에너지를 소비하고 [스타팅 해금](capture-unlocks.md)을 기록한다. 미리보기 취소나 방출은 이를 취소하거나 다시 청구하지 않는다. 미리보기 창 자체는 저장하지 않으며, 재실행하면 저장된 포획 합류 선택으로 돌아온다. 이전 v3 저장도 같은 대기 동료를 그대로 확인한다.

## 초반 영입 비교

개발용 [원정 비교 도구](balance-measurements.md)에 `--recruitment off,early`를 추가했다. `early`는 첫 바이옴의 일반 야생에서 최대 두 번 실제 포획을 시도한다. 같은 진화 계열은 피하고 빈자리를 채우며, 가득 차면 현재 능력치·기술 평가가 최약 동료보다 15% 이상 높을 때 교체한다. 야생 하나당 세 턴 뒤에는 일반 전투 정책으로 돌아온다. 현재 평가에 따른 제한된 정책으로, 미래 진화·덱 조합·상성의 최적 판단은 아니다.

볼·에너지·HP 조건은 실제 규칙을 따르고 파티·레벨·경험치·보상을 강제로 수정하지 않는다. 포획 전후 카드 선택과 정산 경험치 때문에 실제 영입 없이도 두 정책의 결과가 달라질 수 있다. 게임에 자동 포획 기능이나 첫 지역 포획 횟수 제한을 추가한 것은 아니다.

## 검증

Godot 4.7.2 기준:

```bash
godot --headless --path . --script res://tests/test_recruitment.gd
godot --headless --path . --script res://tests/test_recruitment_ui.gd
python3 tools/test_recruitment_process.py
python3 tools/test_campaign_report.py
# DISPLAY와 XTest가 있는 환경
python3 tools/test_native_pointer.py --probe native_recruitment_probe
```

386종의 실제 초기 기술과 카드 최소 두 장, 미리보기 순수성·강화·부상·반환 장비·빈자리·방출·실제 확정·저장 일치를 검사한다. UI 검사의 HP 경계·장비·긴 제거 목록은 명시적인 테스트 상태다. 별도 프로세스 검사는 종·HP·자원을 조작하지 않고 시드 2026의 첫 지역에서 실제 주뱃 포획과 합류·다음 전투를 진행한다. 측정의 미완료 결과와 수동 밸런스 한계는 비교 도구 문서에 따로 기록한다.

추가/제거 카드 목록은 같은 소유자·강화·내용의 사본을 겹친 카드와 `×N`으로 묶어 표시한다. 합류 후 덱 장수와 제거 장수는 모든 실제 사본을 포함한다.
