# 필드·룸과 진영 교환 · 원정 v13

새 원정v13/플레이어 효과5에20개 카드를 보완했다. 기존 안개제거를 확장하고19기술을 더해 **누적390기술**이다. [v10](player-move-cards.md)·[v11](player-move-tactics.md)·[v12](player-move-exchange.md)의 구현을 유지한다. 원작과 차이가 있어도 특징을 살린다는 사용자 기준이며 모든919기술의 원작 고유 효과 완료는 아니다.

접지는 현재 전투 타입·날개쉬기·뿌리박기·중력·충전 공중 상태를 확인한다. 기존 수면/화상 등을 필드 생성만으로 치료하지 않는다. 잠자기는 접지한 사용자의 새 수면을 막는 필드에서 비용 없이 사용 거절한다. 기존에 예약된 하품도 실제 수면 전환 시 필드를 확인하고, 필드 중 새 하품이 예약됐다가 필드가 끝난 뒤 잠드는 우회는 막는다. 신비의부적은 접지와 무관하게 새 상태를 막는다.

그래스필드 회복은 전투 환경 회복이며 카드 회복 감소 유물을 적용하지 않는다. 상대 회복봉인은 유지한다. 고정 피해에는 새 필드/흙놀이/물놀이/진영 피해 배율을 적용하지 않는다. 원작 전체 확률/대상 수/실제 우선도에 의한 턴 순서 변경은 추가하지 않았다.

흰안개는 상대의 능력 감소와 접촉 보호 기술의 감소를 막는다. 자기 껍질깨기의 방어 감소나 능력 교환/흑안개 초기화까지 되돌리지 않는다. 원더룸은 기본 방어/특방 값의 계산 교환이며 단계를 별도로 적용한다. 바디프레스처럼 방어를 공격에 쓰는 계산과 확정 급소·연타도 현재 룸을 반영한다.

코트체인지로 아군에게 넘어온 스텔스록/압정은 다음 교대 때 실제 입장 피해, 독압정은 접지·독 흡수·강철/상태 면역, 네트는 스피드-1을 적용한다. 필수 교대는 기존 규칙을 유지하고, 입장 즉시 기절할 소유자의 기술 자동 교대는 카드/자원/UID/RNG 변경 없이 거절한다. 같은 진영의 이전받은 스텔스록과 상대가 다시 설치한 스텔스록은 중복 피해를 주지 않는다. 고속스핀/킬러스핀과 안개제거는 이전받은 설치도 지운다. 승인 파티/마지막 대표·순차 출전 순서는 유지한다.

v13 자연의힘은 필드가 있으면 10만볼트/에너지볼/문포스/사이코키네시스를 호출하며 필드가 없으면v12 날씨 공격을 따른다. 복사/잠꼬대도 새 필드 공격의 실제 특징을 유지한다. 미스트버스트는 새 자폭기로 분류해 호출 풀에서 제외한다. 호출은 기존 카드 소유자/UID/비용을 유지하며 새 카드를 추가하지 않는다.

## 저장과 호환

`PlayerTechniques`의 효과5가 별도 `PlayerMoveFields`/`player_move_fields_v13.json`을 선택한다. 선택 `field_context`는 공통 필드/지속 시간·룸·놀이·양쪽 진영 기간·이전받은 아군 설치를 보관한다. v12 타입/기본 능력치 문맥과 함께 저장·복원하며 UID 없는 전역 상태의 키/타입/범위/필드-기간 조합을 검증한다.

이번 턴 에너지를 지급할 때의 비교 방향은 선택 `turn_speed_inverted:true`에 따로 저장한다. 같은 턴에 트릭룸을 켜거나 꺼도 지급받은 에너지를 바꾸지 않으며, 현재 룸 상태로 과거 에너지 지급을 잘못 재검증하지 않는다. 전투가 끝나 필드가 지워져도 마지막 턴 지급 사실은 복원 가능하다. 연출 프레임·상태 배지·에너지 툴팁도 해당 지급 시점의 규칙을 사용한다.

동결v10/v11/v12 입력과 엔진, 보스v6~v9/승인137대진138대표·경로/RNG·도감/TM·BGM·배경 좌표·성장/가격/보상은 유지한다. 이전v12 실제 지문 `e96129c17840469e6ef32ed0996be6e535a7cad0f9fd0eb186259c893ac9ac5a`을 수용한다. 게시 후v13 입력도 동결한다. 생성기 `tools/import_player_move_fields.py`는 고정 PokéAPI CSV4종과v10~v12 기반 SHA256을 확인하고20개 오버레이/공격 우선도 목록을 결정적으로 생성한다. 새 이미지나 음원은 없다.

## 남은 범위

매직룸·주술·부유/텔레키네시스·페어리록 등 남은 도구/이동 제한 계열, 변신 전체·특성/PP 조작 등은 여전히 별도 작업이다. 다음은 기존 지닌 물건/공중/교대 규칙 안에서 구현할 수 있는 남은 기술을 각색한다. 실제 창 검사는 기술 작업 뒤 일괄 진행하고 EXE/export/Windows CI는 계속 보류한다.
