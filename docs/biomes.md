# 1~3세대 바이옴과 등장 포켓몬

포켓몬 범위는 관동·성도·호연 원종 386종(#001~386)이다. 현대 타입과 복합타입을 인정하며 지역폼·메가진화는 제외한다. 악타입을 포함한 18개 바이옴 모두 실제 해당 타입의 포켓몬으로 채운다. 전설·환상 21종은 일반 풀과 관장 파티에서 제외하고 별도 이벤트 후보로 분리한다.

아래 출현 콘텐츠는 [정식 원정](full-campaign.md)의 무작위 8개 바이옴 순회에서 사용한다. 개발용 `scenes/art_lab.tscn`에서 각 바이옴의 출현 후보와 관장 6마리 편성을 확인할 수 있다. 자주/가끔/희귀의 종별 상대 가중치는 8:3:1이며 등급 전체 확률을 뜻하지 않는다.

기존 관동 출현 등급은 유지하고, 새 종은 기본형 자주·중간 진화 가끔·최종 진화/아기/신규 스타팅 희귀로 분류한 초안이다. 특정 원작의 서식지와 출현율을 재현하지 않는다. 진화 전후는 서로 다른 종으로 취급한다.

배경은 기존 3개 PNG 아틀라스의 18개 영역을 유지한다. [에셋 출처](../ASSET_SOURCES.md), [출현 데이터](../data/biomes.json), [타입별 관장 파티](gyms.md)를 참고한다. `python3 tools/build_biomes.py`로 카탈로그에서 출현표와 관장 편성을 재생성한다.
