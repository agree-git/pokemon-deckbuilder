# 카드·유물 조합 확장

공용 카드 23종과 부상, 파티 유물 10종, 지닌 물건 6종을 사용한다. 새 전용 게이지 없이 기술의 소유자·교대·드로우·보호막·지속 피해를 연결한다. 아래 수치는 첫 밸런스이며 원정 보상으로 획득한다. 초기 덱은 그대로다.

## 추가 카드

보호막·추가 피해의 기준값은 기존처럼 최대 HP/48로 환산한다. 지속 피해는 대상 적의 최대 HP를 기준으로 한다.

| 카드 | 비용 | 효과 | 강화 |
|---|---:|---|---|
| 교대 엄호 | 1 | 출전 멤버 보호막 6. 이번 턴 기술 카드로 한 번이라도 교대했다면 2장 드로우 | 보호막 10, 조건부 드로우 3장 |
| 집중 지시 | 1 | 다음 공격 추가 피해 5. 출전 멤버가 이번 턴 기술을 2회 이상 사용했다면 2장 드로우 | 추가 피해 9, 조건부 드로우 3장 |
| 소모전 작전 | 1 | 지속: 적의 화상·독·씨앗 매회 피해 기준값 +1 | 비용 0 |
| 보호막 전환 | 1 | 출전 멤버 보호막 전부 소비, 그 수치만큼 적에게 피해 | 비용 0 |
| 독성 캡슐 | 1 | 독 3회 부여, 도구·소진 | 비용 0 |
| 방어 배터리 | 0 | 보호막 6, 도구·소진 | 보호막 10 |

교대 엄호와 집중 지시는 조건을 충족하지 못해도 기본 보호막/추가 피해를 제공한다. 조건부 드로우만 생략한다. 손패에서 ✓와 툴팁의 충족/미충족으로 확인한다. 기술 사용 횟수는 소유자별로 세며 공격 외 기술도 포함한다. 교대했다 돌아와도 해당 턴 사용 횟수는 남는다. 적 교체에도 초기화하지 않는다.

보호막 전환은 **공격 능력치·자속·상성을 적용하지 않고 적 보호막에는 막힌다**. 다음 기술의 추가 피해를 소비하지 않는다. 보호막 0이면 피해 0이다. 공격 후 방어가 남지 않는 대가가 있으므로 예고와 마지막 출전 멤버를 고려한다. 보호막 소비와 피해를 별도 연출 단계로 표시한다.

소모전 작전은 사본마다 중첩하며 해당 전투에서만 유지한다. 아군의 상태 피해·혼란·상태 회수 피해에는 적용하지 않는다. 씨앗은 강화된 실제 HP 피해만큼 살아 있는 시전자에게 흡수한다. 상태 아이콘 툴팁도 강화된 피해를 표시한다.

## 추가 유물

| 유물 | 효과 |
|---|---|
| 릴레이 발전기 | 매 턴 첫 기술 자동 교대 시 에너지 +1 |
| 집중 문장 | 같은 포켓몬이 한 턴 두 번째 기술을 사용할 때 1장 드로우, 파티 전체에서 턴당 한 번 |
| 잔류 시약 | 매 턴 첫 화상·독·씨앗 부여 카드의 해당 상태 지속 횟수 +1 |

발전기는 수동·강제 교대에 발동하지 않으며, 카드 비용을 먼저 지불할 수 있어야 한다. 스피드 에너지 판정과 별도이며 턴 시작 스피드를 다시 계산하지 않는다. 잔류 시약은 기존 상태의 재부여에도 적용하지만, 지속 횟수를 무한 가산하지 않고 카드의 기본 횟수 +1로 갱신한다. 수면·마비·혼란은 제외하며 상태 부여 전에 상대가 쓰러지면 발동을 소비하지 않는다.

## 운영 예

- **릴레이:** 교대 배턴·릴레이 발전기를 얻고 기술로 교대 → 교대 엄호로 방어와 손패 보충 → 다른 멤버 기술. 마지막 멤버로 공격 예고를 받아낸다.
- **에이스:** 한 포켓몬의 기술을 두 번 사용해 집중 문장을 발동 → 집중 지시로 다음 공격과 손패 준비. 스피드 보너스·에너지 팩으로 큰 턴을 만들거나, 추가 피해를 다음 턴까지 남긴다.
- **소모전:** 소모전 작전 → 독성 캡슐/씨뿌리기 등으로 지속 피해. 잔류 시약으로 시간을 늘리거나 상태 회수로 남은 횟수를 즉시 피해로 바꾼다. 회수하면 이후 지속 피해와 흡수는 사라진다.
- **보급·보호막:** 보급 작전·보급 벨트·수호 부적과 방어 배터리로 보호막을 모은다. 적 예고에 따라 보호막을 남겨 막거나 보호막 전환으로 공격한다.

## 선택 보상

첫 공용 카드 후보는 연계 후보가 있다면 **50%는 현재 조합 관련 풀**, 50%는 전체 공용 풀에서 추첨한다. 전체 풀에도 관련 카드가 있으므로 최종 관련 카드 등장률이 정확히 50%라는 뜻은 아니다. 이미 가진 유물·특화 공용 카드·소유 기술의 화상/독/씨앗 효과로 조합을 찾는다. 초기 공용 카드만으로 모든 원정에 같은 보급/방어 조합을 강제하지 않는다.

두 번째 소유 기술 후보와 세 번째 유물/장비/공용 카드 후보의 기본 구조를 유지한다. 공용 카드 후보끼리는 중복하지 않으며 하나만 선택하거나 전부 넘긴다. 엘리트·관장·사천왕은 미보유 유물을 우선 제시한다. 추첨은 시드로 재현하며 화면 재진입·불러오기로 재추첨하지 않는다.

이것은 조합 발견을 돕는 첫 구현이다. 유물과 카드가 항상 함께 나오거나 모든 파티의 강도가 같다는 보장은 없다. 상점 카드 판매·가격·보상 가치와 실제 플레이 지표를 다음 단계에서 조정한다.

## 저장과 검증

v3 저장 형식을 유지한다. 턴 조건과 발동 여부는 기존 `turn_flags`, 소모전은 `powers`에 저장하고 검증한다. 기존 대진·손패·보상 후보는 유지하며 새 보상 추첨부터 확장 콘텐츠가 등장한다. 진행 중 원정을 다시 시작할 필요는 없다.

```bash
source /workspace/.cloud-setup/pokemon-deckbuilder/env.sh
godot --headless --path . --script res://tests/test_build_synergies.gd
godot --headless --path . --script res://tests/test_build_synergies_ui.gd
source /workspace/.cloud-setup/pokemon-deckbuilder/enable-display.sh
LIBGL_ALWAYS_SOFTWARE=1 python3 tools/test_native_pointer.py --probe native_build_synergies_probe
```

규칙 검사는 조건 전후·업그레이드·발동 제한·수동/강제 교대 제외·적 교체·다음 턴/전투 초기화·보호막 소비·상태 강화·디스크 저장/복원과 시드별 보상 접근성을 확인한다. 실제 X11 마우스로 조건 표시·교대·드로우·보호막 전환·지속 작전·상태 적용까지 실행하고 1920×1080 화면을 확인한다. 자동 완주는 회귀 검사이며 조합별 재미나 밸런스 확정을 뜻하지 않는다.
