# 원정 난도 비교 도구

> 이 문서의 기존 60개 결과는 개체값·노력치 제거 이전 규칙의 측정이다. 현재 능력치 공식의 승률로 해석하지 않는다. 새 규칙은 별도 코드 지문으로 재측정해야 한다.

고정 시드에서 스타팅 파티와 보상/상점의 선호 주제를 비교한다. [현재 60개 측정 결과](measurements/campaign-balance.md)와 [원본 JSON](measurements/campaign-balance.json)을 함께 보관한다. 첫 표본은 세 시드뿐이며 자동 전투 정책의 편향을 포함한다. 사람의 승률이나 모든 파티의 밸런스 확정을 뜻하지 않는다.

## 실행

Godot 4.7.2와 Python 표준 라이브러리만 사용한다. 게임용 저장과 분리할 때는 실행 명령의 `XDG_DATA_HOME`, `XDG_CONFIG_HOME`, `XDG_CACHE_HOME`에 측정 전용 임시 디렉터리를 지정한다. 도구는 측정 대상 원정을 세션에 채택하거나 저장하지 않는다.

```bash
# 기본: 15개 파티 × 시드 0/42/2026, 기존 자동 정책
 godot --headless --path . --script res://tools/benchmark_campaign.gd -- --output /tmp/balance-starters.json
# 같은 관동 파티에서 보상/상점 선호 주제 5개 비교
 godot --headless --path . --script res://tools/benchmark_campaign.gd -- --parties kanto --styles relay,ace,status,shield,supply --output /tmp/balance-styles.json
# 다른 엔진/규칙/정책이나 중복·미완료 행을 섞지 않고 보고서 생성
 python3 tools/report_campaign_balance.py /tmp/balance-starters.json /tmp/balance-styles.json --json /tmp/balance.json --markdown /tmp/balance.md
```

`--seeds`는 쉼표로 구분한 정수, `--parties`는 아래 식별자, `--styles`는 `baseline,relay,ace,status,shield,supply`를 받는다. 출력 위치는 `--output`으로 지정한다. 빈 선택·알 수 없는 옵션·1000개를 넘는 측정은 거부한다. 출력 파일 작성 실패·불법 행동·100턴/15,000행동 제한으로 중단된 원정·집계 오류는 실패 종료한다. 정상 전멸은 측정 결과이며 완주로 취급하지 않는다.

| 파티 식별자 | 구성 |
|---|---|
| kanto / johto / hoenn | 각 지방 기본 스타팅 세 종 |
| bugs | 캐터피·뿔충이·개무소 |
| babies | 피츄·삐·푸푸린 |
| psychic | 캐이시·랄토스·마자 |
| slow | 알통몬·꼬마돌·뿔카노 |
| ghost | 고오스·무우마·어둠대신 |
| water | 잉어킹·빈티나·루리리 |
| mixed | 이브이·배루키·루브도 |

## 정책과 비교 한계

HP·레벨·경험치·골드·에너지·드로우·보상 난수를 직접 바꾸지 않고 실제 공개 행동으로 진행한다. 세대별 기술 선택·전투 행동은 기존 `CampaignPolicy`를 공유한다. `baseline`은 기존 정책 그대로 휴식·장비·일반 회복약을 사용한다. 주제별 정책은 같은 전투 행동을 유지하며 다음만 추가한다.

- 실제 제시된 보상에서 해당 주제의 카드·유물·지닌 물건을 우선한다. 선호 보상이 없으면 기존 선택 정책을 쓴다.
- 덱이 24장 미만이고 구매 후 100골드가 남으면 상점의 주제 공용 카드 한 장을 구매한다. 이후 레벨업으로 기술 카드가 추가되므로 최종 덱의 상한이 24장이라는 뜻은 아니다.
- 야영지 이벤트·발견을 공개 선택지로 이용한다.

포획·희귀 조사·진화 재료 구매·카드 강화/제거·주제별 최적 전투 AI는 아직 측정 정책에 넣지 않았다. 보조형과 한 마리 편성도 동료를 영입하지 않는다. 따라서 약한 초기 편성이 초반에 탈락하는 결과만으로 전체 난도를 낮추지 않는다. 희귀 포함 파티는 이미 영구 해금한 계정의 반복 플레이를 가정한다.

원정별 완주/전멸·마지막 장소/타입·승리 수·배지·턴·HP 피해·기절·교대·드로우·지출·덱 크기·카드별 사용·유물·레벨을 JSON에 남긴다. 측정 시간·무작위 원정 ID는 넣지 않아 같은 버전·시드·정책의 결과를 그대로 비교할 수 있다. 전투·원정·성장·적·보상 코드와 측정 정책, 데이터에서 SHA-256 지문을 만든다. 저장 호환 버전이 같아도 코드나 데이터가 다르면 보고서를 합치지 않는다. 보고서는 미완료·중복·엔진/규칙/정책/지문 불일치를 거부한다.

## 이번 결과에 따른 적용

기본 스타팅과 희귀 포함 파티는 세 시드에서 완주했으나 보조형·아기·단독 편성은 첫 관장 부근에서 자주 전멸했다. 보상/상점 선호가 있는 관동 파티도 모두 완주했으며 피해·턴·지출·덱 크기는 달랐다. 완주율만으로 전략을 평가하기 어렵다는 첫 근거다. 관동 파티 18개 측정은 최종 유물이 10종으로 같아졌다. 유물 우선 정책의 편향과 작은 공용 유물 풀이 조합을 수렴시키는 가능성도 다음 콘텐츠 조정에서 검토한다.

먼저 [출발 덱·Lv.5 능력치 미리보기](starter-loadout.md)를 추가해 실제 공격 카드·발버둥·기본 능력치를 알린다. 이번에는 종족값·경험치·원작 레벨업 기술·보스 레벨·카드 수치를 바꾸지 않는다. 다음은 초반 포획과 진화 재료/강화/제거를 포함한 정책, 더 많은 시드, 수동 플레이를 함께 비교하는 단계다.
