# 능력·타입 교환과 공격 복사 · 원정 v12

현재 새 원정v13은 필드·룸·진영 교환을 더해 누적390기술이다. [최신 범위/각색/남은 항목](player-move-fields.md)을 먼저 확인한다. 아래 목록은 해당 버전 게시 당시 범위다.

새 원정v12에서30개 카드를 보완했다. 기존 날개쉬기1개를 확장하고29기술을 더해 **누적371기술**이다. [v10 기본 규칙](player-move-cards.md)과 [v11 설치·행동 제한](player-move-tactics.md)을 유지한다. 원작과 차이가 있어도 특징을 살린다는 사용자 기준을 따르며 전체919기술의 고유 효과 완료는 아니다.

## 실제 효과와 각색

| 분야 | 기술 | 카드 전투 동작 |
|---|---|---|
| 능력 단계 | 파워스왑·가드스왑·하트스왑 | 공격/특공, 방어/특방 또는 모든 능력 단계를 양쪽이 교환. 기본 능력치와 구분 |
| 단계 복사·반전 | 자기암시·뒤집어엎기·섀도스틸 | 상대 단계 복사, 상대 단계 부호 반전, 상대 양수 단계를 먼저 훔친 뒤 공격. 섀도스틸 미리보기도 훔친 단계를 반영 |
| 기본 능력치 | 파워트릭·파워셰어·가드셰어·스피드스왑 | 자기 공격/방어 교환, 양쪽 공격/특공 평균, 양쪽 방어/특방 평균, 양쪽 스피드 교환. 단계는 유지하고 실제 피해 계산에 적용. 스피드 변경으로 이번 턴 에너지를 다시 지급하지 않음 |
| 상대 타입 | 물붓기·마법가루 | 상대를 물 또는 에스퍼 단일 타입으로 변경. 풀 타입은 마법가루 면역 |
| 타입 추가 | 핼러윈·숲의저주 | 상대에게 고스트 또는 풀 타입 추가. 최대3타입, 추가 타입은 하나만 유지하고 다음 추가가 이전 것을 교체 |
| 자기 타입 | 미러타입·텍스처·텍스처2·보호색 | 상대 타입 복사, 첫 습득 기술 타입, 직전 상대 공격의 반감/무효 타입, 날씨 대응 타입으로 변경 |
| 타입 소모 | 날개쉬기·불사르기 | 날개쉬기는 회복 후 이번 상대 행동까지 비행 제거. 불사르기는 불꽃 타입일 때 공격하고 성공 후 불꽃 제거. 단일 불꽃은 무타입이 될 수 있음 |
| 상태 전달 | 사이코시프트 | 화상/독/수면/마비 중 자기 주 상태를 상대로 옮긴 뒤 자기 상태 해제. 상대가 이미 주 상태이상이거나 타입 면역이면 자원 소비 없이 거절. 보호·대타 등에 막히면 자기 상태도 유지 |
| 상대 공격 복사 | 흉내내기·따라하기·흉내쟁이·선취 | 상대 직전 공격, 따라하기 플래그 허용 공격, 양쪽 마지막 공격, 다음 예고 공격을 호출. 선취는 피해1.5배 |
| 동료·재사용 | 조수·지휘·스케치 | 살아 있는 다른 동료의 첫 적격 습득 공격, 자기 직전 공격, 처음 복사한 공격을 호출. 스케치는 전투 중 고정/소진이며 영구 습득 슬롯은 바꾸지 않음 |
| 공개 호출 | 손가락흔들기·자연의힘 | 공개된18타입 공격 순환 또는 날씨에 맞는 공격을 호출. 사용 전에 카드에서 실제 공격을 확인 가능 |

교환/추가된 타입은 자속·상성·접지·타입 상태 면역에 즉시 반영한다. 기본 능력치 변경은 급소·방어 단계 무시 공격과 NPC의 연타 계산에도 유지한다. HP·종·폼·스프라이트는 바꾸지 않는다. 교대하는 포켓몬의 타입/기본 능력치는 원래대로 복구하고 전투 종료 시 양쪽 모두 복구한다. 능력 단계는 기존 교대/인계 규칙을 따른다.

텍스처2는 노말→불꽃→물→전기→풀→얼음→격투→독→땅→비행→에스퍼→벌레→바위→고스트→드래곤→악→강철→페어리 순으로 현재 타입과 다른 첫 반감/무효 타입을 선택한다. 공격 기록이 없거나 무타입 발버둥이면 거절한다. 보호색은 비=물, 쾌청=불꽃, 눈=얼음, 모래=바위, 그 외=노말이다. 날개쉬기의 비행은 다음 아군 턴 에너지 비교 전에 복구한다.

공격 복사는 충전/재충전·자폭·복사·반격·일격기·목숨걸기를 제외한다. 현재 사용자의 능력치와 원래 복사 카드 비용/소유자/UID/강화를 사용하고 호출용 카드를 추가하지 않는다. 복사한 공격의 흡수·반동·연타·구속·단계 훔치기 같은 구현된 특징은 유지한다. 변화 기술까지 무제한 호출하거나 원작의 영구 기술 습득을 재현하지 않는다. 지휘는 자기 직전 공격 반복으로 각색했다.

손가락흔들기는 시드/사용자UID/사용 횟수의 공개 순환이며 미리보기는 횟수나 게임 RNG를 소비하지 않는다. 기본 공격 풀은18타입을 한 번씩 포함하고 실제 사용 시에만 다음 순서로 진행한다. 자연의힘은 비=파도타기, 쾌청=화염방사, 눈=냉동빔, 모래=파워젬, 그 외=트라이어택이다. 별도 지형 시스템은 만들지 않는다.

## 저장과 호환

`PlayerTechniques`가 플레이어 효과1/2/3/4를 분기하고 v12만 `PlayerMoveExchange`/`player_move_exchange_v12.json`을 사용한다. 게시된v10/v11 입력과 엔진은 수정하지 않는다. 선택 `exchange_context`에 타입 원본/현재값, 기본 능력치, 날개쉬기 만료 턴, 직전 기술, 손가락흔들기 횟수, 스케치 기록을 저장한다.

저장 포켓몬 행에는 원래 타입을 남기고 복원 후 별도 문맥에서 전투 타입과 기본 능력치를 재적용한다. 원본 저장 배열을 복원 과정에서 바꾸지 않도록 분리한다. `battle_stats`는 문맥에서 파생되는 전투용 값이며 영구 포켓몬 필드가 아니다. 연출 프레임에는 현재 타입/능력치를 보존한다. UID·타입·단계와 별개인5능력치 범위·턴·기술·횟수·버전을 검증하며 HP/알 수 없는 UID/구 버전 문맥 주입을 거절한다.

이전v11 실제 지문 `efe331c4f45f549b9bba7dc032ae577acca0fff3eebdc0c154cf403e01069d52`을 수용한다. 같은 시드의v11/v12 경로/RNG·미래69전투 정의·승인137대진/138대표는 동일하다. 도감/TM·배경 좌표·BGM·성장/가격/보상은 그대로다. 생성기 `tools/import_player_move_exchange.py`는 동결v10/v11 JSON과 PokéAPI 고정CSV4종의 SHA256을 확인하고 결정적으로30개 오버레이를 생성한다. 새 에셋은 없다. 게시 후v12도 동결한다.

## 남은 범위

변신 전체·특성/PP 조작, 트릭룸의 원작 턴 순서, 코트체인지의 양쪽 필드 교환 등은 단순 카드 변환으로 남는다. 타입/능력 변경과 공격 복사를 구현했다는 것이 이들 원작 시스템까지 완성했다는 뜻은 아니다. 다음은 남은 필드·시간 규칙을 카드 전투에 맞게 각색하는 단계다. 실제 창 검사는 기술 작업 뒤 일괄 진행하고 EXE/export/Windows CI는 계속 보류한다.
