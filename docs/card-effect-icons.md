# 카드 효과 아이콘과 설명

아이콘은 수치와 효과를 찾는 보조 수단으로 쓴다. **아이콘과 같은 뜻인 명칭은 반복하지 않고, 대상·동작·조건·지속 시간은 카드 자체에서 읽을 수 있게 남긴다.** 범례나 툴팁을 외워야만 의미를 알 수 있는 기호 나열로 줄이지 않는다. 손패·덱·남은/버린/소진 더미·보상·상점·출발 덱·강화/제거·기술 비교에서 같은 카드 얼굴을 사용한다.

예를 들어 카드에는 ‘상대에게 독 아이콘 3턴 부여’, ‘자신 방패 아이콘 +8’처럼 표시한다. ‘독 아이콘 독’, ‘방패 아이콘 보호막’처럼 이름을 덧붙이지 않는다. 소모전은 상태 아이콘들을 유지하면서 **지속 피해 발생 시·적 최대 HP 기준·추가·전투 내 유지** 관계를 복원한다.

## 과도한 축약 수정

| 카드 | 복원한 설명 |
|---|---|
| 독성 캡슐·상태 기술 | 상대에게 독 등 상태를 부여한다는 사실, 지속 시간(예: 3턴), 사용 후 이번 전투에서만 제외된다는 설명 |
| 소모전 작전 | 적의 화상·독·씨앗 지속 피해가 발생할 때 적 최대 HP의 2.1%를 추가하며, 이번 전투 동안 유지 |
| 상태 회수 | 적 화상·독·씨앗을 제거하고 남은 횟수 1회마다 적 최대 HP의 8.3% 피해, 상성 무시 |
| 재정비 | 버린 더미의 가장 최근 기술 카드 1장을 손패로 가져오기 |
| 작전 변경 | 남은 손패 모두 버리기 → 버린 수만큼 뽑기, 강화 추가 드로우 |
| 대기 지시 | 비용이 가장 높은 카드 1~2장을 다음 턴까지 보존 |
| 교대 엄호·집중 지시 | 이번 턴 기술을 통한 교대/출전 멤버의 기술 2회 조건, 조건부 카드 뽑기 |
| 보호막 전환 | 자신의 보호막 전부 소비, 같은 수치 피해, 상성 무시·적 보호막 적용 |
| 릴레이·보급·에이스 지속 작전 | 발동 조건, 대상·HP 비율 또는 다음 턴 위력, 전투 내 유지 |
| 회복·보호막·추가 피해 | 자신/다음 공격, 실제 미리보기 수치 또는 자신 최대 HP 기준 |
| 부상 | 기절 시 덱에 추가, 사용 효과 없음, 야영지 휴식으로 제거 |

소진 기호 뒤에는 이름을 반복하는 대신 **‘이 전투에서만 제외’**라고 설명하고, 툴팁에도 사용 후 제외됨을 명시한다. 공격·방어·특공·특방·스피드 변화는 기호 옆에 자신/상대·단계를 표시한다. 방어 약화는 실제 전투 규칙인 3턴을 얼굴과 툴팁에 표시한다.

카드의 크기·겹침·호버 입력 범위는 유지한다. 일러스트 영역을 중앙 60px로 정리해 효과 영역을 162×108로 넓혔다. 포켓몬 초상은 최근접·정수 배율로 맞추며 트레이너 도트 일러스트는 정수 2배율을 유지한 채 기호 중심으로 잘라 표시한다. 긴 설명을 무작정 작은 글자로 줄이지 않으며 공용 카드 전체의 글자 크기가 14 이상인지 검사한다.

## 아이콘과 수치

- 초록 하트: HP·회복. 빨간 칼: 실제 피해·공격 보정. 파란 방패: 보호막.
- 카드 묶음: 뽑기. 번개: 에너지. X가 있는 카드: 소진. 상태·능력 변화에는 서로 다른 기호를 쓴다.
- 전투 손패의 공격·회복·보호막은 기존 계산된 미리보기 숫자다. 동료가 정해지지 않은 덱 조회의 회복·보호막·추가 피해는 자신 최대 HP 비율이며, 기술의 **위력**은 실제 피해로 표시하지 않는다. 위력의 %는 공격 보정이다.
- 사용 직후 결과는 **상대 하트 −3**, **사용자 방패 +3**, **에너지 −1**처럼 증감량을 표시한다. 변화 없는 항목은 숨기고 HP 바의 예측 구간을 유지한다.

전투 HP·보호막 HUD, 능력/상태 칩, 피해·회복·보호막 부유 숫자에도 같은 기호를 쓴다. F1 또는 상단 도움말에서 범례를 볼 수 있으며 전체 한국어 규칙은 카드 툴팁에도 남긴다.

`CardEffectText`는 표시 모듈이다. 전투 규칙·저장·난수·경험치·사용자 배경 좌표를 바꾸지 않는다. 새 상태/능력 SVG는 저장소에서 작성한 도트 도형이며 승인된 18개 타입 배지를 유지한다.

## 검증

- `tests/test_card_effect_icons.gd`: 기본/강화 기술·공용 카드와 전투 조회값 총 780개 얼굴, 설명의 대상·조건·동작·기간, 잘림·공용 카드 최소 글자 크기·비율·상태 기호·툴팁·입력 무시·전투 불변성 및 증감량을 검사한다.
- `tests/native_card_icons_probe.gd`: 실제 X11 포인터로 확대 카드의 설명 영역 사용·도움말을 확인하고 전투/카드 모음 2장/범례를 촬영한다.
- 기존 손패 겹침·출발 덱·덱/더미·빌드 연계를 함께 검사한다. Windows 실행·사람 밸런스 검증은 별도다.
