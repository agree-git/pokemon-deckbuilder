# 카드 효과 아이콘

카드의 반복 효과를 아이콘과 숫자로 표시한다. 손패·덱·남은/버린/소진 더미·보상·상점·출발 덱·강화/제거·기술 비교에서 같은 카드 얼굴을 사용한다. 조건·대상·단계 등 의미를 정하는 짧은 단어와 전체 한국어 툴팁은 유지한다.

- 초록 하트: HP·회복. 빨간 칼: 실제 피해·공격 보정. 파란 방패: 보호막.
- 카드 묶음: 뽑기. 번개: 에너지. X가 있는 카드: 소진. 에너지와 소진은 다른 모양이다.
- 화상·독·씨앗·수면·마비·혼란은 서로 다른 상태 기호와 남은 횟수를 쓴다. 타입 배지와 상태 아이콘을 구분한다.
- 능력 변화에는 공격·방어·특공·특방·스피드·전 능력 아이콘과 자신/상대·단계를 표시한다.
- ‘교대 후’, ‘기술 2회 후’, ‘다음’, ‘모두 소비’ 같은 조건은 남긴다. 충족한 조건에는 ✓가 나타난다.

전투 손패의 공격·회복·보호막은 기존 계산된 미리보기 숫자를 사용한다. 포켓몬이 정해지지 않은 덱 조회의 회복·보호막·추가 피해는 최대 HP 비율이며, 기술의 **위력**은 실제 피해로 표시하지 않는다. 공격 보정의 %는 위력 증감이다. 상대 HP를 기준으로 하는 소모전·상태 회수에는 ‘적’을 남긴다.

사용 직후 결과는 **상대 하트 −3**, **사용자 방패 +3**, **에너지 −1**처럼 변화량으로 표시한다. HP 8→5 계산을 읽게 하지 않고 변화가 없는 HP·보호막·에너지는 숨긴다. 다음 적 공격은 예고 값이며 자원 변화와 구분한다. HP 바의 피해/회복 구간 표시는 유지한다.

전투 HP·보호막 HUD, 능력/상태 칩, 피해·회복·보호막 부유 숫자에도 같은 기호를 쓴다. F1 또는 상단 도움말에서 기본/상태/능력 기호 범례를 볼 수 있다. 카드 전체 설명은 마우스를 올려 확인한다. 원정 기록·상점의 복잡한 유물 설명 등 모든 문장을 무조건 기호로 바꾸지는 않는다.

`CardEffectText`는 구조화된 카드 조회값을 표시할 뿐 전투 규칙·저장·난수·경험치·사용자 배경 좌표를 바꾸지 않는다. 짧은 효과는 크게 표시하고 긴 효과는 카드의 162×60 영역에 맞춰 줄·글자 크기를 조정한다. 아이콘 자식은 마우스 입력을 가로채지 않는다. 새 상태/능력 SVG는 저장소에서 작성한 도트 도형이며, 승인된 18개 타입 배지는 유지한다.

## 검증

- `tests/test_card_effect_icons.gd`: 기본/강화 기술·공용 카드와 전투 조회값 총 780개 얼굴, 잘림·비율·상태 기호·툴팁·입력 무시·전투 불변성 및 증감량 검사를 실행한다.
- `tests/native_card_icons_probe.gd`: 실제 X11 포인터로 확대 카드 사용·도움말을 확인하고 전투/카드 모음/범례를 촬영한다.
- 기존 손패 겹침·행동 미리보기·출발 덱·적/보스 전술·연출 검사를 함께 실행한다. Windows 실행 검증은 별도다.
