# 화면과 전투 연출 설정

시작 화면 오른쪽 위의 톱니바퀴, 전투의 `Esc → 설정`, 야영지 등 원정 화면 오른쪽 위의 톱니바퀴에서 같은 설정창을 연다. 닫기 버튼이나 Esc로 이전 화면에 돌아간다.

![1920×1080 설정창](images/settings.png)

| 항목 | 선택과 적용 범위 |
|---|---|
| 화면 | 창 모드 / 최대화 / 전체 화면. F11로 전체 화면과 창 모드를 전환한다. 창 모드는 1280×720을 기본으로 디스플레이에 맞춰 조절한다. UI 기준은 계속 1920×1080이며 다른 화면 비율에서도 비율과 입력 좌표를 유지한다. |
| 전투 연출 속도 | 1 / 1.5 / 2배. 트레이너 등장·포켓볼 교대·공격·기술 효과·카드 이동·피해 숫자의 재생 속도다. 공격 → 피해 → 다음 행동의 순서를 유지한다. 손패 호버·메뉴·장소 이동의 속도는 그대로다. |
| 전체 음량 / 효과음 음량 | 각각 0~100%. 클릭·드래그와 좌우 화살표로 조절한다. 기본 전체 75%·효과음 80%다. |
| 음소거 / 효과음 듣기 | 즉시 음소거하고 현재 재생을 멈춘다. 미리 듣기로 현재 음량을 확인한다. 음소거 또는 음량 0이면 미리 듣기를 비활성화한다. |
| 피격 흔들림 | 켜짐 / 꺼짐. 켜면 포켓몬 피격 움직임과 짧은 전장 흔들림을 표시한다. 끄면 이 흔들림을 생략하고 공격 동작·기술 효과·피해 숫자·HP 변화는 표시한다. |

선택 즉시 적용하고 `user://settings.cfg`에 저장한다. 다음 실행 때 복원하며 원정·도감 저장과 분리한다. 저장 실패 시 현재 실행에는 적용하고 설정창 아래에 안내와 `다시 저장` 버튼을 표시한다. 형식이 잘못된 값은 해당 항목의 기본값으로 돌아간다. 새 설치의 화면·연출 기본값은 최대화·1배·피격 흔들림 켜짐이다. 오디오 항목이 없는 기존 파일에는 음량 기본값을 적용한다.

설정창을 열고 닫거나 옵션을 바꿔도 카드·자원·난수·전투 결과가 변하지 않는다. 창 뒤의 클릭과 카드/교대/턴 종료 단축키를 차단한다. 설정창에서 Esc를 눌러도 원정에서 이탈하거나 뒤에 있던 메뉴까지 닫지 않는다.

## 개발과 검증

`scripts/preferences.gd`는 자동 로드되는 환경설정 서비스다. `scripts/ui/settings_panel.gd`는 세 화면이 공유하는 모달이며 전투 모델을 참조하지 않는다. `UiMotion.combat()`으로 전투 Tween과 단계별 재생의 동일 배율을 맞추며 기술 VFX도 동일 배율로 실행한다. `Engine.time_scale`이나 전투 규칙을 바꾸지 않는다.

```bash
godot --headless --path . --script res://tests/test_settings.gd
godot --headless --path . --script res://tests/test_settings_ui.gd
# 같은 격리된 user 디렉터리에서 별도 프로세스로 저장/시작 복원 검사
godot --headless --path . --script res://tests/test_settings_restart.gd -- --write
godot --headless --path . --script res://tests/test_settings_restart.gd -- --read
# 실제 X11 창과 OS 포인터/키보드
python3 tools/test_native_pointer.py --probe native_settings_probe
```

Linux / Godot 4.7.2에서 환경설정 32개·설정 UI 헤드리스 29개·실제 X11 33개(27클릭), 별도 프로세스 시작 복원을 통과했다. 780개 카드 얼굴의 기존 아이콘 검사와 단계별 전투 연출 헤드리스 28개·실제 X11 28개도 통과했다. 실제 창 검사는 창 관리자가 동작하는 X11 환경이 필요하다. Windows 내보내기와 실제 Windows 창 전환은 별도 검증 대상이다. [전투 효과음](audio.md)과 음량·음소거를 지원하며 배경 음악은 후속 작업이다.
