# 플라스마샤워·송전·분진 · 원정 v20

새 원정v20/플레이어 효과12에3개 기술을 보완해 누적426개다. 기존v1~v19 입력/전용 엔진은 동결한다. NPC 대진/기술·실제 포켓몬 타입·명중/행동 순서 체계는 바꾸지 않는다.

| 기술 | 카드 각색 |
|---|---|
| 플라스마샤워569 |이번 상대 행동 종료까지 양쪽의 노말 기술을 전기로 변환. 사용자의 교대/다른 소유자 카드에도 유지. 발버둥165의 타입 없는 피해는 제외 |
| 송전582 |이번 상대의 다음 기술 타입을 전기로 변환. 다음 상대 행동 또는 대상 교대/기절에 해제. 보호/대타/공중 회피는 원본 플래그에 따라 적용 |
| 분진600 |이번 상대가 불꽃 기술을 쓰려 하면 기술을 취소하고 상대 최대HP¼ 피해(내림,최소1). 보호/공중 회피·풀 타입에 차단. 원본14번 플래그로 대타는 우회. 비불꽃/수면/봉인 등으로 폭발하지 않아도 상대 행동 뒤 만료 |

타입 변환은 종별 기술 타입/날씨·필드에 따른 타입 결정 뒤에 적용하며 상성/자속/날씨/필드·룸/방어 계산에 변환한 타입을 사용한다. 포켓몬 타입은 그대로다. 필드로 풀 타입이 된 대지의파동은 플라스마샤워로 전기가 되지 않지만 송전은 전기로 바꾼다. 송전으로 불꽃이 전기가 됐다면 분진은 폭발하지 않는다.

분진 폭발 피해는 보호막/대타를 우회한다. 불꽃 기술의 원래 타격·부가효과·반동은 실행하지 않고 NPC의 행동/충전/고정 연속기를 정상 취소한 뒤 기존 승패/다음 상대 판정을 따른다. 불꽃 충전 준비도 기술 사용으로 처리한다. 원작의 특성/방진고글 면역은 이 게임에 없는 시스템이라 추가하지 않았다. 효과는 완료된 상대 행동 단계 기준이며 새 행동 순서를 만들지 않는다.

## 코드와 저장 계약

- `scripts/tactics/player_move_reactions.gd` / `data/player_move_reactions_v20.json`;선택 `reaction_context={plasma,electric,powder}`. 전역 bool과 대상UID별 true 표시. 다음 상대 행동에 전부 정리하고,대상 교대/기절/포획은 대상 표시만 지운다. 시작/전투 종료에도 정리한다.
- 플레이어는 `TacticalBattle.card_view`의 종별 타입 결정 뒤 `card_type`을 적용한다. 일반 상대는 기본 피해 계산 전 타입을 바꾼다. NPCv4는 `BossEffects.preview`의 새 효과 분기로 연결한다. 이전 효과 경로는 유지한다.
- `player_move_reaction_math.gd`는 동결 보스v9 미리보기/공중 필드의 상대 피해·주술/소지품의 애로 피해4함수를 파생한다. 조건부 타입과 필드 타입 결정 뒤 변환을 추가하고 실제 기술ID·나머지 규칙은 유지한다. `tools/derive_player_reaction_math.py --game-dir .`가3개 입력 엔진 SHA를 확인한다.
- `PlayerTechniques.enemy_preview`의 마지막에 분진 취소 미리보기를 만들고 실제 상대 행동에서는 기존 실행 대신 폭발/취소를 처리한다. 봉인·수면·실패 기술은 폭발하지 않으며 보호/상성 무효 때문에 불꽃 사용 자체가 취소되지는 않는다. BattleFrame/UI는 분리된 문맥을 사용한다.
- 저장은 기존 선택 문맥을 유지하며 새 문맥은 효과12에만 허용한다. 생성기 `tools/import_player_move_reactions.py --game-dir . --csv-dir /path/to/csv`는v19 기반 SHA와v10→v19 체인/고정CSV4종 SHA를 확인한다. 임시 보호막5를 제거하고 강화는 비용-1로 처리한다.

## 최소 검사와 다음 작업

`tools/check.py --suite player-reactions`는 `tests/test_player_move_reactions.gd` 한 스크립트다.3개 순수 미리보기/강화,양쪽 노말/비노말·발버둥·소유자 교대·상성/필드,일반/NPC 송전과 분진·취소/반동 없음·기상 전 미폭발·원본 대타 우회/풀 면역·기절 정리,새 실제 저장/동일 다음 입력·기존 멸망/조준 문맥·분리된 연출·오염 거절·v19 저장/지문을 묶는다. 사전 실제v19 체크포인트가 `/tmp/player-v19-before.bin`에 있으면 함께 확인하며 없으면 생략한다. 전체919기술/전체 suite/전체69전은 반복하지 않는다. 실제 창/native/X11·EXE/빌드는 계속 보류한다.

목록 밖493기술에는 기본 공격/부가효과도 포함한다. 임시 보호막5 변화 기술33개가 우선 후속 대상이다. 다음은 경혈찌르기·승리의춤·농성·파워시프트 등 능력 강화/교환을 검토한다. 새 특성/PP·전투 전용 변신 전체는 자동 추가하지 않는다.
