# 상대 레벨과 진화 단계

v28 원정은 새 전투를 만들 때만 출현 후보를 같은 계열의 적정 단계로 되돌린다. 이미 저장된 전투는 교체하지 않고 다음 새 전투부터 적용한다. v27 이하의 미래 상대는 이전 동작을 유지한다. 사용자 요청으로 새 버전/EXE/export/Windows CI/Release는 계속 보류한다.

- `scripts/tactics/enemy_evolution.gd`: 전국도감 진화644분기의 역방향 그래프. 각 경로의 수치 레벨 조건과 앞단의 최소 레벨을 함께 확인한다. 직접 진화 간선이 없는 주인/성별 등 상시폼은 같은 도감번호·지역폼의 간선을 공유한다. 난수를 사용하지 않는다.
- `CampaignRoute.opponents(step,true)`: 실제 전투에 사용할 종을 먼저 결정한 뒤 이름/타입/HP/일반 전술/관장 전술/난도 보호막을 생성한다. 이전 단계는 최종 대표 전용 기술을 이어받지 않고 기존 관장 역할 전술을 사용한다. 적정 레벨의 대표는 전용 기술 그대로다.
- `TacticalJourney.restart`와 `opponents_at`: v28만 위 옵션을 켠다. 원본 출현표/승인 파티/대표 마지막 자리/경로 signature/캠프/RNG/전투 레벨/경험치는 변경하지 않는다. 파티 원본에 최종 진화체가 남아 있는 것은 저장 경로 재현을 위한 설계다. 실제 표시·울음·포획은 생성된 적의 종을 따른다.
- 돌/통신/친밀도 등 자체 레벨 제한이 없는 조건에 가상의 제한을 만들지 않는다. 단, 니드퀸/팬텀/자포코일처럼 앞 단계에 필요한 수치 레벨은 확인한다. 높은 레벨의 미진화 포켓몬을 강제 진화시키지는 않는다.
- 희귀 조우103종은 최초 예약 가능 지역+기존 보너스 레벨이 모두 진화 최소 레벨 이상이다. 약속된 목표/단서/포획 조건을 바꿀 필요가 없다.
