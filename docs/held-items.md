# 원작 지닌 물건 · 원정 v21

현재 작업은 이 문서의 계약과 해당 효과 코드부터 읽고,아래55종 표는 필요한 물건 이름으로 검색한다. 기술 작업은 별도 [기술 지도](tasks/moves.md)다.

## 적용 범위와 각색

새 원정v21/플레이어 효과13에서 원작 지닌 물건55종을 보상/야영 장착/전투/UI/저장에 연결했다. 기존6종은 이전 원정의 획득/RNG/효과를 위해 보존하고 새 보상에는 제시하지 않는다. 기술 특징 보완은426종 그대로이며 새 기술을 추가한 버전이 아니다. 원작 전체 지닌 물건을 모두 구현한 것은 아니다.

- 소모성 물건은 원작처럼 사용 후 영구 소모한다. 다시 얻어 장착해야 하며 기절 멤버를 부활시키지 않는다. 베리/띠/보험/허브/내던지기의 소비물을 리사이클로 복구하면 영구 소비도 취소한다. 원 소유권/교환은 전투 종료에 복구하되 이미 소모된 원본 물건은 복구하지 않는다.
- 매직룸/금제/장비 제거 중에는 새 효과도 꺼진다. 구애 도구는 소유자별 첫 기술만 허용하고 교대에 고정을 해제한다. 돌격조끼는 자신의 변화 기술 카드만 막고 공용 훈련가/도구 카드는 허용한다.
- 능력치는 원작 배율을 계산에 적용한다. 스피드는 기존 에너지 우대 비교에 반영하며 새 행동 순서를 만들지 않는다. 아이템은 실제 포켓몬 타입을 바꾸지 않는다. 진화의휘석은 실제 남은 진화 경로,전용 도구는 도감번호로 지역/상시폼을 포함해 판정한다.
- 회복에는 기존 회복 감소 유물/회복봉인을 적용한다. 턴 종료 효과는 출전 멤버만 받는다. 기합의띠는 HP가 가득 찬 직접 타격에만 발동하고 연타 후속타는 막지 않는다. 울퉁불퉁멧은 HP 피해를 준 접촉 타격마다 반응하며 공격자 기절 시 남은 타격/부가효과를 중단한다.
- 생명의구슬은 보호/타입 무효/완전 보호막 흡수에는 반동을 주지 않고,실제 HP 또는 대타를 타격한 공격 뒤 한 번 반동을 준다. 조개껍질방울은 과잉 피해가 아닌 실제 HP 피해를 기준으로 회복한다. 고정 피해 기술의 고정 수치는 강화하지 않는다.
- 화상/독은 기존 지속 횟수 체계를 사용한다. 맹독구슬은 별도 맹독 누적 단계를 새로 만들지 않고 기존 독을 건다. PP/명중·급소 추첨/특성/전투 전용 폼을 요구하는 물건과 아직 효과를 연결하지 않은 풍선/통굽부츠/탈출버튼/레드카드 등은 획득 목록에 넣지 않았다.
- 내던지기는 실제 물건의 위력(강화+15)을 쓰며 던진 물건의 자기 능력 보정은 적용하지 않는다. 포함된 베리/하양허브와 화염구슬/맹독구슬/독바늘/전기구슬의 대상 효과도 연결한다. 클리어참은 최신 CSV에 빠진 효과/위력30의 별도 참조를 기록했다.

## 코드와 저장 계약

- `scripts/tactics/held_items.gd` / `data/held_items_v21.json`이 새 원작 효과/목록의 기준이다. `TacticalContent.LEGACY_HELD_ITEMS`는 과거6종,`HELD_ITEMS`는 표시/검증용 합집합이다. `HeldItems.reward_keys(route)`로 버전별 획득 목록을 고른다.
- 선택 `held_context={originals,owners,used,spent,choice}`. 원래 개체UID별 물건,현재 소지자→원 소유자 토큰,영구 소비 토큰,리사이클용 마지막 소비 토큰,구애 기술을 저장한다. 같은 베리 두 개도 원 소유자별 토큰으로 구분한다. 이전 원정은 새 문맥을 빈 값도 거절하고 새 물건을 과거 item_context에 주입할 수도 없다.
- `held_attack`은 한 카드/상대 행동 중 실제 HP 피해·접촉/명중·전달 전 소유권을 모으는 일시 상태이며 변경 알림 전에 정리하므로 저장하지 않는다. 기존 소지품 복구 후 새 원 소유권/영구 소비를 적용한다. BattleFrame은 새 지속 문맥을 복제한다.
- 피해는 `HeldItems.calculate`에서 원작 공격/방어 배율과 타입별 위력 배율을 적용한다. 공통 버전 분기 외 게시된 전용 엔진/JSON66파일은 그대로다. `held_item_math.gd`는 고정4개 입력의11함수를 파생해 원작 도구 계산과 접촉 기절 중단/실제 피해 추적만 연결한다. 생성기 `tools/derive_held_item_math.py --game-dir .`가 입력 SHA를 확인한다.
- `tools/import_held_items.py --game-dir . --cache-dir /path/to/cache`는 고정CSV3종과55개 PNG를 확인한다. 원본 CSV/수집 캐시는 게임 밖에 보관한다. UI는 기존 장착 선택기에 원작 아이콘/줄바꿈·전체 설명을 연결하며 소모품이 되돌아오지 않음을 표시한다.

## 최소 검사와 다음 단계

`tools/check.py --suite held-items` 한 스크립트로55종 순수 미리보기/현지화/그림,효과 계열·실제 피해,구애/조끼의 원자적 거절,단발/연타·양쪽 접촉 기절/생존,영구 소모/리사이클·교환/동일 베리 토큰·매직룸/금제·내던지기,실제 새 저장/동일 다음 입력/소모 유지·장착·이전v20 실제 저장을 확인한다. 사전 저장 `/tmp/player-v20-before.bin`이 있으면 해당 복원/오염 거절 사례도 검사한다. 실제 창/native/X11·EXE/빌드는 계속 보류한다. 전체919기술/전체69전은 반복하지 않는다.

후속 물건 후보는 풍선·통굽부츠·탈출버튼·레드카드처럼 접지/입장/강제 교대와 연결되는 계열이다. 새 버전에서 확장하고 현재55종/원 소유권 토큰·소모·기존 저장을 보존한다. 기술의 경혈찌르기·승리의춤·농성·파워시프트 등은 대기 중이다.
