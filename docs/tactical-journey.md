# 전술 전투의 햇살숲 원정

F5 기본 실행은 **전투 3회·휴식 2회, 총 5개 장소**의 짧은 원정이다. 고정 기술·트레이너 카드·브레이크 규칙을 전투 사이의 성장과 연결한다. 마지막 풀타입 체육관을 이기면 레인보배지 1개를 받고 이 짧은 원정을 끝낸다. 정식 8개 바이옴과 리그 완주는 후속 개발이며, 여기의 승리는 챔피언 등극이 아니다.

| 순서 | 장소 | 진행 |
|---|---|---|
| 1 | 햇살숲 입구 | 뚜벅쵸 → 가디, 기존 시험과 같은 시작 전투 |
| 2 | 숲속 야영지 | 전원 회복 또는 한 마리 훈련 |
| 3 | 체육관 수련자 | 뚜벅쵸 HP44 → 냄새꼬 HP54 |
| 4 | 체육관 앞 야영지 | 전원 회복 또는 한 마리 훈련 |
| 5 | 풀의 체육관 · 민화 | 모다피 → 덩쿠리 → 아라리 → 우츠동 → 라플레시아 → 우츠보트 |

민화의 파티는 관동 원종의 실제 풀타입 6종을 사용한 이 게임의 편성이며 특정 원작 버전의 파티를 그대로 재현하지 않는다. 체력은 순서대로 32·38·36·40·46·54다. 적마다 강공격 → 보호막 → 공격을 반복하며, 브레이크와 연쇄 격파는 기존 전술 시험과 같은 규칙이다.

## 전투 사이의 유지와 보상

파티의 현재 HP·기절·최대 HP, 공용 트레이너 덱과 부상 카드를 유지한다. 보호막·공격력·상태·에너지·빈틈·기술 사용 횟수는 새 전투에서 초기화한다. 살아 있는 이상해씨가 우선 출전하며 기절했다면 살아 있는 멤버를 출전시킨다. 소진은 이번 전투에만 적용하므로 다음 전투에서 전술 정리도 덱으로 복귀한다. 카드 인스턴스 ID를 보존하고 새 카드에는 새 ID를 부여한다.

일반 전투 승리 후 분석·방어 지시·전술 정리·강화 지시·견제 지시 중 서로 다른 세 종류를 시드에 따라 제시한다. 한 장을 원정 덱에 추가하거나 넘긴다. 보상과 전투는 별도 난수 흐름을 사용하며 화면을 다시 열어도 보상은 바뀌지 않는다. 경험치·보상·턴 정산과 마지막 배지는 전투당 한 번만 지급한다. 마지막 체육관은 카드 보상 대신 원정 결과를 표시한다.

휴식은 장소마다 다음 중 한 번만 선택한다.

- **회복:** 파티 전원 최대 HP의 50% 회복(올림, 최대 HP 이내), 기절 부활, 부상 카드 전부 제거.
- **훈련:** 살아 있는 포켓몬 한 마리의 최대 HP와 현재 HP +8. 다음 전투에도 유지.

새 원정의 회복량은 6마리 관장전에 맞춘 시험 수치다. 기존 9개 장소 원정의 회복 30%·진화 규칙은 별도로 유지한다. 새 전투의 포획·진화·네 번째 기술 학습·저장 기능은 아직 연결하지 않았다.

## 화면과 조작

1·2·3 교체, Q·W·E·R 기술, Enter 턴 종료를 유지한다. R은 현재 미습득 네 번째 기술 슬롯이다. 전투 결과에서 `계속 진행`을 누르면 보상 또는 원정 결과로 이동한다. 지도에서 다음 장소로 이동하고 휴식 행동을 선택한다. 지도·보상·휴식·결과 화면에서는 왼쪽에 파티 체력과 원정 덱 버튼, 가운데에 현재 선택지만 표시한다. 덱 확인창이 열려 있으면 뒤의 선택은 차단한다.

- 메뉴의 재시작·특성 변경은 **원정 전체를 같은 시드로 처음부터** 시작한다.
- 원정 결과에서 같은 시드 또는 새 시드로 재도전한다.
- F2: 아트 랩 왕복. 현재 원정 상태를 메모리에 유지한다.
- F3: 기존 9개 장소 원정. F4: 단일 전술 시험과 새 원정 사이 전환. 각 모드는 상태를 별도로 유지한다.
- F11: 전체 화면. 실행을 종료하면 진행 상태는 초기화된다.

## 검증

`TacticalJourney`가 진행·성장·정산, `TacticalJourneyContent`가 경로·관장 편성, `TacticalJourneyUI`가 전투 화면과 단계별 선택 화면을 연결한다. 기존 `RunState`는 변경하지 않았다.

```bash
godot --headless --path . --script res://tests/test_journey.gd
godot --headless --path . --script res://tests/test_journey_ui.gd
# X11 그래픽 세션에서 OS 마우스로 한 판 완주, 실제 1920×1080 화면 캡처
LIBGL_ALWAYS_SOFTWARE=1 python3 tools/test_native_pointer.py --probe native_journey_probe
```

모델 검사는 30개 시드·세 특성으로 90회 원정을 완주하고 체력·덱 유지, 부활·훈련, 잘못된 단계의 행동, 중복 정산·중복 보상·배지 지급을 검사한다. UI 검사는 포인터로 전투 세 번·보상·지도·휴식·관장전·최종 결과·재시작을 연결하고 세 창 크기의 입력과 덱 모달 차단을 검사한다. 자동 전략은 공개 행동만 사용하며 완주 검사에서 체력이나 전투 결과를 조작하지 않는다. 이 결과가 모든 보상·훈련 조합의 난이도를 보장하지는 않는다.
