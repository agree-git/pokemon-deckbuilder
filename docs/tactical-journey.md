# 전술 전투의 햇살숲 원정

이 문서는 **개발용 5개 장소 햇살숲 원정**의 규칙과 회귀 검사다. F5 일반 플레이는 [8개 바이옴과 리그의 정식 원정](full-campaign.md)이다. 이 짧은 경로는 전투 3회·야영지 2회와 민화의 6마리, 배지 1개로 전투·성장·입력을 빠르게 검증하기 위해 보관한다.

| 순서 | 장소 | 진행 |
|---|---|---|
| 1 | 햇살숲 입구 | 뚜벅쵸 → 가디, 한 마리 편성이면 뚜벅쵸만 등장. 포획 가능 |
| 2 | 숲속 야영지 | 휴식·구매·가방·전리품 이용 후 출발 |
| 3 | 체육관 수련자 | 통통코 HP44 → 버섯꼬 HP54 |
| 4 | 체육관 앞 야영지 | 휴식·구매·가방·전리품 이용 후 출발 |
| 5 | 풀의 체육관 · 민화 | 아르코 → 솜솜코 → 로젤리아 → 덩쿠리 → 라플레시아 → 우츠보트 |

민화의 파티는 관동·성도·호연의 실제 풀타입 6종을 사용한 이 게임의 편성이며 특정 원작 버전의 파티를 그대로 재현하지 않는다. 체력은 순서대로 32·38·36·40·46·54다. 적마다 강공격 → 보호막 → 공격을 반복하며, 브레이크와 연쇄 격파는 기존 전술 시험과 같은 규칙이다. 정식 원정에서는 [18개 타입의 관장 파티](gyms.md)와 리그까지 연결한다.

## 전투 사이의 유지와 보상

파티의 현재 HP·기절·최대 HP, 공용 트레이너 덱과 부상 카드를 유지한다. 보호막·공격력·상태·에너지·빈틈·기술 사용 횟수는 새 전투에서 초기화한다. 선택한 첫 번째 포켓몬이 우선 출전하며 기절했다면 살아 있는 멤버를 출전시킨다. 소진은 이번 전투에만 적용하므로 다음 전투에서 전술 정리도 덱으로 복귀한다. 카드 인스턴스 ID를 보존하고 새 카드에는 새 ID를 부여한다.

일반 전투 승리 후 분석·방어 지시·전술 정리·강화 지시·견제 지시 중 서로 다른 세 종류를 시드에 따라 제시한다. 한 장을 원정 덱에 추가하거나 넘긴다. 보상과 전투는 별도 난수 흐름을 사용하며 화면을 다시 열어도 보상은 바뀌지 않는다. 원작의 종별 경험치 곡선에 기본 경험치 400과 스테이지·전투 종류 배율을 적용한다. 현재 경험치는 400·875·1500이며 기절한 멤버는 30%를 받는다. 조건 레벨에 도달하면 자동 진화하고 원작 레벨별 기술을 배운다. 네 기술이 차면 교체하거나 포기한다. [성장과 야영지 규칙](growth.md)을 참고한다. 경험치·보상·턴 정산과 마지막 배지는 전투당 한 번만 지급한다. 마지막 체육관은 카드 보상 대신 원정 결과를 표시한다.

야영지는 휴식·아이템 구매·가방·전리품 탭을 제공한다. 휴식은 방문당 한 번이며 다른 서비스는 자원·재고 내에서 계속 이용할 수 있다. 준비를 마친 뒤 출발 버튼으로 진행한다. 진화는 야영지 행동이 아니다. 이 개발용 짧은 경로는 디스크에 저장하지 않는다. 일반 정식 원정은 [자동 저장과 이어하기](persistence.md)를 지원하며 특수 진화는 후속 단계다.

## 화면과 조작

1·2·3 교체, Q·W·E·R 기술, Enter 턴 종료를 유지한다. 기술 슬롯은 배운 순서대로 Q/W/E/R에 대응한다. 전투 결과에서 `계속 진행`을 누르면 보상 또는 원정 결과로 이동한다. 지도에서 다음 장소로 이동하고 휴식 행동을 선택한다. 지도·보상·휴식·결과 화면에서는 왼쪽에 파티 체력과 원정 덱 버튼, 가운데에 현재 선택지만 표시한다. 덱 확인창이 열려 있으면 뒤의 선택은 차단한다.

- 메뉴의 재시작·특성 변경은 **원정 전체를 같은 시드로 처음부터** 시작한다.
- 원정 결과에서 같은 시드 또는 새 시드로 재도전한다.
- 메뉴 또는 홈 아이콘: 시작 화면 복귀. 같은 실행 중에는 `이어하기`로 현재 원정에 돌아온다.
- F2/F3/F4 개발용 모드 전환은 일반 플레이에서 제거했다.
- C: 포획. F11: 전체 화면. 실행 종료 시 원정 진행은 초기화되며 포획 도감·스타팅 해금은 유지된다.

## 검증

`TacticalJourney`가 진행·성장·정산, `TacticalJourneyContent`가 경로·관장 편성, `TacticalJourneyUI`가 전투 화면과 단계별 선택 화면을 연결한다. 기존 `RunState`는 변경하지 않았다.

```bash
godot --headless --path . --script res://tests/test_journey.gd
godot --headless --path . --script res://tests/test_journey_ui.gd
# X11 그래픽 세션에서 OS 마우스로 한 판 완주, 실제 1920×1080 화면 캡처
LIBGL_ALWAYS_SOFTWARE=1 python3 tools/test_native_pointer.py --probe native_journey_probe
```

모델 검사는 30개 시드·세 특성으로 90회 원정을 완주하고 체력·덱 유지, 부활·상점·가방, 잘못된 단계의 행동, 중복 정산·중복 보상·배지 지급을 검사한다. UI 검사는 포인터로 전투 세 번·보상·지도·휴식·관장전·최종 결과·재시작을 연결하고 세 창 크기의 입력과 덱 모달 차단을 검사한다. 자동 전략은 공개 행동만 사용하며 완주 검사에서 체력이나 전투 결과를 조작하지 않는다. 이 결과가 모든 파티·아이템·기술 선택의 난이도를 보장하지는 않는다.
