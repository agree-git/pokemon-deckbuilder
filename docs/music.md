# 장면별 배경 음악

시작 화면·야영지·일반 전투·관장/사천왕·챔피언에 직접 제작한 배경 음악 5곡을 사용한다. 기존 효과음은 각 행동 시점에 계속 재생한다.

[모바일용 음악 모음 듣기·다운로드](audio/music-preview.mp3) · [원본 PCM WAV](../assets/audio/music)

모음은 아래 순서로 각 곡의 앞 6초를 들려주며 곡 사이에 0.5초를 둔다.

| 곡 | 적용 화면 | 템포 / 루프 |
|---|---|---|
| title | 시작 화면·스타팅 선택·포획 도감·챔피언 등극 화면 | 100 BPM · 19.2초 |
| camp | 야영지·지도·보상·포획 합류·기술 학습·전투 결과 | 84 BPM · 약 22.86초 |
| battle | 야생·일반 트레이너·엘리트 트레이너 | 124 BPM · 약 15.48초 |
| boss | 관장·사천왕의 등장과 전투 | 138 BPM · 약 13.91초 |
| champion | 챔피언 등장과 전투 | 132 BPM · 약 14.55초 |

각 곡은 8마디의 짧은 칩튠이다. 현재는 타입/지방별 변주 없이 위 다섯 장면으로 구분한다. 원작 음악이나 외부 음원을 내려받지 않고 독자적인 선율·화성·리듬을 합성했다.

장면이 바뀌면 **0.55초 동안 이전 곡을 줄이고 새 곡을 키운다.** 음악 플레이어 두 개를 재사용한다. 같은 곡을 다시 요청하는 화면 갱신·메뉴 조회·설정 변경은 음악을 처음부터 다시 틀지 않는다. 빠르게 화면을 바꿔도 마지막 장면의 음악만 남으며 아직 재생 중인 이전 곡으로 돌아갈 때는 그 위치를 활용한다.

승리를 계산한 순간에는 전투 음악을 유지하고, 마지막 공격·기절 연출을 마친 뒤 결과 음악으로 전환한다. 승패/포획 효과음은 그대로 들린다. 첫 출발·장소 이동 중에는 이전 곡을 이어 듣다가 목적지 화면이 준비되면 바꾼다.

![음악 음량 설정](images/settings.png)

[설정](settings.md)의 **음악 음량**은 전체/효과음 음량과 별개다. 기본 음악 55%이며 기존 설정 파일에도 기본값을 적용한다. 음악만 0%로 내려도 효과음은 들린다. 음악 0%·전체 0%·음소거에서는 재생 위치를 일시 정지하고, 다시 켜면 현재 화면의 음악을 이어 듣는다. 음악 음량을 바꾸거나 전투 연출을 2배로 바꿔도 음악의 음높이는 유지한다. 설정은 다음 실행에도 복원한다.

## 제작과 검증

`tools/generate_music.py`가 Python 표준 라이브러리와 FFmpeg로 22.05kHz 모노 소스를 합성하고 PCM WAV 5곡과 MP3 검토용 모음을 만든다. `assets/audio/music/manifest.json`에 템포·길이·원본 PCM·WAV 파일/모음의 지문을 기록한다. 반복 경계에 짧은 페이드를 적용해 파형의 시작과 끝을 0으로 맞춘다. 생성용 난수는 독립된 고정 시드이며 게임 난수에는 접근하지 않는다.

```bash
python3 tools/generate_music.py
python3 tools/generate_music.py --check
godot --headless --path . --script res://tests/test_music.gd
```

`GameMusic` 자동 로드는 미리 로드한 곡과 음악 플레이어 두 개를 유지한다. 루프 설정은 Godot `.import`에 보관한다. `Music → Game → Master`로 보내 음악과 전체 음량을 적용하며 `Effects → Game → Master`의 기존 효과음 경로와 분리한다. 화면은 곡의 키만 요청하고 음악 서비스는 전투/저장/난수를 바꾸지 않는다.

Linux / Godot 4.7.2에서 루프 경계의 실제 재생·빠른 전환·음소거/복원·믹서 출력과 설정 UI를 검사한다. 클라우드는 Dummy 드라이버에서 PCM을 캡처하므로 실제 스피커 청음·Windows 오디오 장치 검증은 별도다. 지역별 분위기 소리·포켓몬별 울음소리는 후속 작업이다.
