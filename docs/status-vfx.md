# 상태이상 이펙트 강화

main `7b3ee86`. **사용자의 최종 지시: 원인은 새 문구로 표시하지 않고 이펙트만 늘린다.** 피해 숫자/배너/상태 배지/전투 기록의 기존 문구와 아이콘은 유지한다. 상태 이름·피해 원인 라벨을 자동으로 추가하지 않는다. 새 버전/EXE/CI/Release는 재요청까지 보류한다.

## 최소 파일 지도

- `scripts/ui/status_feedback.gd`: 상태별 색의 확대 입자/원형 파동/스프라이트 색 반응. 독은 보라색 독방울, 화상은 주황 불꽃, 마비는 노란 전기. 기존 `MoveEffect.draw_status`를1.65배로 재사용한다. 수면/혼란/얼음/씨앗/구속/저주/모래바람도 같은 색 사전을 쓴다.
- `scripts/ui/tactical_ui.gd::_play_event`: 해석된 이벤트/전후 frame만 읽고 효과를 호출한다. 새 상태가 생긴 순간, 실제 상태 피해, 기존 status_tick/weather_tick과 연결된 피해, 씨앗 회복/수면 취소의 효과다. 원래 피해 숫자/배너 로직은 그대로다. 일반 공격은 상태를 갖고 있다는 이유만으로 독·화상 효과를 띄우지 않는다. 비출전 동료의 기존 파티 펄스도 유지한다.
- `scripts/tactics/tactical_battle.gd::_status_hit/_damage`: 기존 상태 피해 이벤트에 **내부 시각용 cause 키**만 덧붙인다. 마지막 tick에서 상태가 지워져도 적절한 입자가 나온다. 선택 인자 기본값은 빈 문자열이며 기존 호출/피해/방어/통계/RNG/로그 문구는 유지한다. 동결된 버전별 엔진/JSON은 수정하지 않았다.

상태 burst는0.65초, 색 반응은0.50초이고 기존 전투 배속을 따른다. `self_modulate`를 써 기존 피격/기술 플래시의 `modulate`와 분리한다. 마지막 입자가 만료될 때도 다시 그려 잔상이 남지 않게 한다. 재시작 시 입자/색 반응/대기 중 상태 문맥을 지운다. 원본 프레임/공격 모션/배경 좌표/기술과 피해 규칙/저장 fingerprint는 유지한다.

구속·날씨는 기존 event 캡션에서 내부 분류만 얻고 해당 대상의 다음 피해에서 한 번 소비한다. 새 원인 텍스트를 생성하지 않는다. 상태 적용은 전후 frame의 동일 UID 상태를 비교한다. 원정이나 전투 RNG는 사용하지 않는다.

## 이번 실제 검사

`tests/native_status_feedback.gd`를 `tools/native_pointer.py`로 실행했다. Godot4.7.2 실제 X11/1920×1080/Dummy, 격리된 XDG 경로다.

- 사용자 정정 후 최종 범위 **32검사/0실패**. 독·화상·씨앗·혼란의 마지막 tick, 정확한 피해량/방어 관통/상태 만료/전투 RNG·기록 문구 보존을 확인했다.
- 독·화상 확대 효과, 마비 적용의 전기/색 반응, 기존 숫자·상태 카운터 유지, 일반 공격 오인 방지, 구속·날씨 문맥1회 소비, 씨앗 회복,2배속/입자와 색 복구.
- 실제 OS Enter로 원래 burn/poison 동시 적용 턴을 진행해 두 효과가 차례로 발동하는지 확인했다. 직접 계산한 기준 원정 snapshot과 정확히 같고, 별도의 실제 원정/저장 바이트/UID·RNG 및 기존 snapshot 복원도 불변이다.
- 독/화상/마비 PNG3장 모두 시각 확인. 적용 상태를 넣은 frame은 시각 검사 fixture이며 실제 저장을 변경하지 않았다. 증거 `/tmp/pokemon-status-feedback/`, 최종 로그 `/tmp/pokemon-status-feedback-final.log` 오류/누수 없음. 기존 소프트웨어 VSync 안내만 있다.
- 초기 검사 파일의 RNG 필드 오타로 실행 전 로드가 실패해 `_rng`로 고쳤다. 이전 원인 라벨 검사는 사용자 정정으로 폐기하고 최종 효과 전용 범위만 한 묶음 실행했다. 전체 UI/919기술/69전투/전종 에셋/모션·오디오 회귀/빌드·패키지 검사는 반복하지 않았다.

다음에는 실제 플레이에서 효과의 크기/색/발동 순간 피드백을 우선한다. 피해 원인 문구나 상태 이름을 새로 붙이는 방향으로 되돌리지 않는다.
