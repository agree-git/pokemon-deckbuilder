# 야영지 카드 제거 확인

상인이 있는 야영지의 **카드 제거**를 누르면 원정 덱을 카드 그림으로 펼친다. 같은 소유자·강화·내용의 사본은 겹친 카드와 `×N`으로 묶고, 강화 카드는 별도로 표시한다. 묶음을 선택하면 그중 **한 장**의 제거 확인 화면이 열린다.

확인 화면에는 선택한 실제 카드, 같은 카드 사본 수·전체 덱 장수·골드의 **현재 → 제거 후** 변화를 표시한다. 다음 전투의 실제 상대별로 통하는 공격·약점 공략·지속/조건부 카드 수의 변화도 보여 준다. 마지막 유효 직접 공격이 사라지면 상대 이름과 붉은 안내를 표시한다. 이것은 현재 파티의 살아있는 동료와 이번 제거 한 장에 대한 상성 비교다. 피해량·승률·이후 회복·학습·영입을 예측하거나 플레이어 대신 결정을 막지 않는다.

**이 카드 1장 제거**를 눌렀을 때만 선택한 카드 ID로 기존 제거 행동을 실행한다. 실제 사본·소유자·강화·연결된 부상은 선택한 한 장을 제외하고 보존한다. 확인 시점에도 상인 여부·방문당 제거 횟수·현재 골드·카드 존재·최소 덱 장수·마지막 동료 기술 보호를 다시 검사한다. 비용이 부족해지면 사유를 표시하고 확정을 비활성화한다.

- 제거는 상인 방문당 한 장이며 첫 50골드, 원정 누적 제거마다 25골드씩 비싸진다.
- 덱에는 최소 5장을 남겨야 하고 동료의 마지막 기술 카드 자체는 제거할 수 없다. 다른 보조 기술 카드가 남아 있다면 마지막 공격 카드 제거는 가능하므로 상성 안내를 확인한다.
- 제거는 야영지의 휴식·강화·조사와 공유하는 주 행동을 소비하지 않는다.
- **목록으로**, 닫기, 바깥 클릭, **Esc**는 카드 선택으로 돌아간다. 목록에서 다시 Esc를 누르면 야영지로 돌아간다. Enter는 제거를 확정하지 않는다.

미리보기는 원정 카드·기술·경험치·골드·난수·고유 ID·상인 재고·기록을 바꾸지 않는다. 가상 덱은 실제 카드와 분리된 사본으로 만든다. 조회 화면과 선택은 저장하지 않으며, 확정한 제거·골드 지출·상인 이용 여부만 기존 자동 저장으로 함께 보관한다. 저장 형식과 게임 규칙은 유지한다.

## 검증

Godot 4.7.2에서 실행한다.

```bash
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tests/test_removal_preview.gd
godot --headless --path . --script res://tests/test_removal_preview_ui.gd
godot --headless --path . --script res://tests/test_merchant_ui.gd
# X11 / DISPLAY / XTest 환경의 실제 OS 입력
python3 tools/test_native_pointer.py --probe native_removal_preview_probe
```

규칙 검사 111개는 기본/강화·다른 소유자·부상 연결의 보존, 실제 공개 제거 행동과 가상 결과 일치, 다음 상대별 상성, 기절·마지막 공격·최소 덱·마지막 기술 보호·비용 부족·잘못된 ID·방문당 제한과 저장 유효성을 확인한다. 실제 X11 UI 검사 65개·포인터 27회·Enter 3회·Esc 6회는 세 창 비율의 카드 얼굴 위/중간/아래 클릭, 중복 묶음·강화 구분, 조회/취소 불변성·모달 차단·정확한 한 장 확정·자동 저장·확정 시 비용 재검사를 다룬다. 1920×1080의 선택 목록과 마지막 공격 제거 안내 화면을 검토했다. 장소·자금·덱은 명시적인 경계 테스트 상태이며 해당 장소까지 수동 공략했다는 뜻은 아니다. Linux 실행 검증으로 Windows 검증을 대신하지 않는다.
