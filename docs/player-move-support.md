# 조건부 변화·동료 지원·분말 · v25 / 효과17

기술16종의 조건/대상/설명을 하나의 버전에서 보완했다. 새 원정만 적용하고 기존v1~v24 정의·저장·미래 전투·경로/RNG는 이전 분기를 유지한다. 별도 영구 문맥은 없고 기존 능력 단계/타입·접지/날씨 상태를 쓴다.

지원 기술의 대상이 없으면 에너지/손패/UID/RNG/자동 교대 전에 거절한다. 다른 동료 강화는 단일 출전·최대3마리 체계에 맞춘 파티 지원 각색이다. 자기장조작/어시스트기어의 플러스·마이너스 특성은 새로 도입하지 않는다. 분진·마법가루의 기존 풀 면역은 보존하면서 나머지 가루/포자도 같은 정책에 연결했다. 양수 단계는±6 상한,심플빔의 기존 배율을 적용한다. 이 수치를 원작 고유 효과16종 신규 완성으로 해석하지 않는다.

## 코드와 보존

- `scripts/tactics/player_move_support.gd`:정의 오버레이/순수 미리보기/적격 대상/사용 전 거절/지원 단계 적용/상대 분말 취소. `PlayerTechniques`가17을 선택한다.
- `data/player_move_support_v25.json`:9개 조건부/동료 지원과7개 분말 오버레이. 새 상태 필드 없이 기존 문맥 검증에17만 허용한다. 미리보기의 대상 UID/설명은 영구 저장하지 않는다.
- `tools/import_player_support.py --game-dir .`:v10/v24 SHA를 확인해 오버레이를 결정적으로 생성한다. 이전JSON/전용 엔진은 수정하지 않는다.
- 기초 사실은 [Pokémon Showdown 고정 moves.ts](https://github.com/smogon/pokemon-showdown/blob/7b02eb39878f4b486f658a752b38c161379bd352/data/moves.ts)의 대상·조건·분말 플래그와 대조했다. 원본 SHA256 `61ab107dae9628d79ac61da16c72e8565f6a1211874298e00c77c5c0ac9755a7`,기존 게임의 `licenses/pokemon-showdown-MIT.txt` 유지. 외부 코드를 실행하지 않았다.
