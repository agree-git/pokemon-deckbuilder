# 출발 덱·Lv.5 능력치 미리보기

스타팅 선택 화면 오른쪽의 **출발 덱·Lv.5 능력치 확인**을 누르면 새 원정을 확정하기 전에 실제 출발 구성을 확인한다. 한 마리 이상 골라야 열 수 있다.

- 선택 순서대로 스프라이트·이름·첫 출전/교체 순서와 HP·공격·방어·특공·특방·스피드를 표시한다. 희귀 스타팅은 준전설·환상·초전설 분류도 표시한다.
- 공용 카드와 소유자별 기술을 이름 목록 대신 실제 카드 그림·비용·타입·효과·포켓몬 초상으로 표시한다. 전체/공용 버튼 또는 동료 초상을 눌러 필터링하며 휠로 아래 카드까지 볼 수 있다.
- 기술 카드에는 고정 피해 예측 대신 위력·물리/특수 정보를 표시한다. 실제 피해는 상대의 방어·상성에 따라 달라지며 공용 보호막·회복은 실행 당시 포켓몬의 HP를 기준으로 환산한다.
- 캐이시·잉어킹처럼 Lv.5에 공격 기술이 없는 종은 출발 덱에 들어가는 발버둥과 그 이유를 표시한다. 발버둥을 새로 배우거나 네 기술 슬롯을 차지하게 만들지 않는다.
- 빈자리가 있으면 야생 포획으로 동료를 늘릴 수 있음을 표시한다. 기본 스타팅의 원래 기술·종족값이나 원정 난도를 미리보기 때문에 바꾸지 않는다.
- Esc·닫기·팝업 바깥 클릭으로 돌아간다. 카드 클릭은 실행되지 않고 창 아래의 시작 버튼도 차단한다. 닫아도 선택 순서와 진행 중인 원정을 보존한다.

`StarterLoadout`은 같은 `TacticalGrowth.initialize()`·`TacticalContent.starting_deck()`를 사용해 Lv.5의 별도 인스턴스를 만든다. 원정·영구 도감·시계·난수·저장에 접근하지 않는다. 개무소의 실제 진화 분기는 원정 시드와 개체로 결정하므로 여기서 미리 추첨하지 않는다. 새 원정은 기존의 최종 **원정 시작** 버튼을 눌렀을 때만 생성한다.

1~3세대 범위의 미진화 스타팅 202종에 대해 카드 얼굴·소유권·기술 슬롯·능력치를 검증한다. 실제 새 원정과 카드 ID·사본 수·소유자·Lv.5 수치가 같은지 비교한다. 실제 X11 UI 검사는 세 창 비율의 필터·휠·모달 차단·취소·최종 출발과 자동 저장을 확인한다.

```bash
godot --headless --path . --script res://tests/test_starter_loadout.gd
godot --headless --path . --script res://tests/test_starter_loadout_ui.gd
python3 tools/test_native_pointer.py --probe native_starter_loadout_probe
```
