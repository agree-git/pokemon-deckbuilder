# 전국도감·지역/상시폼 확장

**자동 진화·현재 훈련 정책은 [자동 진화·훈련](camp-progression.md)이 우선합니다.** 아래는 도감 확장 당시 기록이며 수동 진화 분기 준비와 전 기술 훈련은 폐기했습니다.

전국도감1,025종, 지역·상시·무늬·코스튬 폼을 포함한 총1,412항목입니다. 사용자 선택대로 메가진화·거다이맥스 등 전투 전용 변신, 이동 자세, 폐기된 불명 타입 아르세우스는 제외했습니다. 현재 수정은 로컬에 보관하며 **빌드/export/Windows CI와 게임 main push는 사용자 요청으로 보류**합니다.

- 앞/뒤 스프라이트2,824장과 실제 울음소리1,412개를 연결했습니다. 신규는 각각1,888장·944개이고 기존468항목의 이미지를 보존했습니다.
- 본가 기술919개의 이름·타입·원작 메타데이터·카드 전투용 효과/연출, 종별 실제 습득표·기술 훈련 경로를 포함합니다.
- 진화분기644개와 진화 재료52종을 연결하고 새 재료 아이콘37장을 포함합니다. 지역 계통을 구분하고 상시 폼·합체 포획 조건을 확인합니다.
- 울트라비스트·일반 패러독스도 일반 조우에 포함합니다. 기존 희귀103항목과 지정 준전설 패러독스6항목은 기존 조사/포획 문턱을 유지합니다. 기본1,025종 모두가 일반 조우 또는 조사에 연결됩니다.
- 특성은 한국어 도감 정보로 제공합니다. 기술은 기존 카드 전투 규칙에 맞춰 사용하며 별도 특성 전투 시스템은 추가하지 않았습니다.
- 원작의 장소·통신·회전·걷기·특정 사용 횟수 등 외부 조건은 화면에 표시한 야영 준비로 대체합니다. 레벨·시간·성별·친밀도·필수 기술 조건을 확인하며, 선택한 분기의 조건이 부족할 때 다른 분기로 자동 진화하지 않습니다.
- 새 원정v4에 전 세대 조우/새 습득표를 적용합니다. v1~v3 저장은 이전 경로·난수·기존 개체 습득표를 복원합니다. 최대3마리·69전투·개체값/노력치 없음·사용자 배경 좌표를 유지합니다.

재현 방법은 [development](development.md), 검증 결과와 빌드 보류 상태는 [validation](validation.md)·[HANDOFF](../HANDOFF.md)에 있습니다. CSV/이미지/울음소리의 고정 출처·SHA256은 게임의 `assets/sources/pokedex_expansion.json`, `assets/sources/manifest.json`, `assets/audio/cries/manifest.json`에 기록했습니다. 현재 main push가 보류돼 새 실행 데이터는 아직 원격 main에 반영하지 않았습니다.
