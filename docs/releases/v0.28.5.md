# 포켓몬 원정대 v0.28.5

포획 애니메이션과 일반 트레이너 이미지를 보완하고, 아이템 표시 크기를 수정했습니다.

- 몬스터볼이 날아가 포켓몬을 수납하고 바닥에 떨어진 뒤 세 번 흔들리는 포획 연출을 추가했습니다. 성공 안내는 연출이 끝나면 표시됩니다.
- 원작 HGSS의 일반 트레이너 이미지 12종을 일반·베테랑 전투에 배정합니다. 같은 전투를 불러오면 같은 모습으로 표시되며, 관장·사천왕·챔피언의 전용 이미지는 유지됩니다.
- 일부 아이템 이미지가 버튼보다 크게 표시되는 문제를 수정했습니다.
- 저장 폴더를 `%APPDATA%\PokemonExpedition`으로 변경했습니다. 첫 실행 시 기존 원정·도감·설정을 옮기며 기존 원본은 보존합니다. 새 폴더에 이미 있는 저장은 덮어쓰지 않습니다.
- 제공받은 Credit.txt·README-Windows.txt·PLAY_GUIDE.md를 반영했습니다. 엔딩의 명예의 전당·스크롤 형식과 제작자 DO 표시는 유지합니다.
- ASSET_SOURCES.md·CHANGELOG.md를 배포 구성에서 제거했습니다. 자료별 원문 고지는 assets/sources·licenses에 남아 있습니다.
- 포획 판정·비용, 기존 저장 형식·전투 규칙·보스 파티는 유지합니다.

## 실행

`PokemonExpedition-Windows-x86_64-….zip`을 새 폴더에 모두 풀고 `PokemonExpedition.exe`를 실행하세요. Godot 설치는 필요 없으며 EXE와 PCK를 함께 둡니다. GitHub의 `Source code`는 실행용 파일이 아닙니다.

기존 저장 위치는 `%APPDATA%\Godot\app_userdata\포켓몬 원정대`입니다. 정상 이전 후 새 저장은 `%APPDATA%\PokemonExpedition`을 사용합니다. 저장 이전에 실패하면 안내 후 종료되며 원본은 남습니다.

소스에서 저장 이전 30건, 연출 176건 및 마지막 포획 수정 27건을 확인했습니다. Windows 실제 실행 결과는 GitHub 검사 통과 후 첨부되는 windows-native-report.json을 확인하세요.
