포켓몬 원정대의 새 원정을 도전 난도로 조정한 Windows x86_64 시험 배포입니다.

### 다운로드와 실행

1. 아래 Assets에서 `PokemonExpedition-Windows-x86_64-….zip`을 받습니다. GitHub가 자동 생성한 **Source code**는 실행 파일이 아닙니다.
2. ZIP 전체를 새 폴더에 압축 해제합니다.
3. `PokemonExpedition/PokemonExpedition.exe`를 실행합니다. 옆의 `.pck`를 함께 두며 **Godot 설치는 필요 없습니다**.

### 이번 변경

- 트레이너·관장·사천왕·챔피언의 각 포켓몬에 개시 보호막을 추가하고 후반 직접 공격을 강화했습니다. 실제 피해는 상대 행동 예고에 반영합니다.
- 야영 휴식 회복을 첫 지역40%,두 번째35%,이후30%로 조정했습니다. 상성·교대·방어와 야영지 강화·회복약·장비 준비가 중요합니다.
- 첫 지역 야생은 이전 공격 배율을 유지합니다. 승인된 트레이너 파티·대표 포켓몬과 경험치·레벨·기술 효과는 유지합니다.

난도 변경은 **새 원정부터** 적용합니다. 기존 원정은 이전 난도와 저장을 유지합니다. Windows 저장은 `%APPDATA%\Godot\app_userdata\포켓몬 원정대`이며 업데이트 시 ZIP은 별도 폴더에 풀 수 있습니다.

### 검증과 범위

같은 시드의 공개 행동 자동 진행은 이전과 같이69승을 완료하면서215→257턴,기절0→6회로 늘었습니다. 다른 두 시드는 첫 관장에서 실패했습니다. 실제 플레이어의 평균 클리어율을 측정한 결과는 아닙니다.

이 릴리스 작업은 공식 Godot4.7.2로 제작한 Windows EXE를 Windows runner에서 headless 실행해 검사한 후 게시합니다. `windows-native-report.json`에서 파일 일치·시작 화면·리소스/저장/설정 검사를 확인하고,ZIP의 해시는 `SHA256SUMS.txt`와 비교할 수 있습니다. 실물 GPU·스피커·수동 장시간 플레이 검증은 별도입니다. 자세한 조작과 변경사항은 ZIP 안의 `PLAY_GUIDE.md`와 `CHANGELOG.md`에 있습니다.
