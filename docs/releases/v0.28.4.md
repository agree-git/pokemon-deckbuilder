# 포켓몬 원정대 v0.28.4

챔피언을 이긴 뒤, 함께한 동료와 원정 성적을 담은 엔딩 크레딧이 재생됩니다.

- 명예의 전당·동료 포켓몬·승수·배지·턴수를 표시합니다.
- 제작자 **DO**와 자료별 이름·버전·웹사이트·기여자·라이선스를 소개합니다.
- YOUNG의 Another Red 크레딧 구성 형식을 참고했습니다. 전체 원문 고지를 담은 Credit.txt를 배포하고, 게임 안의 상세 크레딧에서도 읽을 수 있습니다.
- 자동 스크롤, Space 일시정지·재생, ↑↓·휠 스크롤, Esc·Enter 건너뛰기를 지원합니다.
- 결과 화면에서 다시 보거나 시작 화면의 크레딧 버튼으로 열 수 있습니다.
- 기존 저장·원정·전투 규칙을 유지합니다.

## 다운로드

`PokemonExpedition-Windows-x86_64-….zip` 전체를 새 폴더에 풀고 `PokemonExpedition.exe`를 실행하세요. Godot 설치는 필요 없습니다. EXE와 PCK는 같은 폴더에 둡니다. `Source code`는 개발용 소스이며 실행용 ZIP이 아닙니다.

기존 저장은 `%APPDATA%\Godot\app_userdata\포켓몬 원정대`에서 유지됩니다. 에셋별 출처와 원문 고지는 ASSET_SOURCES.md·assets/sources·licenses에 포함됩니다. Windows 실행 검사는 워크플로 통과 후 첨부되는 windows-native-report.json에서 확인할 수 있습니다.
