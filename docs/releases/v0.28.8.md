# 포켓몬 원정대 v0.28.8

처음 플레이할 때 튜토리얼의 안내 순서를 따르도록 입력을 제한하고,지역 이동 화면과 기술 가르침 목록을 정리했습니다.

- 튜토리얼에서는 현재 안내한 카드·버튼만 사용할 수 있습니다. 강화 단계도 강화 열기→카드 선택→확정 순서로 진행합니다. 연습 나가기와 Esc는 유지합니다.
- 지역 내 스테이지를 화살표로 연결한 가로 카드로 표시합니다. 한 번에4개를 볼 수 있고,가로 스크롤과 좌우 버튼으로 탐색합니다. 현재 스테이지가 있는 구간을 자동으로 보여줍니다.
- 기술 훈련 명칭을 **기술 가르침**으로 변경하고,이미 습득한 기술을 목록 맨 위에 표시합니다.
- 연구 검색창을 한글 조합을 읽을 수 있는 입력창으로 교체했습니다. 입력 중 결과 버튼을 다시 만들거나 검색창의 글자·포커스·커서를 덮어쓰지 않습니다. Enter는 검색을 확정하며 줄바꿈하지 않습니다.
- 저장 위치·전투 규칙·자동 진화·기술 비용100/200골드·야영 행동과의 분리·야영지 출발마다×1.1 복리 골드 정책은 유지합니다. 원정 다시하기 제거도 유지합니다.

## 한글 입력의 확인 범위

**Windows 한글 입력기의 실제 조합은 아직 검증하지 못했으므로 해결 완료를 보장하지 않습니다.** Linux의 실제 두벌식 입력 검사에서 기본 외부 조합 방식은 검색·삭제·재입력·Enter 확정9건을 통과했습니다. 반면 입력창 안에 조합을 표시하는 방식에서는 앞 음절이 누락되는 문제가 남아 있으며,검색 기능이 없는 기본 입력창에서도 재현됐습니다. 이 결과를 Windows 결과로 일반화하지 않습니다.

튜토리얼·스테이지 UI 소스 검사81건,검색·명칭·습득순 정렬 검사27건을 통과했습니다. 첨부 windows-native-report.json은 GitHub Windows 빌드·실행 검사 결과이며 한글 IME 실기 검증을 뜻하지 않습니다.

## 실행

`PokemonExpedition-Windows-x86_64-….zip`을 새 폴더에 모두 풀고 `PokemonExpedition.exe`를 실행하세요. Godot 설치는 필요 없으며 EXE와 PCK를 함께 둡니다. `Source code`는 실행용 파일이 아닙니다. 기존 저장 위치는 `%APPDATA%\PokemonExpedition`입니다.
