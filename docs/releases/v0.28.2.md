Assets의 `PokemonExpedition-Windows-x86_64-….zip`을 받아 **전체 압축을 새 폴더에 해제**하고 `PokemonExpedition/PokemonExpedition.exe`를 실행하세요. 옆의 `.pck`를 함께 둡니다. **Godot 설치는 필요 없습니다.** GitHub의 Source code ZIP은 실행 파일이 아닙니다.

### 이번 변경

- 기본종·지역·상시폼1,412항목의 앞뒤2,824뷰를 실제 Gen5 스타일2D 애니메이션으로 표시합니다. 트레이너와 배경은 유지합니다.
- 야영지 UI 겹침을 수정하고 전투·설정·덱·상점·시작 화면의 버튼 간격과 공간을 정리했습니다. 포켓몬 연구는 동료 세로 목록과 연구 본문으로 나누고 긴 버튼을 줄였습니다.
- 전투·야영 Esc 메뉴에 음악 플레이어를 넣었습니다. 곡 제목·진행 시간·이전/재생·일시정지/다음·음악 음량을 조절할 수 있습니다. 관장·사천왕·챔피언의 전용곡은 유지합니다.
- 타격·베기·발사·충전·방어·회복·보조 기술의 준비·돌진·도약·반동·자세 복귀를 추가했습니다. 기존 전투 배속과 피격 흔들림 설정을 따릅니다.
- 독·화상·마비 등 상태 적용과 지속 피해의 입자·색 반응을 강화했습니다. 새로운 원인 문구 없이 기존 숫자·문구를 유지합니다.
- v28 원정의 새 전투에서는 상대 레벨이 진화 조건에 부족하면 같은 계열의 이전 단계로 등장합니다. 진행 중인 전투와 이전 원정·승인 파티 원본은 유지합니다.
- 처음이라면 시작 화면의 튜토리얼에서 카드·자동 교대·방어·포획·야영 휴식과 강화를 연습할 수 있습니다. 연습은 진행 중인 원정·도감·골드를 변경하지 않습니다.
