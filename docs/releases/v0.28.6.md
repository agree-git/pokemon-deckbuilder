# 포켓몬 원정대 v0.28.6

진화 분기를 자동으로 결정하고 기술 훈련을 정리했습니다. 야영지를 떠날 때마다 골드 보상과 일반 비용이 이전 금액 대비10% 증가합니다.

- 야영지의 진화 분기 선택·준비 버튼을 제거했습니다. 레벨·친밀도·시간·필수 기술 등의 조건 충족 후 레벨업할 때 자동 진화합니다. 진화석 등은 가방에서 재료를 사용하며, 연구 화면에서 조건을 확인할 수 있습니다.
- 기술 훈련에 현재 레벨까지의 자력기를 모두 표시합니다. 자력기는100골드,그 외 해당 포켓몬이 배울 수 있는 기술은200골드입니다. 골드가 충분하면 반복할 수 있고 휴식·강화·조사 행동을 소모하지 않습니다.
- 기술머신은 기존처럼 호환되는 소모품1개로 배웁니다. 판매가100골드와 사용 방식은 유지합니다.
- 야영지 출발마다 획득 골드와 일반 지출에×1.1을 누적 적용합니다: **100%→110%→121%→133.1%…**. 전투·이벤트 보상과 보급품·진화 재료·상인 카드·카드 제거·전술 수업에 적용합니다.
- 훈련비100·200골드와 기술머신 가격은 증가 대상에서 제외합니다. 야영지에 머무르거나 저장을 다시 불러오는 것으로는 배율이 증가하지 않습니다.
- 커진 후반 보상도 저장·복원할 수 있도록 전리품 골드 검증 범위를 보완했습니다. 저장 필드·경로·전투 난수·승인된 보스 파티는 유지합니다.

## 실행

`PokemonExpedition-Windows-x86_64-….zip`을 새 폴더에 모두 풀고 `PokemonExpedition.exe`를 실행하세요. Godot 설치는 필요 없으며 EXE와 PCK를 함께 둡니다. `Source code`는 실행용 파일이 아닙니다.

저장 위치는 `%APPDATA%\PokemonExpedition`입니다. 이전 기본 폴더의 저장·도감·설정 자동 이전도 유지합니다. Credit.txt·PLAY_GUIDE.md·README-Windows.txt와 자료별 원문 고지를 함께 제공합니다.

기술 훈련·골드 거래·68회 출발 배율·후반 고액 보상 저장을 포함한 소스 검사217건을 통과했습니다. 자동 진화 검사도 앞선 수정에서 확인했습니다. Windows 실제 실행 결과는 이번 GitHub 검사 통과 후 첨부되는 windows-native-report.json을 확인하세요.
