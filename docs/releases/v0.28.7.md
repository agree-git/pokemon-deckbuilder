# 포켓몬 원정대 v0.28.7

원정 다시하기를 제거하고,기술 훈련 검색에서 한글 조합을 보호하도록 입력 처리를 보완했습니다.

- 원정 중 메뉴와 전투 결과의 다시하기 버튼을 제거했습니다. 최종 결과의 같은 시드·새 시드 재출발 기능도 제거했습니다. 새 원정은 시작 화면에서 스타팅을 선택해 시작합니다.
- 최종 결과의 시작 화면 버튼을 중앙에 배치했습니다. 클리어 후 엔딩 크레딧 다시 보기는 유지합니다.
- 연구 검색창에서 한글을 조합하는 동안에는 결과 갱신을 미루고 조합 확정 후 처리합니다. 입력 중 결과 버튼을 삭제·재생성하지 않으며 검색창의 포커스·커서를 유지하도록 변경했습니다. 기술 훈련과 기술머신 등 연구 검색 탭에 적용됩니다.
- 저장·전투 규칙·자동 진화·훈련 비용·야영지 출발마다×1.1 복리 골드 정책은 유지합니다.

## 실행

`PokemonExpedition-Windows-x86_64-….zip`을 새 폴더에 모두 풀고 `PokemonExpedition.exe`를 실행하세요. Godot 설치는 필요 없으며 EXE와 PCK를 함께 둡니다. `Source code`는 실행용 파일이 아닙니다. 저장 위치는 `%APPDATA%\PokemonExpedition`입니다.

원정 다시하기 제거 관련 소스 검사11건,검색 입력 관련 소스 검사21건을 통과했습니다. **Windows 한글 입력기의 실제 조합 문제는 아직 직접 검증하지 못했습니다.** 첨부 windows-native-report.json은 GitHub Windows 빌드·실행 검사 결과이며 한글 IME 실기 검증을 뜻하지 않습니다.
