# 접지·부유 · 원정 v15

새 원정v15/플레이어 효과7에 중력(356)·전자부유(393)·텔레키네시스(477)를 추가했다. 누적396기술 보완이며,이전 [v14](player-move-seals.md)까지의 정의/전용 엔진은 동결한다. 원작 완전 복제보다 카드 전투의 특징을 살리는 각색이다.

| 기술 | 실제 카드 동작 |
|---|---|
| 중력 |5상대 행동 동안 양쪽 강제 접지. 비행 타입을 지우지 않고 땅 무효만 해제. 전자부유/텔레키네시스·공중 충전/보존을 취소. 고정CSV의 중력 제한10기술은 양쪽 모두 사용 불가. 재사용은 기간 갱신 |
| 전자부유 |사용자5상대 행동 동안 땅 공격 무효. 접지 필드의 공격 강화/회복/새 상태 방어에서 제외. 일반 공격/상태 기술을 모두 회피하는 효과는 없음 |
| 텔레키네시스 |상대3상대 행동 동안 같은 부유 효과. 보호/대타/공중 회피에 막힘. 중력/뿌리박기/떨어뜨리기의 강제 접지 대상에는 비용 없이 사용 거절 |

기존 보스 중력도 새 부유를 취소하고 새 중력과 같은 강제 접지 판정에 참여한다. 전자부유/텔레키네시스는 교대·전투 종료·중력·뿌리박기·성공한 떨어뜨리기에 해제된다. 떨어뜨리기는 남은 전투 중 그 대상이 교대하기 전까지 강제 접지를 유지한다. 전장 중력만5회 기간을 따르며 출전자 변경으로 사라지지 않는다. 중력 중 기술 사용 거절은 카드/에너지/교대/UID/RNG를 바꾸지 않는다. 상대의 중력으로 취소된 무릎차기는 충돌 반동을 적용하지 않는다.

접지 판정은 필드 강화·지진 감소·필드 연계 위력/비용·수면/상태 방어·그래스필드 회복·선공 공격 차단·잠자기 조건을 함께 사용한다. 상대방과 아군의 다음 입장 시 압정/독압정/네트도 중력으로 비행 포켓몬에 적용한다. 이미 출전 중인 대상에게 설치 입장 피해를 다시 주지 않는다. 날개쉬기·타입 교환·원더룸·주술의 급소 연타 방어·복사/잠꼬대와 함께 계산하고 실제 타입/영구 능력치/소지품은 유지한다.

명중 확률/회피 추첨이 없는 카드 규칙이므로 중력/텔레키네시스의 명중 보정은 별도 도입하지 않았다. 텔레키네시스의 체중·종별 예외도 생략했다. 사우전드애로/사우전드웨이브의 고유 효과는 후속 범위다.

## 코드와 저장 계약

- 핵심은 `scripts/tactics/player_move_altitude.gd`의 `grounded/affinity/reason/after_card/synchronize`와 `data/player_move_altitude_v15.json`. 선택 `altitude_context={gravity,rise,lift,down}`;중력0..5,나머지는 개체UID별 부유1..5/1..3 또는 착지true. 잘못된 UID/형식/기간 및 자체 중력과 부유의 동시 보관은 거절한다. 이전 원정은 빈 새 문맥도 허용하지 않는다.
- `player_move_air_fields.gd`는 기존 필드에서 접지에 의존하는11함수와 주술의 NPC 급소 계산만 파생하고 나머지는 동결 도우미를 호출한다. 중복 수동 수정 대신 `tools/derive_player_air_fields.py --game-dir .`로 재생성한다. 입력 엔진 SHA를 검증하고 실제 접지 호출만 새 판정으로 바꾼다. 이전 엔진은 수정하지 않는다.
- `tools/import_player_move_altitude.py`는v14 기반 SHA와v10→v14 체인/고정CSV4종 SHA를 검사하며3개 정의를 생성한다. 새 호출도 원래 카드 UID/소유자/비용을 유지한다.
- 공통 전투 훅은 효과7에서만 새 필드/부유 경로를 사용. BattleFrame/저장에 문맥을 복제하고 교대 시 충전 보존과 부유를 지운다. 선택 필드를 기존 저장의 필수 필드로 만들지 않는다.
