# 현재 확정 규칙

이 문서는 현재 동작과 사용자 결정을 요약한다. 최신 사용자 요청이 우선이며, 과거 기획 초안은 별도 [고정 자료](history.md)다. 실제 세부 카드 수치·콘텐츠는 main의 코드/JSON을 확인한다. 밸런스 조정은 보류 중이다.

## 콘텐츠와 원정

- 전국도감#001~1025 전종과 지역·상시·무늬·코스튬 폼을 포함해1,412항목이다. 사용자 선택에 따라 메가진화/거다이맥스 등 전투 전용 변신·이동 자세·폐기된 불명 타입 아르세우스는 제외한다. 울트라비스트와 일반 패러독스도 일반 조우에 포함한다. 기존 희귀103항목과 조사/포획 문턱은 유지하며 지정 준전설 패러독스6항목을 일반 조우에 넣어 우회시키지 않는다.
- 해금된 가장 미진화체 중 서로 다른 **1~3마리**를 Lv.5 스타팅으로 선택한다. 원정의 레벨·HP·덱·가방은 새 원정에서 초기화하며 포획 해금은 유지한다.
- 무작위 8바이옴에서 각각 야생5·일반 트레이너1·엘리트 트레이너1·관장1 =8전투와 배지를 거친다. 이후 무작위 사천왕4·챔피언1. **총69전투·68야영지**다. 각 전투 사이 야영지와 짧은 이동 연출이 있다.
- 타입은18개. 관장·사천왕·챔피언은 지방 제한 없이 후보에서 선정하며 새 원정(v3)은 같은 인물도 역할별로 별개 후보로 취급한다. 같은 역할의 중복 대진은 막는다. v1/v2 저장은 이전 인물 제외 규칙과 경로를 유지한다. 관장은6마리, 기존 사천왕은5마리(추가 블루베리4인은6마리), 챔피언은6마리 파티를 한 전투에서 차례로 내보낸다. 챔피언은 전원Lv.100이다.
- 일반 파티 전멸 시 실패, 챔피언 승리 시 종료한다. 옛 짧은 경로/호환 코드는 저장/회귀가 참조하는 한 함부로 삭제하지 않는다.

## 카드 전투

- 기술·도구·트레이너 카드가 하나의 덱/손패를 공유한다. **브레이크와 고정 기술 버튼은 없다.**
- 턴 시작 기본 에너지3, 출전 아군이 상대보다 빠르면 +1. 비교 결과는 그 턴 동안 고정하며 중간 교대로 재지급하지 않는다. 기본 드로우5, 손패 상한10. 유물에 의한 명시적 변경은 별도다.
- 대기 동료의 기술 카드를 쓰면 그 동료로 무료 자동 교대 후 실행한다. 수동 교대는 에너지1, 강제 교대는 무료다. 비용이 부족한 카드는 교대/자원/카드/난수를 바꾸지 않는다.
- 일반 사용 카드는 버린 더미, 소진 카드는 해당 전투의 소진 더미로 간다. 드로우 부족 시 버린 더미만 섞는다. 보존은 다음 턴까지 손패 유지. 더미 UI는 카드 그림·동일 카드 겹침/개수를 보여 주되 숨은 드로우 순서는 공개하지 않는다.
- 보호막/능력 강화는 포켓몬에게 귀속된다. 플레이어 턴 시작에 아군 보호막을 초기화한다(핵심 유물 예외). 마지막 출전 멤버가 예고된 적 행동을 받는다.
- 상대 교대가 현재 손패·에너지·턴·지속 작전을 초기화하거나 추가 즉시 공격을 만들지 않는다. 기절한 소유자의 카드는 해당 전투에서 제외하고 원정 덱에 부상1장을 추가한다. 영구 삭제하지 않는다.
- 기술 슬롯은4개. 기술을 새로 배우거나 교체하면 소유 카드에도 반영하고 기존 사본의 ID/강화를 보존한다. 제거는 기술 자체를 잊게 하지 않는다. 삭제한 기술을 무료로 덱에 되돌리지 않는다.
- 공용 카드55종 + 부상, 일반 유물26·핵심 유물5·지닌 물건6. 유물은 파티 전체, 지닌 물건은 멤버별1개다. 핵심 유물은 관장 보상에서 원정당 하나만 선택하며 장점/대가를 함께 적용한다.
- 일반 전투 보상은 카드·유물·지닌 물건 등의 제시 선택지 중 하나 또는 넘기기다. 파티 교체는 떠난 소유자의 기술/부상을 제거하고 지닌 물건을 반환한다.

## 능력치·성장·진화

같은 종·같은 레벨은 같은 기본 능력치다. **개체값·노력치·성격 보정 없음.** 기존468항목의 역사적 종족값은 보존하며 추가 항목은 고정 PokeAPI 출처의 종족값을 사용한다.

- 기초 = `floor(2 × 종족값 × 레벨 / 100)`.
- HP = 기초 + 레벨 +10. 껍질몬은 항상1. 나머지5능력치 = 기초 +5.
- 물리/특수는 각각 공격/방어와 특공/특방을 사용한다. 자속·18타입 복합 상성·능력 단계·상태·날씨를 적용하며 기본 피해 공통 배율은0.6이다. 상세 구현: `scripts/tactics/pokemon_stats.gd`, `type_matchup.gd`.
- 경험치가 종별 원작 성장 곡선의 문턱을 넘을 때만 레벨업한다. 살아 있는 파티 전원 정상 XP, 기절 멤버는30%. 전멸에는 보상 없음. 정산은 한 번만 한다.
- 정상 생존 진행은 마지막 사천왕 정산 후Lv.100, 챔피언 직전100을 목표로 전투별 경험치를 배분한다. 늦은 합류/기절은 늦을 수 있다. 스테이지 진입만으로 레벨을 직접 맞추지 않는다.
- 레벨 진화는 정산 도중 자동 처리한다. 레벨업 기술은 원작 레벨별 목록을 사용하고 네 슬롯이 차면 습득/교체를 선택한다. 원작의 모든 특수 기술·특성·PP·확률을 전부 재현한 것은 아니다.
- 돌/통신 재료는 야영지 아이템 사용으로 진화한다. 친밀도220 이상 레벨업 진화와 원정 낮/밤 분기를 지원한다.
- 배루키는 야영지에서 진화할 모습을 선택(기본 카포에라)하며 능력치를 바꾸지 않는다. 개무소는 시드/UID에 고정된 진화 분기, 빈티나는 아름다움170+레벨업, 토중몬은 빈자리+볼1개일 때 껍질몬 추가 합류다.
- 새 희귀 계열: 코스모그Lv.43→코스모움Lv.53 낮 솔가레오/밤 루나아라, 타입:널 친밀도→실버디, 치고마 악의족자→일격 우라오스, 멜탄 원정용 사탕→멜메탈.

## 야영지·날씨

야영지는 휴식/강화/희귀 단서 조사 중 주 행동을 선택한다. 가방의 회복 아이템, 장비 교환, 상인 구매/카드 제거, 무작위 특별 이벤트/발견은 현재 상태에 맞게 처리한다. 아이템은 클릭 후 파티 초상 팝업에서 대상을 선택한다. 전리품 확인만을 위한 탭은 제거했다.

날씨는 양쪽에 적용되는 한 종류,5턴이다. 다른 날씨로 교체하거나 같은 날씨5턴 갱신, 교대로 유지, 전투 종료 시 해제한다.

| 날씨 | 효과 |
|---|---|
| 비 | 물 피해×1.5, 불꽃×0.5 |
| 눈 | 얼음 타입의 물리 방어×1.5, 지속 피해 없음 |
| 쾌청 | 불꽃 피해×1.5, 물×0.5 |
| 모래바람 | 바위 특방×1.5, 양쪽 출전 멤버에 최대HP1/16 피해. 바위/땅/강철 면역 |

모래 피해는 보호막을 무시하고 양쪽 처리 후 승패를 판정한다. 날씨별 특성/특수 기술 예외와 적 날씨 행동·바이옴 자동 날씨는 미구현이다. 쾌청 광원은 왼쪽 위 햇살/렌즈 플레어다.

| 분류 | 항목 | 단서/배지 | 볼 | 에너지 | HP |
|---|---:|---:|---:|---:|---:|
| 준전설 |53|3|3|2|10% 이하|
| 환상 |23|5|3|2|10% 이하|
| 초전설 계열 |27|7|5|3|10% 이하|

초전설 계열은 최종25 + 코스모그/코스모움2다. 미진화체 포획/진화로 문턱을 우회하지 않는다. 일반 야생 포획은HP25% 이하, 볼1·에너지1이다.

- 원정당 도전1회, 준비한 다음 야생 한 전투를 대체한다. 처치하면 그 원정의 포획 기회를 잃는다.
- 103종별 장소/소문/단서463개. 이미 얻은 마지막 단서만 보여 준다. 발견 전 이름·그림·실루엣·타입·번호와 지도/준비/이동/검색을 `?`로 숨긴다.
- 포획 기록만 영구 도감에 남는다. 현재 원정에서 만난 대상은 표시하지만 미포획 조우 이력을 별도 영구 수집 시스템으로 저장하지 않는다.
- 포획에 성공하면 풀어주거나 원정 실패해도 그 계열의 가장 미진화한 지원 종을 스타팅으로 해금한다.
- 최종25종은 DNA·무지개·거품·파도·지진·구름·시간/공간·그림자·불꽃/번개/얼음·수풀/세포·태양/달/웜홀·칼/방패·눈보라·스텔라 등 고유 도입. 레시라무는 푸른 불꽃, 코라이돈은 태고 지층/역행 먼지, 미라이돈은 미래 격자/전송이다.
- 희귀103종에는 포획·합류·방출 반응309개가 있다. 포획 성공 결과/합류 선택 화면에 포획 문구를 표시하고, 실제 합류·방출 완료 뒤에는 종별 반응창을 표시한다. 창은 클릭·Enter·Space·Esc로 닫으며, 닫기/다시 그리기는 모델·보상·덱·UID·게임 난수를 바꾸지 않는다. 확인창은 임시 UI라 저장/재접속 시 재생하지 않는다. 일반 포획과 희귀 격파에는 추가 반응을 넣지 않는다.
- 코스모그/코스모움은 공용 희귀 도입이다. 예고→몸/울음소리/문구→조작 복원으로 진행하며 연출은 상태·날씨·게임 난수를 바꾸지 않는다.

## 표시·조작

화면/UI는 **1920×1080**, 그래픽만 도트다. 최근접 보간·정수 배율을 사용하며 전체 UI를 저해상도로 렌더링하지 않는다. 아군은 왼쪽 아래, 상대는 오른쪽 위. 양쪽 파티는 가장자리, 손패는 아래다.

손패6~10장은 겹치며 호버 카드가 위로34px·10% 확대되고 양옆 카드가 공간을 만든다. 같은 카드 목록은 겹침+개수로 표시한다. HP/공격/보호막 등의 아이콘은 대응 명칭을 대체하되 대상·행동·기간 설명은 남긴다. 숫자 변화는 가능하면 차이값으로 표시한다.

1/2/3 파티 교대, Q/W/E/R 왼쪽 네 카드, Enter 턴 종료, C 포획, Esc 메뉴/닫기, F1 도움말, F11 전체 화면. 카드/공격/교대/상태는 단계 연출을 사용한다. 배속1/1.5/2·피격 움직임·음량 설정은 원정 저장과 별도다.

### 바이옴 오디오

사용자가 제공한 포켓몬 BGM35곡 중에서 지역에 진입할 때 무작위 한 곡을 고른다. 일반 야생/트레이너/엘리트 트레이너 전투와 야영·보상·지도·이동에서 같은 지역의 곡을 이어 재생한다. 새 지역은 직전 지역과 다른 곡을 고르며, 같은 지역의 화면 새로고침·전투/야영 전환·메뉴 재진입은 다시 추첨하지 않는다. 관장/사천왕/챔피언 전투는 전용 전투곡이며 종료하면 그 지역의 선곡으로 복귀한다. 보스용39파일(36개 서로 다른 녹음)을8ZIP으로 제공받아137대진에 역할 키로 연결했다. 같은 역할의 BW/BW2곡은 등장별 독립 오디오 RNG로 선택하고 전투 중에는 고정한다. 비트·마리·타임은 파일명에 없어 해당 지방의 일반 관장곡을 사용한다.

지역 키는 원정run_id·chapter·경로biome이며 전용 RandomNumberGenerator를 쓴다. 리그(chapter8)는 실내 대진 타입과 무관하게 한 지역으로 묶는다. 선곡은 오디오 계층의 임시 캐시로, 게임/전투/보상 난수나 원정 저장/지문에 넣지 않는다. 같은 실행 중 저장을 다시 읽으면 run_id로 기존 곡을 찾으며 앱을 완전히 다시 시작하면 새로 고른다. 발견 전 희귀의 별도 배경 대신 원정 경로로 선곡한다. 타이틀은 ORAS 미로마을, 종료/예비 야영곡은 HGSS 태초마을이다.

18바이옴 환경음은 경로에 따라 재생하고 야외 전투에서는 낮춘다. 관장/사천왕/챔피언 실내 전투와 타이틀·원정 종료는 환경음을 페이드아웃한다. 이전 자체 합성 바이옴 음악은 예비/독립 전투 화면 호환용으로 보관한다.

- 음악/환경음은 지속하는 두 보이스로 1.2초 교차 전환한다. 같은 화면/바이옴을 새로 그려도 재시작하지 않으며, 전투 배속은 소리의 속도/페이드 시간에 적용하지 않는다.

선택 `boss_context`와 개체별 `effects_v3`를 UID/타입/상한/행동 순서로 검사한다. 스텔스록 기절 후 같은 턴 교대를 `hazard`로 복원하며 손패/에너지/턴 재지급을 막는다. 입장 기절할 자동 교대 기술은 비용 없이 거절하고 수동/강제 교대 기절은 정상 처리한다. 기존 v1~v7 원정과 미래 전투·난수를 보존하며 이전 실제5de9a6 지문을 수용한다. v6/v7 입력·엔진은 동결하고 v8도 후속 버전으로 확장한다. 아직33대표는 이전 전술이다. EXE/export/Windows CI와 전반 밸런스/경제/성장/특성/PP 추가는 자동 재개하지 않는다.


## 대표 기술 효과 P3와 원정 v9

검토된138대표/233기술의 카드 전투 구현을 별도 효과4/v9 입력에 연결한다. 플레이어919기술의 원작 효과 전체 구현과 구분한다. 지연 수면/길동무/음성·마지막 기술 봉인/장비 무효·종료 복구/공중 회피/확정 급소/타입 소모/공개 변덕 주기와 각색 수치는 [효과 현황](boss-move-effects.md)을 따른다. 실제 성별/명중/PP/특성/테라스탈·전반 밸런스/경제/성장을 추가하지 않는다.

수동 교대와 다른 소유 기술 카드의 자동 교대는 구속 중 함께 금지한다. 현재 동료 기술/도구·고속스핀/킬러스핀 해제·시전자 기절·구속 만료·고스트 탈출·기절 후 필수 교체는 허용한다. 거절은 비용/카드/RNG를 소모하지 않는다. 길동무 등 카드 도중 기절의 `card` 교대는 같은 턴/손패/에너지를 보존한다.

기존v6/v7/v8 데이터·엔진·문맥 동작은 동결한다. v9는 새 `BossBattleRules` 분기와 별도 `BossBattleEffectsP3`/`effects_v4`를 사용하고 이전 실제36fe00 지문을 수용한다. UID/타입/정수/상한/다음 행동을 검사하며 도감 타입을 바꾸지 않고 소모 타입을 전투 문맥에 기록한다.

**사용자 최신 검사 순서:** 기술 구현과 소스/모델 검사를 먼저 끝내고 실제 창 검사는 이후 한꺼번에 진행한다. 구현 도중 개별 native/X11 실행을 반복하지 않는다. EXE/export/Windows CI는 별도 명시 재개 요청 전까지 보류한다.


## 플레이어 기술 카드와 원정 v10

사용자는 원작과 차이가 있어도 기술의 특징을 살리는 카드 규칙을 승인했다. 새 원정v10의 플레이어919기술 중311개에 연타·실제HP 기반 흡수/반동·충전/재충전·조건부 위력·보호/대타/장막·회복/비축·봉인 등의 특징을 적용한다. 구체적 각색과 미구현 범위는 [기술 카드 현황](player-move-cards.md)을 따른다. 모든919기술의 원작 고유 효과 전체 구현으로 보고하지 않는다.

기존 원정v1~v9의 플레이어 효과1은 유지하고 새v10만 효과2를 선택한다. 선택 `move_context`는 UID/카드/턴/상한/버전을 검증한다. 보스효과4/138대표233기술과 승인137대진 파티/경로 RNG·지닌 물건·성장·경제·배경 좌표는 유지한다. 새 특성/PP/성별/명중률 시스템은 추가하지 않는다. 이전 실제f82367 지문을 수용하며 게시된v10 입력도 후속 버전으로 확장한다. 실제 창 일괄 검사와 EXE/export/Windows CI 보류 지시는 계속 적용한다.


새 원정v11의 플레이어 효과3은32카드를 추가 보완해 누적342기술이다. 별도 `PlayerMoveTactics`/`player_move_tactics_v11.json`/선택 `technique_context`와 `PlayerTechniques` 분기를 사용한다. 게시된v10 데이터/엔진·기존v1~v10 저장·경로/RNG·승인 파티/마지막 대표를 유지하며 v11도 게시 후 동결한다. 설치는 다음 상대 입장, 울부짖기 계열은 전술 밀어내기, 앙코르는 기존 예고 순서에서 직전 기술만 허용하는 명시 각색이다. [v11 기술 현황](player-move-tactics.md)을 따른다. 실제 창/빌드/EXE 보류 지시는 계속 적용한다.
