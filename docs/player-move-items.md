# 사우전드애로·소지품 조작 · 원정 v17

새 원정v17/플레이어 효과9에8개 기술을 보완해 누적411개다. v1~v16 엔진/JSON은 동결한다. 기존6종 커스텀 장비만 다루며 새 아이템/열매/특성·NPC 장비 배정은 추가하지 않았다.

| 기술 | 실제 동작 |
|---|---|
| 사우전드애로614 |부유/공중 회피를 관통하고 명중 후 강제 착지. 접지 전 비행 타입 첫 타격은 땅 상성1배,부유만 하는 비비행 타입은 원래 땅 상성. 착지 뒤 일반 땅 상성. 보호/대타에 막히면 착지하지 않음 |
| 트릭271·바꿔치기415 |양쪽 실제 전투 소지품 교환. 한쪽 무소지도 가능. 양쪽 무소지면 원자적으로 거절 |
| 기프트패스516 |자신의 소지품을 무소지 상대에게 전달. 원본 플래그처럼 보호/대타를 우회하지만 공중 회피는 차단 |
| 내던지기374 |현재 커스텀 소지품을 위력40(강화55)으로 던져 소비. 보호 등에 막혀도 소비. 무소지/매직룸/금제 중에는 비용 없이 사용 거절. 장비별 신규 위력/상태 효과는 도입하지 않음 |
| 리사이클278 |무소지 상태에서 자신의 이번 전투 마지막 내던지기 소비물을 복구. 복구 뒤 기록 소비. 탁쳐서떨구기/부식가스의 제거물은 복구하지 않음 |
| 금제373 |대상5상대 행동 동안 소지품 효과/도구 카드/내던지기 금지. 소지품 소유권은 유지. 교대 시 해제. 매직룸과 동시에 있어도 각각의 잔여 기간을 유지 |
| 부식가스810 |보호/대타/공중에 막히지 않은 상대 장비 제거. 리사이클로 복구 불가 |

교환/전달/제거/소비는 전투 안에서만 적용하고,교대 후에도 실제 전투 소지품은 유지한다. 전투 종료/재시작 때 양쪽 원래 장비로 복구한다. 영구 장비/가방/보상 수량은 바꾸지 않으며 상대 장비를 영구 획득하거나 장비를 복제하지 않는다. 기존 보스가 장비를 제거한 경우 기존 복구를 먼저 실행한 뒤 새 원래 장비 기록을 적용한다. 이미 받은 보호막/강화는 소급 회수하지 않는다.

사우전드웨이브615는 기존v16의 구속/공중 빗나감 규칙을 유지하고 애로와 구분한다. 실제 연무의 뛰어오르기 준비 취소,플레이어 공중 충전에 대한 일반 NPC 애로,챔피언 그린의 따라하기로 복사한 애로를 확인했다. 복사 기억에는 실제614를 기록한다. 접지/필드/원더룸·보호/대타와 카드 UID/소유자·강화/비용은 기존 규칙을 따른다.

## 코드와 저장 계약

- `scripts/tactics/player_move_items.gd` / `data/player_move_items_v17.json`;선택 `item_context={base,spent,embargo}`. 개체UID별 원래 장비/내던지기 소비물/금제 기간. 복원 시 현재 전투 장비는 포켓몬의 기존 `held_item` 필드에서 읽고,전투 종료에만 `base`로 원래 소유권을 복구한다. 이전 원정은 빈 새 문맥도 거절한다.
- 소지품 효과는 기존 `TacticalBattle.effective_item()`에 금제 조건 추가. 도구 거절은 공통 `PlayerTechniques.reason()`을 거치므로 카드/에너지/교대를 바꾸지 않는다. BattleFrame은 문맥을 복제한다.
- `player_move_item_math.gd`는 동결v12 피해 함수와v10 상대 미리보기만 파생. 애로 계산의 명시적 기술ID와 공중 예외614/615 수정만 적용한다. `tools/derive_player_item_math.py --game-dir .`로 재생성하며 입력 엔진 SHA 확인. 공통 보스 훅의 애로 어댑터는 보호/대타를 유지하고 복사 기억에 가짜ID를 남기지 않는다.
- `tools/import_player_move_items.py`는v16 기반 SHA와v10→v16 체인/고정CSV4종 SHA를 확인한다. 기존 공격 강화 유지,변화 기술 강화는 비용-1.

## 최소 검사와 다음 작업

`tools/check.py --suite player-items`는 `tests/test_player_move_items.gd` 한 스크립트만 실행한다.8개 순수 미리보기/강화,애로의 첫 상성/착지·실제 공중 준비/복사,장비 교환/전달/소비/복구·보호/대타·매직룸/금제,원래 장비 복구,새/실제 이전 저장과 동일 입력·오염 거절을 묶었다. 전체919기술/과거 전체 suite/전체69전은 반복하지 않는다. 구체적 수정/미확인 위험에만 관련 사례를 추가한다. 실제 창/native/X11·EXE/빌드는 사용자 지시대로 보류.

목록 밖508기술에는 기본 공격/부가효과도 포함하며,설명 없이 보호막5인 변화 기술48개가 우선 후속 대상이다. 다음은 간파/명중 보조와 남은 행동·팀 보조 기술의 카드 각색. 특성/PP·전투 전용 변신 전체는 자동 추가하지 않는다.
