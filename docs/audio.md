# 전투 효과음과 음량

카드 사용·공격 준비·타격·보호막·회복·포켓볼 교대와 전투 결과에 서로 다른 짧은 효과음을 연결했다. 전투 계산이 확정되는 순간에는 소리를 내지 않고 화면에서 해당 단계가 재생될 때 낸다. 전투 연출을 1.5/2배로 바꾸면 재생 간격은 따라가며 음높이는 유지한다.

[15종 효과음 모음 듣기·다운로드](audio/effects-preview.wav) · [원본 WAV](../assets/audio/effects)

모음의 순서는 아래 표와 같다. 각 소리 사이에 0.35초를 두었다.

| 순서 | 파일 | 재생 시점 |
|---|---|---|
| 1 | ui_click | 일반 UI 버튼을 누를 때. 손패 호버에는 소리를 내지 않는다. |
| 2 | card_play | 도구·트레이너 카드, 공격이 아닌 기술의 사용 단계 |
| 3 | attack | 아군/적의 공격 준비 동작 |
| 4 | hit | 실제 HP 피해 표시 |
| 5 | block | 보호막으로 피해를 전부 막은 타격 |
| 6 | shield | 보호막 획득 표시 |
| 7 | heal | HP 회복 표시 |
| 8–9 | recall / release | 포켓볼 회수와 다음 포켓몬 등장 |
| 10 | status | 상태·능력 변화·지속 효과·유물 발동 |
| 11 | knockout | 기절 표시 |
| 12 | capture | 포획 성공 표시 |
| 13 | turn | 턴 시작 안내 |
| 14–15 | victory / defeat | 승리/패배 연출이 끝나고 결과를 보여줄 때 |

보호막·회복·피해가 0이면 해당 변화 소리를 내지 않는다. 포획으로 끝난 전투는 포획 소리 뒤에 승리 소리를 겹치지 않는다. 장면 전환 시 이전 장면의 효과음을 정지한다.

![음량 설정](images/settings.png)

시작 화면·전투 메뉴·야영지의 [설정창](settings.md)에서 전체 음량과 효과음 음량을 0~100%로 조절한다. 슬라이더를 누르거나 드래그하고, 선택된 슬라이더는 좌우 화살표로 1%씩 바꾼다. `음소거`와 `효과음 듣기`도 제공한다. 기본값은 전체 75%·효과음 80%이며 다음 실행 때 복원한다. 기존 설정 파일에는 새 항목의 기본값을 적용한다.

음소거/음량 0은 현재 소리를 정지하고 새 소리를 쌓아 두지 않는다. 음량을 다시 올려도 지나간 행동의 소리를 뒤늦게 재생하지 않는다. [장면별 배경 음악](music.md) 5곡과 음악 전용 음량을 지원한다. [포켓몬별 울음소리](cries.md) 386종과 별도 음량·미리 듣기도 지원한다.

## 제작과 구조

`tools/generate_sound_effects.py`로 직접 합성한 44.1kHz·모노·16비트 PCM WAV 15종이다. 이 15종 효과음은 외부 게임 음원을 사용하지 않았다. 별도로 가져온 포켓몬 울음소리는 [출처 문서](cries.md)를 따른다. 짧은 페이드와 보수적인 피크를 적용하고 생성용 난수는 별도 고정 시드만 사용한다. 게임 난수에는 접근하지 않는다.

```bash
python3 tools/generate_sound_effects.py          # 원본과 검토용 모음 재생성
python3 tools/generate_sound_effects.py --check  # PCM·형식·페이드·피크·재현성 검사
godot --headless --path . --script res://tests/test_audio.gd
```

`GameAudio` 자동 로드는 효과음 플레이어 6개와 UI 전용 플레이어 1개를 재사용한다. `Effects → Game → Master`로 보내며 효과음/전체 음량을 각각 독립적으로 적용한다. 배경 음악은 `Music → Game → Master`로 보내 음악 전용 음량과 전체 음량/음소거를 공유한다. `BattleSoundCues`는 이미 확정된 표시 이벤트에서 소리만 고르며 모델·카드·자원·난수·원정 저장을 변경하지 않는다.

검사는 Linux / Godot 4.7.2 기준이다. `AudioEffectCapture`로 실제 믹서의 비무음·음량 비율·무음을 측정한다. 클라우드는 Dummy 출력 드라이버이며 실제 스피커 청음과 Windows 오디오 장치 검증은 별도다.
