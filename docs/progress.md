# 개발 진행 현황

현재는 **시작부터 챔피언까지 플레이 가능한 초기 알파**다. 전체 진행을 연결한 뒤 전투의 선택과 콘텐츠 품질을 다듬는 단계이며, 출시 준비가 끝난 상태는 아니다. 퍼센트 대신 실제 구현 범위와 남은 작업으로 관리한다.

## 아직 완성되지 않은 부분

- **빌드의 폭과 밸런스:** 공용 카드·유물·지닌 물건은 첫 구성이다. 같은 파티가 보상에 따라 다른 운영을 하도록 조합을 늘리고, 보상 가치·상점·회복 경제·초반 관장 대진·플레이 시간을 조정해야 한다.
- **원작 규칙의 깊이:** 386종과 354개 기술의 데이터가 있으나 기술 효과 일부는 카드 전투용으로 간소화했다. 개별 특성·날씨·확률·고정 피해·다단 공격 등을 모두 원작처럼 재현하지 않았다. 돌·친밀도·통신 등 특수 진화는 미구현이다.
- **적의 개성:** 네 역할 체계를 구현했고 인물별 전용 기믹·트레이너 카드·보스 고유 보상은 후속 단계다.
- **희귀 콘텐츠:** 전설·환상 21종은 일반 출현에서 제외한 상태다. 전용 탐색·조건부 전투·희귀 포획 이벤트는 아직 없다.
- **완성도·배포:** 사운드·음악·세부 옵션, 장시간 수동 플레이와 파티별 난도 검증, Windows 실행 파일·내보내기·호환성 검증이 남아 있다. 현재 실행 검증은 Linux/Godot 4.7.2 기준이다.

## 다음 개발 순서

1. 확장한 [카드·유물 조합](build-synergies.md)을 수동 플레이와 파티별로 비교하고 한 가지 운영이 과도하게 유리한지 조정한다.
2. 구현한 [카드 상점](merchant.md)의 가격·보상 가치·골드 지출과 강화/제거/휴식 선택을 수동 플레이 지표로 비교·조정한다.
3. 공통 적 역할 위에 관장·사천왕·챔피언의 고유 전술을 추가하고 빌드별 대응을 검증한다.
4. 특수 진화와 조건부 희귀 포획을 구현해 수집의 장기 목표를 만든다.
5. 사운드·설정·안내를 다듬고 Windows 빌드로 배포 전 검증을 진행한다.

각 단계에서도 최대 3마리 스타팅·69전투·경험치 성장·챔피언 전원 Lv.100·자동 저장을 유지한다. 자유 분기 지도나 4세대 이후 종을 현재 범위에 조용히 추가하지 않는다.

## 이번 작업과 검증 기록

[야영지 상점](merchant.md)에 조합 지원 공용 카드·다른 공용 카드·파티 기술 사본의 세 칸 진열과 한 장 20골드 할인, 지역별 가격·매진·보유 장수 표시를 추가했다. 카드 구매·보급품·제거를 같은 화면과 골드로 선택하며 휴식/강화는 별도 행동으로 유지한다. 기존 v3 원정과 이미 방문한 상점의 재고를 유지하고 새 상인부터 카드 진열을 제공한다.

규칙 검사 1,199개, 실제 X11 UI 검사 30개(마우스 16회)를 통과했다. 세 창 비율에서 구매 버튼 위/중앙/아래, 매진·제거·휴식·모달 차단과 자동 저장을 실행하고 1920×1080 화면을 확인했다. 별도 프로세스 다섯 개로 구매 후 종료·재실행·가격과 매진 유지·추가 구매·백업 복구를 확인했다.

고정 시드 0/42/2026은 혼합 보상·장비·야영지 선택에 상인 카드 세 장 구매/저장 복원까지 포함해 각각 69전투를 완주했다(통합 검사 185개). 전체 저장 검사 1,807개와 기존 야영지 UI 검사 48개도 통과했다. Godot 4.7.2에서 임포트·파싱을 확인했다. 자동 정책 결과는 모든 구매 선택의 가치나 사람의 재미를 보장하지 않으며, 경제 밸런스와 Windows 빌드는 추가 검증 범위다.

지난 조합 확장에서는 신규 규칙 610개와 실제 UI를 확인했고, 30개 시드의 기존 자동 정책은 28개 완주·2개 실제 전멸로 종료했다. 이번 상점 검증을 그 전체 시드의 재측정으로 해석하지 않는다.
