# 개발 진행 현황

현재는 **시작부터 챔피언까지 플레이 가능한 초기 알파**다. 전체 진행을 연결한 뒤 전투의 선택과 콘텐츠 품질을 다듬는 단계이며, 출시 준비가 끝난 상태는 아니다. 퍼센트 대신 실제 구현 범위와 남은 작업으로 관리한다.

## 아직 완성되지 않은 부분

- **빌드의 폭과 밸런스:** 공용 카드·유물·지닌 물건은 첫 구성이다. 같은 파티가 보상에 따라 다른 운영을 하도록 조합을 늘리고, 보상 가치·상점·회복 경제·초반 관장 대진·플레이 시간을 조정해야 한다.
- **원작 규칙의 깊이:** 386종과 354개 기술의 데이터가 있으나 기술 효과 일부는 카드 전투용으로 간소화했다. 개별 특성·날씨·확률·고정 피해·다단 공격 등을 모두 원작처럼 재현하지 않았다. 지원 범위의 진화 184경로를 연결했으며 개별 특성·기술의 원작 효과 재현은 계속 확장해야 한다.
- **적의 개성:** 인물별 파티 전술을 구현했다. 아홉 가지 공통 유형을 조합한 첫 구성이며 인물 전용 카드·대사·초상·고유 보상과 체력 구간별 변화는 후속 단계다.
- **희귀 콘텐츠:** 세 등급 21종의 조건부 도전·포획·영구 해금을 연결했다. 종별 전용 대사·유적 그래픽·특성·전용 보상과 희귀 스타팅의 반복 플레이 균형은 후속 단계다.
- **완성도·배포:** 사운드·음악·세부 옵션, 장시간 수동 플레이와 파티별 난도 검증, Windows 실행 파일·내보내기·호환성 검증이 남아 있다. 현재 실행 검증은 Linux/Godot 4.7.2 기준이다.

## 다음 개발 순서

1. [원정 기록](run-records.md)으로 카드·유물 조합과 [보스 전술](boss-tactics.md) 대응을 수동 플레이·파티별로 비교하고 운영을 조정한다. 초반 영입 측정에서 남은 약한 편성·고스트 상성의 장기 전투를 포획 판단·진화/기술 습득 시점과 함께 조사한다.
2. 카드 상점 가격·보상 가치·골드 지출과 강화/제거/휴식 선택을 실제 기록으로 비교·조정한다.
3. 세 등급 희귀 조우의 실제 포획 난도·희귀 스타팅의 반복 플레이를 비교하고 종별 콘텐츠를 보강한다.
4. 사운드·설정·안내를 다듬고 Windows 빌드로 배포 전 검증을 진행한다.

각 단계에서도 최대 3마리 스타팅·69전투·경험치 성장·챔피언 전원 Lv.100·자동 저장을 유지한다. 자유 분기 지도나 4세대 이후 종을 현재 범위에 조용히 추가하지 않는다.

## 이번 작업과 검증 기록

[포획 후 합류 미리보기](recruitment.md)를 추가했다. 실제 추가/제거 카드 얼굴과 소유 포켓몬·강화·부상, 합류 후 덱 장수, 반환 장비를 보고 편성을 확정한다. 빈자리는 기존 파티를 보존한다. 목록으로·Esc·바깥 클릭은 조회만 취소하며 포획 대기·영구 해금을 유지한다. 확정만 실제 파티/덱 변경과 자동 저장을 호출한다. 기존 포획·성장·69전투·희귀 조건·저장 형식을 바꾸지 않았다.

규칙/비교 정책 479개와 실제 X11 UI 34개 검사·포인터 25회를 통과했다. 세 창 비율의 위/중간/아래 클릭, 카드 탭·긴 제거 목록 스크롤·모달 차단·취소·Esc·합류·자동 저장을 확인하고 1920×1080 화면을 검토했다. 실제 카드 행동으로 주뱃을 포획한 뒤 세 별도 프로세스에서 미확정 포획 저장 → 재실행/합류/다음 전투 행동 → 재실행/승리/XP 정산을 확인했다(78개 검사).

[초반 영입 비교](balance-measurements.md)의 8개 편성·10시드·두 정책 160개 실행 중 159개는 정상 완주/전멸로 끝났고 혼합 편성 시드 5의 고스트 야생 1개는 200턴 안전 한도로 중단했다. [종료 보고서](measurements/campaign-recruitment.md)에서 제외하고 [미완료 원본](measurements/campaign-recruitment-incomplete.json)을 별도로 남겼다. 이상해씨 단독은 완주 0→5/10, 잉어킹 단독·물 보조형은 여전히 0/10이다. 포획 시도의 카드 선택만으로도 결과가 달라지므로 영입이 없던 아기 편성의 개선을 영입 효과로 해석하지 않는다. 포획 시도 때문에 일찍 전멸한 시드도 있다.

별도 프로세스 12개 재측정에서 모든 필드·지문이 일치했고 영입 없는 관동 10개는 기존 핵심 측정의 모든 필드를 유지했다. 보고서 검사 14개, 시작 규칙 34개·시작 UI 26개·희귀 UI 47개·저장 1,771개·연출 26개와 고정 시드 0/42/2026의 69전투·엔딩/덱 원정 194개 검사를 통과했다. Linux/Godot 4.7.2 기준이다. 전투 장기화의 재현 원인·파티별 수동 밸런스·Windows 검증은 남아 있다.

## 이전 핵심 유물 검증 기록

[핵심 유물 5종](core-relics.md)을 추가했다. 관장 승리 후 시드 고정 세 후보에서 원정당 하나를 선택하고 교대·에이스·상태·보호막·소진 도구 운영의 효과와 대가를 적용한다. 일반 유물 10종은 계속 함께 모을 수 있다. 아직 선택하지 않았다면 다음 관장에 다시 기회를 받으며, 마지막 관장에서도 넘기면 핵심 없이 리그로 진행한다. 기존 보상·진행 중 전투를 재추첨하거나 저장을 초기화하지 않는다.

핵심 규칙 357개 검사로 발동 제한·대가·카드 미리보기/실제 수치·할인 대상 고정·강제 교대·기존 효과 조합·저장/복원·중복 보유와 이전 보상 보존을 확인했다. 세 별도 Godot 프로세스로 실제 첫 관장 보상 → 선택/다음 전투 행동 → 이어하기/승리/중복 정산 방지를 확인했다. 실제 X11 UI 39개 검사·클릭 7회·휠로 세 창 비율의 선택, 핵심 우선 표시와 11개 유물 메뉴의 끝 접근·버튼 겹침 방지를 확인했고 1920×1080 화면을 검토했다.

[현재 비교 측정](measurements/campaign-core-relics.md)은 관동 파티·10시드·여섯 보상 정책·두 야영지 운영의 120개 원정이다. 정상 완주 114개는 핵심 다섯 종류에 따라 최종 유물 구성이 나뉘었다. 이전 같은 조건의 관동 완주 115개는 모두 같은 10종을 모았다. 일반 유물의 수렴은 남아 있고, 핵심 효과만으로 모든 조합의 난도와 재미가 확정된 것은 아니다. 12개를 별도 프로세스에서 재측정해 모든 필드가 일치했다. 보고서 검사 10개도 통과했다.

기존 공유 덱 632개·조합 610개·능력치 55개·저장 1,771개·파일 복구 23개·이전 저장 능력치 호환 390개·연출 26개·덱 UI 33개·조합 UI 14개를 통과했다. 고정 시드 0/42/2026은 69전투를 완주하고 덱 원정 194개 검사를 통과했다. 30시드 원정은 29개 완주·1개 실제 전멸로 23,768개 검사를 통과했다. Linux/Godot 4.7.2 기준이며 다른 파티·초반 포획/영입·수동 밸런스·Windows 검증은 남아 있다.

## 이전 강화 비교·400개 원정 측정 기록

[야영지 카드 강화 비교](camp-upgrade-preview.md)를 추가했다. 카드 선택 후 현재/강화 후 카드 얼굴·비용·효과와 소유 포켓몬을 비교하고 확정한다. 취소와 Esc는 자원을 바꾸지 않고 카드 목록으로 돌아간다. 확정만 기존 강화 행동과 자동 저장을 호출하며 휴식·조사와 주 행동을 공유한다. 실제 X11 27개 검사·포인터 21회·Esc 세 번과 세 창 비율, 1920×1080 화면 검토를 통과했다. 덱 UI 33개·상인 UI 27개·야영지 UI 48개도 통과했다.

[현재 능력치 측정](measurements/campaign-species-level.md)을 10개 시드·400개 원정으로 갱신했다. 15개 파티와 관동 파티의 다섯 보상 주제를 휴식/육성 두 운영으로 비교한다. 육성 정책은 실제 재료 구매·사용·강화·유료 제거와 회복·친밀도를 사용하며 경제 항목을 나눠 기록한다. 기존 공식의 60개 표본과 분리하고, 양쪽 모두 완주한 같은 시드 쌍을 따로 비교한다.

관동 기본은 두 운영 모두 10/10 완주, 평균 283.3→255.7턴이다. 벌레는 0→2/10, 고스트는 2→4/10 완주했으나 성도 기본은 9→8/10으로 줄었다. 휴식 포기의 비용과 정책 편향이 있으므로 육성을 항상 우월한 선택으로 해석하지 않는다. 아기·물 보조형·단독 편성은 이번 영입 없는 정책에서 모두 완주하지 못했다. 관동 완주 115개의 최종 유물은 10종으로 같아졌으며 조합 수렴은 계속 보강할 지점이다.

모든 400개가 정상 완주/전멸로 끝났고 집계가 유효했다. 별도 프로세스 12개 원정을 재측정해 모든 필드가 일치했으며 새 도구의 휴식 운영은 도구 확장 전 새 능력치로 실행한 기존 정책 60개 결과를 그대로 유지했다. 측정 정책 21개·보고서 9개 검사와 잘못된 CLI 선택 5개를 통과했다. 피츄·삐·푸푸린의 시드 5 관장전이 116턴에 정상 종료됨을 확인해 모든 측정에 200턴 안전 제한을 명시했다. 기본 한도 100턴과 원정 15,000행동 제한은 유지하고 미완료는 보고서에서 거부한다. 종족값·카드 수치·적 레벨·희귀 조건과 저장 형식은 이번 작업에서 바꾸지 않았다. 사람의 승률·수동 밸런스·Windows 검증은 별도다.

## 이전 개체값·노력치 제거 검증 기록

개체값·노력치를 제거하고 아군·적의 여섯 능력치를 종족값·레벨만으로 계산한다. 카드·상태의 전투 보정은 유지한다. 배루키는 능력치 훈련 대신 야영지에서 세 진화 중 하나를 선택하고 다음 Lv.20 이상 레벨업에 자동 진화한다. 기존 v3 저장은 잃은 HP·기절·카드·자원·난수·진행을 보존해 변환하며 예전 배루키 준비도 진화 선택으로 이어진다. 현재 턴 에너지를 다시 주거나 포획·승리 보상을 중복 정산하지 않는다.

능력치 55개·성장 42,937개·특수 진화 302개·이전 실제 저장 호환성 390개·출발 덱 6,963개·연출 26개 검사를 통과했다. 기존 60개 밸런스 측정은 이전 능력치 규칙의 기록으로 표시했으며 이번 공식의 난도 근거로 사용하지 않는다. 실제 X11 UI 53개 검사(포인터 48회·키 9회), 세 창 비율·1920×1080 진화 선택 화면을 확인했다. 여섯 별도 Godot 프로세스의 준비·경험치 진화·재실행·추가 합류를 통과했다. 전체 저장 1,771개·파일 복구 23개·희귀 조우 1,329개·적 전술 6,993개·보스 전술 6,338개도 통과했다. 기본 정책 30시드는 29개 완주·1개 실제 전멸로 23,770개 검사를 통과했고, 고정 시드 0/42/2026의 덱 원정 194개 검사도 모두 69전투를 완주했다. 이는 자동 정책 결과이며 Windows와 파티별 수동 밸런스 검증은 남아 있다.

## 이전 출발 덱·측정 검증 기록

먼저 [출발 덱·Lv.5 능력치 미리보기](starter-loadout.md)를 연결했다. 스타팅 선택에서 원래 배운 기술과 실제 출발 카드, 발버둥이 필요한 동료, 여섯 능력치와 희귀 분류를 확인한다. 전체/공용/소유자 필터·실제 카드 얼굴·휠 탐색을 제공하며 새 원정 확정 전에는 현재 원정·영구 도감·난수·자원을 바꾸지 않는다. 종족값·원작 기술·경험치·69전투·희귀 조건은 그대로다.

## 이전 희귀 조우 검증 기록

## 이전 보스 전술 검증 기록
