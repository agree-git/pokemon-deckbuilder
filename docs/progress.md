# 개발 진행 현황

현재는 **시작부터 챔피언까지 플레이 가능한 초기 알파**다. 전체 진행을 연결한 뒤 전투의 선택과 콘텐츠 품질을 다듬는 단계이며, 출시 준비가 끝난 상태는 아니다. 퍼센트 대신 실제 구현 범위와 남은 작업으로 관리한다.

## 아직 완성되지 않은 부분

- **빌드의 폭과 밸런스:** 공용 카드·유물·지닌 물건은 첫 구성이다. 같은 파티가 보상에 따라 다른 운영을 하도록 조합을 늘리고, 보상 가치·상점·회복 경제·초반 관장 대진·플레이 시간을 조정해야 한다.
- **원작 규칙의 깊이:** 386종과 354개 기술의 데이터가 있으나 기술 효과 일부는 카드 전투용으로 간소화했다. 개별 특성·날씨·확률·고정 피해·다단 공격 등을 모두 원작처럼 재현하지 않았다. 돌·친밀도·통신 등 특수 진화는 미구현이다.
- **적의 개성:** 네 역할 체계를 구현했고 인물별 전용 기믹·트레이너 카드·보스 고유 보상은 후속 단계다.
- **희귀 콘텐츠:** 전설·환상 21종은 일반 출현에서 제외한 상태다. 전용 탐색·조건부 전투·희귀 포획 이벤트는 아직 없다.
- **완성도·배포:** 사운드·음악·세부 옵션, 장시간 수동 플레이와 파티별 난도 검증, Windows 실행 파일·내보내기·호환성 검증이 남아 있다. 현재 실행 검증은 Linux/Godot 4.7.2 기준이다.

## 다음 개발 순서

1. 구현한 [원정 기록](run-records.md)으로 카드·유물 조합을 수동 플레이와 파티별로 비교하고 과도하게 유리한 운영을 조정한다.
2. 카드 상점 가격·보상 가치·골드 지출과 강화/제거/휴식 선택을 실제 기록으로 비교·조정한다.
3. 공통 적 역할 위에 관장·사천왕·챔피언의 고유 전술을 추가하고 빌드별 대응을 검증한다.
4. 특수 진화와 조건부 희귀 포획을 구현해 수집의 장기 목표를 만든다.
5. 사운드·설정·안내를 다듬고 Windows 빌드로 배포 전 검증을 진행한다.

각 단계에서도 최대 3마리 스타팅·69전투·경험치 성장·챔피언 전원 Lv.100·자동 저장을 유지한다. 자유 분기 지도나 4세대 이후 종을 현재 범위에 조용히 추가하지 않는다.

## 이번 작업과 검증 기록

[원정 기록](run-records.md)에 전투별 실제 HP 피해·기절·카드/유물 사용, 골드 수입과 지출, 카드·보상 선택·구매·강화·제거를 추가했다. 지도·야영지·결과 화면의 버튼 하나에서 상세 세 탭을 확인한다. 실제 행동만 집계하고 중복 정산·미리보기·연출 재생은 통계를 늘리지 않는다. v3 저장은 유지하며 과거 기록이 없으면 업데이트 이후 부분 집계를 표시한다.

신규 규칙 검사 100개와 실제 X11 기록 UI 검사 25개(마우스 16회·Esc)를 통과했다. 세 창 비율의 탭 클릭, 모달 차단·닫기, 69전투 챔피언 결과와 패배·이전 저장 안내를 실행하고 1920×1080 화면을 확인했다. 별도 프로세스 다섯 개로 전투·야영지의 기록을 포함한 저장/재실행/구매·백업 복구를 확인했다.

고정 시드 0/42/2026은 카드 구매·보상·장비·저장 복원까지 포함해 각각 69전투를 완주했다. 통합 검사 194개는 69개 기록의 유일성과 합계, 카드별 사용 횟수, 파티 구급함 발동 69회와 최종 골드의 수입/지출 일치를 확인했다. 전체 저장 1,807개·기본 카드 전투 660개·상점 규칙 1,199개·연출 26개 검사도 통과했다. 경제 균형과 파티별 재미를 확정한 결과는 아니며 수동 비교와 Windows 검증은 남아 있다.

현재 기록은 진행 중인 도전과 해당 결과 화면에서 확인한다. 완료 원정 목록·플레이 시간·원인별 피해 기여도는 후속 범위다.
