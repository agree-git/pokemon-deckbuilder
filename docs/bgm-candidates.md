# BGM 후보 35곡

확인: 2026-10-18 (Asia/Seoul). 사용자가 추천한 순서다. **추천 35항목·개별 음원 페이지 36개**를 확인했다. 창공날기는 낮/밤 두 곡을 함께 남겼다. 게임에는 적용하지 않았다.

후속 작업: 위 문서는 외부 출처를 조사했을 당시의 기록이다. 이후 사용자가35곡을4개ZIP으로 직접 첨부하고 게임 적용을 요청했다. 현재 사용자 제공 파일의 변환·보관·적용 상태는 [오디오 manifest](https://github.com/agree-git/pokemon-deckbuilder/blob/main/assets/audio/region_music/manifest.json)와 [HANDOFF](../HANDOFF.md)를 따른다. 제공된 창공날기는 `Soaring Dreams` 한 곡이다.

## 이번에 확인한 범위

아래 링크는 비공식 음악 카탈로그의 **곡별 HTML 페이지**다. MP3처럼 끝나는 주소도 이 사이트에서는 재생/다운로드 안내 페이지이며, 오디오 바이너리 주소가 아니다. 36개 페이지 모두 MP3와 FLAC 다운로드 버튼을 확인했다. 실제 파일 다운로드·디코딩·청취는 하지 않았으므로 파일의 무결성·음질·루프·버튼을 누른 뒤의 다운로드 성공을 검증한 결과가 아니다. 링크는 변경될 수 있다.

**다운로드·GitHub 업로드한 음원 파일은 0개다.** 파일 재업로드 허가를 확인하지 못했기 때문에 조사 목록만 자료 브랜치에 보관한다. 원본 녹음 대신 팬 커버/MIDI/리마스터로 임의 대체하지 않았다.

## 재업로드 조건

[Pokémon Game Sound Library 공식 가이드라인](https://soundlibrary.pokemon.co.jp/en/download)은 해당 사이트에서 직접 다운로드한 데이터에 적용된다. 제3자에게 음원 데이터를 다시 배포하는 행위와 게임·앱·소프트웨어·프로그램에서의 사용을 제한한다. 무료 다운로드를 GitHub 재게시나 팬게임 배포 허가로 해석할 수 없다. 이 조건이 아래 모든 외부 카탈로그의 이용약관이라는 뜻은 아니며, 아래 자료의 별도 재업로드/게임 이용 허가는 확인하지 못했다. 권리자의 허가가 확인되기 전에는 원곡 파일을 이 저장소에 넣지 않는다.

## 버전 선택 메모

- DPPT는 DS판 DP 공식 OST 카탈로그로 대응했다. BDSP·팬 restored/remastered 버전은 제외했다. 낮/밤을 지정하지 않은 항목은 낮/기본 버전을 우선 후보로 기록한 것이며 최종 선택은 아니다.
- HGSS는 DS 리메이크 음원으로 대응했다. 같은 앨범의 CD3 GB Sounds는 제외했다.
- ORAS는 3DS 리메이크 음원으로 대응했다. 같은 앨범에 함께 들어 있는 RS(GBA) 원곡은 제외했다.
- 축복시티는 **XY 이설시티 집에서 연주하는 `How About a Song? "Jubilife City"`**다. DP 축복시티 기본곡 및 XY 이설시티 자체 테마와 다르다.
- 미로마을은 **Littleroot Town**이다. 황금마을(Pacifidlog Town)이 아니다.
- 창공날기는 `Soaring Dreams`와 `Soaring Illusions`를 모두 기록했다. 시간의 톱니바퀴는 탐험대 DS판 기본 `Time Gear`이며 Remix/Reprise/팬 편곡과 구분했다.
