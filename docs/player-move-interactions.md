# 기술 상호작용 보완 · v24 / 효과16

새 원정에 v23의 일괄 조정과 v24의 접촉·음성·대타/보호 상호작용을 함께 적용한다. 기존 v1~v23의 정의·저장·다음 입력과 RNG는 이전 버전 분기를 유지한다. 새 영구 문맥은 없고 기존 문맥 검증에 효과16만 허용한다.

## 적용 내용

- 전체919기술의 플래그 중 접촉(1)·음성(9)·대타 관통(14)만 대조한다. 36개 기술에39개 사실을 추가했다. 고유 효과를 새로 구현한 기술 수가 아니며 v23의 개별 특징/각색586개·기본 효과333개 분류는 유지한다.
- 접촉 판정을 울퉁불퉁멧,킹실드·실크트랩 등과 양쪽 공격에 연결한다. 특수 기술인 라이트닝드라이브879도 접촉하며 비접촉 트윈빔888은 반응하지 않는다. 연타 도중 접촉 반격으로 시전자가 쓰러지면 남은 타격은 중단한다.
- 플레어송871·매혹의보이스914·사이코노이즈917은 음성 기술로 대타를 관통하며 지옥찌르기에 봉인된다. 혼란/치유 봉쇄 같은 부가 효과도 같은 판정을 쓴다. 드래곤옐913의 대타 관통 정보도 보완한다.
- 하이퍼드릴887·파워풀에지910은 보호를 관통하되 보호 상태를 지우지 않는다. 다음 일반 공격에는 보호/접촉 반격이 정상 적용된다. 대타는 관통하지 않으며 버티기는 기존 동작을 유지한다. 파워풀에지의 잘못된 상대 공격 저하도 제거했다.
- 공격 실패·준비 중·보호·타입 무효인 공격의 명중 후 자기 능력 변화는 적용하지 않는다. 정상 명중한 인파이트의 방어 저하와 일렉트로빔905의 공격 전 특수공격 상승은 유지한다. 미리보기·실행·복사 기술에 같은 판정을 연결한다.

## 출처와 생성

기초 사실은 [Pokémon Showdown의 고정 data/moves.ts](https://github.com/smogon/pokemon-showdown/blob/7b02eb39878f4b486f658a752b38c161379bd352/data/moves.ts)와 기존 PokéAPI 플래그를 대조했다. 커밋 `7b02eb39878f4b486f658a752b38c161379bd352`,git blob `d240d3e4d4e32fa9ded709110d80a20133b105ce`,원본 SHA256 `61ab107dae9628d79ac61da16c72e8565f6a1211874298e00c77c5c0ac9755a7`. MIT 고지는 게임의 `licenses/pokemon-showdown-MIT.txt`에 보존한다. 외부 TypeScript를 실행하지 않고 필요한 수치 ID/필드만 파싱한다.

원본에서 물리/특수 Z기술이 같은 항목을 공유해 별도 ID가 없는18건(623~657의 홀수)은 기존 플래그를 유지한다. 다른 플래그도 바꾸지 않는다. 최신 세대의 모든 예외·폼·확률·원작 효과를 완성했다는 의미는 아니다.

```sh
python3 .dev-materials/tools/import_player_interactions.py --game-dir . --cache-dir /path/to/cache
python3 .dev-materials/tools/derive_player_interaction_hooks.py --game-dir .
```

캐시의 고정 원본 `moves.ts`를 SHA/깃 blob으로 검증한다. 기반v23 JSON과6개 동결 엔진도 SHA를 확인한다. `PlayerMoveInteractions`는 정의/순수 미리보기,`PlayerInteractionHooks`는 동결 소스에서 파생한19개 훅이다. 새 JSON SHA256 `9cda3ca64e304c33c24777c90ed83b54a3e897db4d3e17d7ae1b51bc70003341`,파생 훅 `05e6d86180b26b1c0bf146093fce3e8131a3b645aa856df4c11a3e9bd70ac567`.

## 검사

`tools/check.py --suite player-interactions --timeout 90`에36개 순수 미리보기/강화,양방향 상호작용,실제 새 저장/같은 다음 입력,사전v23 상태/다음 입력/RNG/지문을 묶었다. 당시140검사 중3건이 보호 관통의 최종 흡수 단계에서 실패했다. 수정 뒤 실패했던 세 경우만6검사(카드 사용3+결과3)/실패0으로 확인했다. 전체140은 재실행하지 않았다. 마지막 검토에서 사우전드애로의 공중 판정용 임시 ID를 원래 ID로 복구하고 이 경계만3검사/실패0으로 확인했다. 상세는 [검증 기록](validation.md)의v24 절을 따른다. 실제 창·EXE·전체919실행/69전 검사는 보류했다.
