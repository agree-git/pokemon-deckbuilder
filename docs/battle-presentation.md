# 전투 연출과 가방

전투의 계산과 화면 재생을 분리한다. 카드 사용·교대·턴 종료 요청 하나는 모델에서 한 번에 확정하고 자동 저장한다. 화면은 이벤트에 기록한 포켓몬·체력·보호막·상태·에너지의 중간 상태를 순서대로 재생한다. 연출 중에는 추가 전투 입력과 메뉴 열기를 막는다. 연출을 종료하거나 저장 후 다시 열어도 피해나 에너지를 중복 적용하지 않는다.

- 다른 동료의 기술 카드 또는 수동 교대: 기존 포켓몬 축소·회수 빛·포켓볼 이동 → 새 포켓몬 등장·확대 → 기술 동작.
- 적 파티의 다음 포켓몬도 교체 연출 후 등장한다. 기절 동작은 해당 출전 포켓몬에만 적용한다.
- 공격: 아군·적의 전진 동작 → 기술 이펙트 → 피해·보호막 흡수와 피격 반동 → 상태·회복 등의 효과 → 다음 행동 또는 턴 시작.
- 기술 이름은 중앙 안내로 보여주며 피해·회복·보호막은 별도 색의 숫자로 표시한다. 보호막은 HP 아래에 큰 파란색 아이콘·수치 막대로 보여준다.
- 원정 시작 때도 파티가 이동하는 출발 화면을 거친다. 이후 전투·야영지 사이와 같은 이동 연출이며 첫 출발 중 중복 시작을 막는다.

전투의 남은 카드·버린 카드·소진된 카드 목록은 실제 카드 그림으로 펼친다. 포켓몬 초상·소유자·비용·효과·강화 여부를 손패와 같은 형태로 표시하고, 스크롤로 전체를 본다. 더미의 사본을 정렬하므로 숨은 드로우 순서를 노출하거나 덱 순서를 변경하지 않는다. 목록의 카드는 사용되지 않는다.

야영지 가방은 아이템 그림·이름과 보유 개수만 표시한다. 아이템을 누르면 파티 초상·이름·레벨·체력과 적용 후 체력을 보여주는 대상 선택 창이 열린다. 기절·체력 가득 참 등 사용할 수 없는 대상은 선택하지 못하고, 취소하면 아이템을 쓰지 않는다. 회복약과 기력의조각은 서로 맞는 대상에만 사용하며 몬스터볼은 야생 전투에서 쓴다. 별도 전리품 탭은 제거했다. 전투 보상의 골드·아이템은 기존처럼 자동으로 가방에 들어간다.

`tests/test_presentation.gd`는 교체 전후·공격 준비와 타격 사이의 상태, 공격 동작·보호막, 연출의 모델 불변, 가방 대상 제한·취소, 첫 출발을 검사한다. `native_presentation_probe`는 실제 창의 OS 포인터와 렌더링으로 같은 경로를 확인한다. `native_deck_probe`는 비율별 카드 클릭, 카드 그림 목록, 보상·강화·장비를 검사한다. `test_campaign_ui.gd`는 새 가방 경로를 포함해 69전투와 엔딩까지 입력으로 진행한다.
