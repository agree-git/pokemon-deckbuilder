# 전투 연출과 가방

[전투 효과음](audio.md)은 아래 행동의 표시 단계에 맞춰 재생하며 설정에서 음량과 음소거를 조절한다.

전투의 계산과 화면 재생을 분리한다. 카드 사용·교대·턴 종료 요청 하나는 모델에서 한 번에 확정하고 자동 저장한다. 화면은 이벤트에 기록한 포켓몬·체력·보호막·상태·에너지의 중간 상태를 순서대로 재생한다. 연출 중에는 추가 전투 입력과 메뉴 열기를 막는다. 연출을 종료하거나 저장 후 다시 열어도 피해나 에너지를 중복 적용하지 않는다.

- 다른 동료의 기술 카드 또는 수동 교대: 기존 포켓몬 축소·회수 빛·포켓볼 이동 → 새 포켓몬 등장·확대 → 기술 동작.
- 적 파티의 다음 포켓몬도 교체 연출 후 등장한다. 기절 동작은 해당 출전 포켓몬에만 적용한다.
- 공격: 아군·적의 전진 동작 → 기술 이펙트 → 피해·보호막 흡수와 피격 반동 → 상태·회복 등의 효과 → 다음 행동 또는 턴 시작.
- 기술 이름은 중앙 안내로 보여주며 피해·회복·보호막은 별도 색의 숫자로 표시한다. 보호막은 HP 아래에 큰 파란색 아이콘·수치 막대로 보여준다.
- 원정 시작 때도 파티가 이동하는 출발 화면을 거친다. 이후 전투·야영지 사이와 같은 이동 연출이며 첫 출발 중 중복 시작을 막는다.

[공통 설정](settings.md)에서 전투 연출을 1/1.5/2배로 바꾸고 피격 시 흔들림을 끌 수 있다. 전투 계산과 이벤트 순서는 같으며 손패 호버·메뉴·장소 이동은 원래 속도를 유지한다.

손패는 5장까지 여유 있게 나란히 표시하고, 6~10장은 한 줄 안에서 간격을 줄여 겹친다. 손패를 가로 스크롤하지 않는다. 마우스를 올린 카드는 화면 위로 34px 이동하며 10% 확대되고, 양옆 카드는 가장자리 범위 안에서 옆으로 벌어져 공간을 만든다. 선택한 카드의 가로 위치는 유지해 포인터에서 도망가지 않는다. 벗어나면 원래 배치로 돌아가며, 사용·추가 드로우 뒤에는 남은 카드가 부드럽게 정렬된다. 겹친 영역의 입력은 보이는 카드에 맞추고 호버는 덱·카드 순서·에너지·난수를 바꾸지 않는다.

일반·엘리트 트레이너, 관장·사천왕·챔피언전은 상대 등장 → 던질 준비 → 포켓볼 포물선 → 첫 포켓몬 등장 → 트레이너 퇴장으로 시작한다. 기본 1배에서 약 1.7초 동안 전투 입력을 잠그고 계산은 실행하지 않는다. 같은 전투 객체의 화면을 새로 그릴 때는 반복하지 않고, 이미 카드를 사용한 전투를 이어할 때는 건너뛴다. 첫 행동 전 저장을 새로 불러오면 짧은 도입이 다시 나올 수 있다. 현재 사람 그림은 타입 색·역할에 맞춘 프로젝트 자체 공용 도트 캐릭터다. 각 관장·사천왕·챔피언의 원작 개별 초상/스프라이트를 구현한 것은 아니다.

포켓몬의 상시 상하 흔들림을 제거하고, 투명 여백을 제외한 발끝을 발밑 그림자와 맞췄다. [배경별 접지 좌표](battlefield-layout.md)는 배경 48종의 원본 발판/바닥을 계측해 배경과 같은 변환으로 포켓몬을 배치한다. HP·보호막·연출이 접지점을 따르며 큰 종은 파티 목록/상단 안내와 겹치지 않는 정수 배율을 사용한다. 아군은 왼쪽 아래, 상대는 오른쪽 위에 놓는다. 큰 적의 행동 예고는 실제 스프라이트 크기에 따라 위 또는 옆으로 옮긴다. [리그 실내 스테이지](league-stages.md)는 전문 타입·출신 지방에 따라 별도 배경을 쓴다. 작은 배경 원본을 화면에 확대하는 프레이밍과 화면·UI 해상도는 구별한다.

전투의 남은 카드·버린 카드·소진된 카드 목록은 실제 카드 그림으로 펼친다. 포켓몬 초상·소유자·비용·효과·강화 여부를 손패와 같은 형태로 표시하고, 같은 소유자·강화·내용의 사본은 겹친 카드와 `×N`으로 묶고 스크롤로 전체를 본다. 상단에는 묶음 수가 아닌 실제 장수를 표시한다. 더미의 사본을 정렬하므로 숨은 드로우 순서를 노출하거나 덱 순서를 변경하지 않는다. 목록의 카드는 사용되지 않는다.

야영지 가방은 아이템 그림·이름과 보유 개수만 표시한다. 아이템을 누르면 파티 초상·이름·레벨·체력과 적용 후 체력을 보여주는 대상 선택 창이 열린다. 기절·체력 가득 참 등 사용할 수 없는 대상은 선택하지 못하고, 취소하면 아이템을 쓰지 않는다. 회복약과 기력의조각은 서로 맞는 대상에만 사용하며 몬스터볼은 야생 전투에서 쓴다. 별도 전리품 탭은 제거했다. 전투 보상의 골드·아이템은 기존처럼 자동으로 가방에 들어간다.

`tests/test_presentation.gd`는 교체 전후·공격 준비와 타격 사이의 상태, 공격 동작·보호막, 연출의 모델 불변, 가방 대상 제한·취소, 첫 출발을 검사한다. `native_presentation_probe`는 실제 창의 OS 포인터와 렌더링으로 같은 경로를 확인한다. `native_deck_probe`는 비율별 카드 클릭, 카드 그림 목록, 보상·강화·장비를 검사한다. `test_campaign_ui.gd`는 새 가방 경로를 포함해 69전투와 엔딩까지 입력으로 진행한다.
