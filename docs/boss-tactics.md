# 관장·사천왕·챔피언 전술

관장 18명·사천왕 후보 31명·챔피언 후보 11명의 각 파티 멤버에 전술을 배정했다. 아홉 가지 공통 행동 유형을 인물별로 조합한 첫 구성이다. 인물마다 완전히 별개의 전투 시스템을 추가한 것은 아니다. 정의는 `scripts/tactics/boss_tactics.gd`에서 관리한다.

## 공개 패턴과 대응

| 유형 | 반복 순서 | 대응 |
|---|---|---|
| 연타형 | 방어 → 연타 → 공격 → 강공격 | 두 타격의 총 피해를 보고 보호막과 받을 동료를 준비한다 |
| 철벽형 | 방벽 → 공격 → 강공격 → 방어 | 방어가 높아지므로 특수 기술이나 지속 피해로 우회한다 |
| 특방형 | 방벽 → 강공격 → 공격 → 방어 | 특방이 높아지므로 물리 기술이나 지속 피해로 우회한다 |
| 회복형 | 방어 → 회복 → 강공격 → 공격 | 회복 전에 집중 공격하거나 회복 턴에 작전을 설치한다 |
| 화상형 | 화상 → 방어 → 공격 → 강공격 | 치료하거나 물리 위력이 줄지 않는 특수 기술을 쓴다 |
| 독형 | 독 → 공격 → 방어 → 강공격 | 대기 중에도 피해가 나므로 치료하거나 빠르게 처치한다 |
| 씨앗형 | 씨앗 → 방어 → 강공격 → 공격 | 치료하거나 흡수 주체를 쓰러뜨려 회복을 끊는다 |
| 집중형 | 강화 → 공격 → 연타 → 방어 | 강화 턴을 활용하고 연속 공격에 대비한다 |
| 돌파형 | 방어 → 강공격 → 연타 → 공격 | 공격이 이어지는 동안 쓸 방어와 교대를 준비한다 |

예를 들어 규리는 방어·특방 장벽을 번갈아 배치하고, 독수는 독과 방어 역할을, 민화는 씨앗·회복·독을 함께 쓴다. 철구는 강화·연타·돌파를 섞는다. 그린·성호·난천 등 챔피언도 편성에 따라 순서가 다르다. 관장과 사천왕 독수, 사천왕과 챔피언 목호는 역할별 정의를 따로 둔다.

## 행동 수치

- **연타:** 종별 실제 공격 기술의 피해를 타격당 55% 압력으로 계산해 두 번 적용한다. 각 타격은 보호막을 순차 소비한다. 예고에 `타격당 피해×2`, 툴팁에 총 피해를 표시한다. 첫 타격에 출전 멤버가 기절하면 나머지는 중단하고 강제 교대한다. 대기 멤버에게 두 번째 타격을 넘기지 않는다.
- **방벽:** 해당 적의 방어 또는 특방 +1단계와 최대 HP 약 12.5%의 보호막을 준다. 단계 상한은 +6이며 이미 상한이면 예고도 +0으로 표시한다. 보호막은 다음 적 행동 직전 해제된다.
- **회복:** 최대 HP 약 12.5%, 실제 잃은 HP까지만 회복한다. HP가 가득 차면 예고와 실제 회복 모두 0이다.
- **상태 지시:** 화상·독·씨앗 중 하나를 행동 시점의 출전 동료에게 2회 부여한다. 다른 공격을 같은 행동에 덧붙이지 않는다. 같은 상태를 다시 걸면 남은 횟수를 갱신한다. 기존 카드 전투와 동일하게 대기 중에도 발동하고 지속 피해는 상성·보호막을 무시한다. 상태의 원작 타입 면역은 아직 재현하지 않는다.
- **씨앗 흡수:** 실제 잃은 HP만큼 살아 있는 시전자에게 회복한다. 기절한 시전자를 되살리지 않는다. 적의 회복은 아군 원정 회복 통계에 포함하지 않는다.
- **집중 강화:** 기존 범용 위력 보정 +20%를 사용한다. 방어·특방 단계와 구분한다. 강공격은 기존 1.2배 압력이다.

공격은 해당 종이 현재 레벨까지 배울 수 있는 기술에서 고른다. 방벽·회복·상태 부여는 이 게임의 트레이너 전술 지시이며 모든 종이 그 연출용 기술을 원작 레벨업으로 배운다는 뜻은 아니다. 개별 기술의 원작 다단 타격 확률·PP·명중을 재현하지 않는다.

## 예고·연출·저장

의도 위 작은 역할 표시, 의도 툴팁의 트레이너·전술명·효과 수치·반복 순서, 상대 파티와 지도 툴팁으로 확인한다. 별도 HUD 패널을 늘리지 않는다. 교대하면 대상의 방어·상성에 따라 피해만 갱신하고 적이 몰래 기술이나 순서를 다시 고르지 않는다. 수면은 이번 행동 전체를 취소한다.

규칙은 한 번 정산하고 화면이 사건별 스냅샷을 재생한다. 연타는 첫 공격 → 첫 피해 → 두 번째 공격 모션 → 두 번째 피해로, 방벽은 능력치 → 보호막으로, 씨앗은 피해 → 흡수 회복으로 표시한다. 재생은 규칙·난수·통계를 다시 적용하지 않는다.

v3 저장과 69전투 경로·레벨·경험치를 유지한다. **진행 중인 전투는 저장된 패턴 그대로, 이후 진입하는 보스전부터 새 전술**을 적용한다. 새 원정을 요구하지 않는다. 관장·챔피언은 6마리, 사천왕은 현재 규칙대로 5마리다.

## 검증과 남은 범위

`test_boss_tactics.gd`는 전체 60개 편성의 Lv.18/50/100 기술·결정성, 예고와 실제 효과, 다단 공격·기절 중단·단계 상한·회복 한도·상태 소유권·수면·저장 호환을 검사한다. `test_boss_tactics_ui.gd`와 `native_boss_tactics_probe`는 실제 버튼 입력과 시간에 따른 두 타격 표시, 치료 카드, 지도 정보를 검사한다. 전체 원정·저장·연출·기록 회귀 검사도 함께 실행한다.

현재는 공개된 순환 전술의 첫 구성이다. 인물 전용 카드·대사·초상·고유 보상, 체력 구간별 패턴 변화와 날씨는 후속 범위다. 자동 정책의 완주율은 회귀 지표이며 모든 파티의 재미와 난이도를 확정하지 않는다.
