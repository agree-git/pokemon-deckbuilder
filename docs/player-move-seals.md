# 소지품 효과·급소·교대 제한 · 원정 v14

새 원정v14/플레이어 효과6에 매직룸(478)·주술(381)·페어리록(587)을 추가했다. 누적393기술의 특징 보완이며, 이전 [v13 필드/룸](player-move-fields.md)까지의 정의/전용 엔진은 동결한다. 기본 공격을 포함한919기술 전부의 원작 고유 효과 완료라는 뜻은 아니다.

| 기술 | 실제 카드 동작 |
|---|---|
| 매직룸 |5상대 행동 동안 양쪽 소지품의 지속 효과 정지. 재사용하면 해제. 소유권/소지품 문자열을 바꾸지 않고 공격·방어·도구 회복·교대 보호막·턴말 회복·연속 출전 강화의6종 효과를 막음 |
| 주술 |아군 진영5상대 행동 동안 확정 급소1.5배·높은 급소1.15배와 급소의 공격 음수/방어 양수 단계 무시를 차단. 교대해도 유지. 코트체인지로 양쪽 잔여 기간 교환. 안개제거로 지워지지 않음 |
| 페어리록 |사용 턴과 다음 플레이어 턴의 수동/소유 기술 카드 자동 교대 제한.2상대 행동 뒤 해제. 현재 출전자가 고스트면 탈출 가능. 기절 후 필수 교대·상대의 강제 교대는 허용. 재사용하면 기간 갱신 |

매직룸은 이미 받은 보호막/강화를 회수하지 않는다. 소지품이 있다는 판정은 유지하므로 애크러뱃을 무소지 위력으로 바꾸지 않으며, 탁쳐서떨구기 등의 소지품 제거도 유지한다. 룸 종료로 제거된 물건을 되살리지 않는다. 기존 보스가 일시 제거한 파티 아이템의 전투 종료 복구는 기존 보스 상태에 맡긴다. 새 아이템·열매·특성 체계는 추가하지 않았다.

주술은 확률 추첨을 추가하지 않는다. 기존 공개 급소 각색만 방어하며 필드/원더룸/장막·화상·연속 타격 수/실제 보호막 피해를 유지한다. NPC의 확정 급소 연타도 원래 음수 공격/양수 방어 단계를 반영해 다시 계산한다. 플레이어 복사/잠꼬대의 공격에도 현재 주술을 반영한다.

페어리록은 시전자 개인 구속이 아닌 전장 효과라 시전자의 교대/기절만으로 해제하지 않는다. 새 상대도 전장 효과의 남은 기간을 따른다. 원작과 다른 고정 행동 순서에 맞춰 기간을 상대 행동으로 표시한다. 현재 구현의 적 순차 출전/대표 마지막 순서는 바꾸지 않는다.

## 코드·저장·검사

- `scripts/tactics/player_move_seals.gd` / `data/player_move_seals_v14.json`; 공통 디스패치의 효과6, 선택 `seal_context={magic,fairy,ally,foe}`. 앞 두 키는 전장, 뒤 두 키는 각 진영의 주술 잔여 기간. 최대5/2/5/5, 정수만 허용. 이전 원정은 이 필드를 허용하지 않음.
- 소지품 지속 효과는 `TacticalBattle.effective_item()`을 통해 읽는다. 영구 소지품이나 저장 정규화를 바꾸지 않음. BattleFrame에서 문맥을 복제해 연출 중 타이머도 보존.
- 생성기 `tools/import_player_move_seals.py`:v13 기반 SHA와v10→v13 체인·고정CSV4종 SHA 확인. 원본CSV는 커밋하지 않음.
- `tests/test_player_move_seals.gd`:919카드 순수/반복 미리보기와v13 무효과 피해 일치,6아이템/실제 치유·교대·만료·보스 제거 복구,양쪽 급소/장막·원더룸 연타,교대 금지/고스트/필수·강제 교대,프레임/정의 불변.
- `tests/test_player_seal_saves.gd`:실제 원정의 사용→저장→재개→다음 행동/교대 동일성,필드/능력·타입/캐시 에너지 조합,비정상 문맥 거절,v13 실제 사전 저장/지문 호환,3seed 전체 미래69전 보존,실제 파일 저장/복원.
- 새 두 검사만 `--suite player-seals-new`, 반영 전 공통 회귀는 `--suite player-seals`로 실행. 실제 창/EXE는 사용자 요청으로 보류.

다음은 중력·전자부유·텔레키네시스 등 접지/공중 효과다. 보완 목록 밖526기술은 기본 공격/부가효과도 포함한다. 특성/PP·전투 전용 변신과 남은 고유 공격 전체는 후속 범위다.
