# 야영지 상인과 카드 구매

무작위 야영지의 떠돌이 상인은 **카드 세 장·보급품·카드 제거**를 제공한다. 카드 그림과 효과, 파티 기술의 소유자, 원정 덱의 같은 카드 보유 장수를 보고 구매한다. 보급품은 도트 아이템 그림과 재고·보유 수를 함께 표시한다.

## 카드 진열

처음 도착한 순간의 덱·유물·파티 기술을 기준으로 진열을 정한다.

1. 현재 조합을 지원하는 공용 카드. 연계 후보가 없으면 전체 공용 카드에서 선택한다.
2. 다른 운영을 시도할 공용 카드. 관련 풀 밖에 후보가 있으면 그중에서 고르고, 첫 카드와 중복하지 않는다.
3. 파티 멤버가 배운 기술의 추가 사본. 새 기술을 무료로 배우는 서비스가 아니며 소유자와 카드 비용을 그대로 사용한다. 학습 기술이 없는 예외에는 몸부림을 제공한다.

모두 미강화 카드이며 **각 한 장만 판매**한다. 세 장 중 무작위 한 장에 20골드 할인을 적용한다. 판매된 카드는 회색 그림과 `판매 완료`로 남고 재구매할 수 없다. 구매는 카드 아래 가격 버튼으로 하며, 원정 덱에서 바로 확인하거나 해당 야영지의 강화 대상으로 선택할 수 있다. 다음 전투에 실제 카드 인스턴스가 들어간다.

시드·장소로 독립 추첨한다. 전투 드로우나 보상의 난수를 소비하지 않으며, 진열 후 덱을 강화·제거하거나 장비를 바꿔도 재고·할인·소유자를 재추첨하지 않는다. 기술 사본은 이후 기술 교체·진화·파티 방출 시 기존 소유 카드와 같은 규칙을 따른다.

## 가격과 선택

| 종류 | 첫 지역 | 여덟 번째 지역 | 리그 |
|---|---:|---:|---:|
| 일반 공용 카드 | 60 | 95 | 100 |
| 지속 작전·에너지 공용 카드 | 90 | 125 | 130 |
| 비용 0~1 기술 | 70 | 105 | 110 |
| 비용 2 이상 기술 | 90 | 125 | 130 |

기본값에 지역 진행마다 5골드를 더하고 리그 단계에서 상한을 둔다. 표는 할인 전 가격이며 해당 상인의 할인 카드만 20골드 저렴하다. 가격에 원작 기술의 희귀도·상성·위력 전체를 평가하는 자동 가치 판정은 아직 사용하지 않는다.

보급품은 상처약 30, 좋은상처약 70, 기력의조각 100, 몬스터볼 35골드다. 기존 무작위 보급품 구성·재고와 전투 골드 수입을 유지한다. 상인은 일반 야영지 추첨에서 35% 확률로 등장하며 모든 야영지에 상점을 추가하지 않는다.

카드 제거는 방문당 한 장, 첫 50골드에서 원정 누적 제거당 25골드씩 증가한다. 최소 덱 5장과 동료의 마지막 기술 카드는 보호한다. 구매와 제거는 같은 골드를 사용하므로 필요한 기능을 추가할지, 기존 카드의 드로우 빈도를 높일지 선택한다. 회복 아이템을 사서 가방에서 사용하면 휴식 대신 카드 강화를 택할 여유가 생긴다.

구매·제거는 **휴식/강화 중 한 번인 주 행동을 소비하지 않는다**. 주 행동과 상점 지출의 기회비용을 구분한다. 이번 가격은 초기값이며 상점의 유물·지닌 물건 판매, 장시간 수동 플레이의 골드 지출·승률 비교는 후속 작업이다.

## 저장 호환

진열·가격·할인·매진 여부는 기존 야영지 상태의 선택 필드 `card_offers`에 저장한다. 구매 성공 시 골드 차감·카드 UID 배정·매진 처리 후 한 번 알리고 자동 저장한다. 잘못된 선택·골드 부족·매진·야영지 밖 구매는 난수와 자원을 바꾸지 않는다. 저장 검사는 카드 종류·소유권 형식·가격·할인·재고를 확인한다. 과거에 판 기술의 소유자가 파티를 떠나도 구매 이력 때문에 저장을 거부하지 않는다.

기존 v3 원정은 이어할 수 있다. **업데이트 전에 이미 방문한 상인은 보급품 진열을 유지**하며 갑자기 카드를 추가하거나 재고를 초기화하지 않는다. 업데이트 후 처음 방문하는 상인부터 카드 진열이 생긴다. 새 원정을 시작할 필요는 없다.

```bash
source /workspace/.cloud-setup/pokemon-deckbuilder/env.sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tests/test_merchant_cards.gd
godot --headless --path . --script res://tests/test_merchant_ui.gd
godot --headless --path . --script res://tests/test_deck_run.gd

LIBGL_ALWAYS_SOFTWARE=1 python3 tools/test_native_pointer.py --probe native_merchant_probe
```

규칙 1,199개 검사로 386종의 진열·가격·연계 후보·시드 재현, 예산 부족·중복 구매의 무변경, 구매 카드의 강화와 다음 전투 진입, 디스크 복원·기존 상점 호환과 잘못된 저장 거부를 확인했다.

실제 X11 창의 마우스 16회로 세 창 비율에서 구매 버튼 위/중앙/아래, 매진·보급품 구매·제거·휴식·모달 차단과 자동 저장을 확인했다. UI 검사 30개와 1920×1080 화면 확인을 통과했다. 별도 프로세스 다섯 개에서 카드 구매 후 종료·재실행·매진 유지·추가 구매·백업 복구를 검증했다.

고정 시드 0/42/2026은 보상·장비·야영지 선택과 상인 카드 세 장 구매/저장 복원을 포함해 각각 69전투를 완주했다. 원정 통합 검사 185개, 전체 저장 검사 1,807개와 기존 야영지 UI 검사 48개도 통과했다. 자동 정책의 완주는 모든 구매 선택의 가치나 파티별 밸런스 확정을 뜻하지 않는다. 검증 환경은 Linux Godot 4.7.2이며 Windows 빌드는 별도다.
