# 검증 현황

## 이번 정리에서 확인할 것

- main의 실행 코드/씬/데이터/에셋/출처 바이트 보존.
- 문서와 도구가 특정 클라우드의 절대 경로에 의존하지 않음.
- 자료 브랜치에 게임 사본·바이너리 산출물·캐시가 없고, 링크가 현재 문서 또는 고정 과거 자료를 가리킴.
- 재배치한 검사기를 최신 main에 대해 실행하고 오류 로그/완료 요약/프로세스 결과를 확인.
- 원격 두 브랜치 반영과 깨끗한 main 상태 확인.
