# 리그 실내 배틀 스테이지

사천왕은 전문 타입의 실내 배틀 룸, 챔피언은 출신 지방과 인물에 맞는 실내 스테이지를 사용한다. `BattleBackdrops.for_stop()`이 표시용 배경만 고른다. 경로·대진·포켓몬·레벨·보상·난수·저장 데이터는 바꾸지 않는다. 지도와 야영지는 기존 바이옴 배경을 유지하며, 전투 상단에는 타입 배틀 룸 또는 지방 챔피언 룸을 표시한다.

## 사천왕

18개 타입 룸을 준비했으며 현재 후보가 사용하는 14타입을 모두 연결했다. 현재 후보에 없는 노말·전기·풀·페어리 룸은 예비 에셋이다. 타입 안에서는 같은 룸을 공유한다.

| 아틀라스 | 왼쪽 위부터 행 순서 |
|---|---|
| `assets/league/elite_1.png` | 노말 / 불꽃 / 물 / 전기 / 풀 / 얼음 |
| `assets/league/elite_2.png` | 격투 / 독 / 땅 / 비행 / 에스퍼 / 벌레 |
| `assets/league/elite_3.png` | 바위 / 고스트 / 드래곤 / 악 / 강철 / 페어리 |

도장·수족관·빙궁·발전실·수정 명상실·화석 전시실·강철 격납고 등의 벽과 바닥으로 타입을 표현한다. 야외 바이옴을 그대로 실내에 넣지 않는다.

## 챔피언

현재 후보 11명, 출신 지방 8곳을 연결했다. 같은 지방도 인물에 따라 방을 달리했다. 알로라 챔피언 후보는 현재 `league.json`에 없다.

| 후보 | 지방 | 배경 |
|---|---|---|
| 그린 | 관동 | 남색 벽·흰 기둥·붉은 카펫의 전통 리그 홀 |
| 목호 | 성도 | 목조 기둥·등롱·용 부조의 전통 전각 |
| 성호 | 호연 | 청색 광물·금속·석재 전시 홀 |
| 윤진 | 호연 | 흰 기둥·수족관·청록 모자이크의 해양 궁전 |
| 난천 | 신오 | 산악 신전의 석조 아치·천체 문양·금색 장식 |
| 노간주 | 하나 | 벽돌·청동·큰 창문의 따뜻한 원형 홀 |
| 아이리스 | 하나 | 별빛 돔·보라색 바닥의 용 궁전 |
| 카르네 | 칼로스 | 흰색 곡선 기둥·유리·장미 장식의 무도회장 |
| 단델 | 가라르 | 지붕·관중석·조명을 갖춘 초록 코트의 실내 경기장 |
| 테사 | 팔데아 | 석조 아치·유리 천장·청백색 아줄레주 홀 |
| 네모 | 팔데아 | 테라코타 아치·청백색 타일의 아카데미 전시장 |

`champion_1.png`의 순서는 그린/목호/성호/윤진/난천/노간주, `champion_2.png`는 아이리스/카르네/단델/테사/네모/공용 리그 홀이다. 알 수 없는 챔피언 ID는 공용 홀로 표시한다. 인물별 원작 룸을 추출한 이미지가 아니라 지방의 건축·분위기에서 착안해 생성한 배경이다.

## 화면과 에셋

화면·UI는 **1920×1080**이다. 배경 파일은 각각 **1536×1024의 2열×3행 아틀라스**이며, 셀 하나는 약 **768×341**이다. 개별 배경 원본이 1920×1080 또는 정확한 16:9라는 뜻은 아니다. 실제 전투에서는 폭에 맞춰 최근접 필터로 확대하고 발밑 기준으로 위쪽을 잘라 프레이밍한다. 하단은 손패 테이블로 자연스럽게 어둡게 연결한다. 화면 전체를 저해상도 SubViewport에 렌더링하지 않는다.

아군은 왼쪽 아래, 적은 오른쪽 위에 선다. [배경별 접지 좌표](battlefield-layout.md)의 수동 계측점을 배경과 같은 카메라로 투영한다. 투명 여백을 제외한 발끝·그림자·HP·보호막·연출이 이 좌표를 함께 따른다. 에셋 출처와 해시는 [에셋 출처](../ASSET_SOURCES.md), `assets/league/manifest.json`, 표시 매핑은 `data/battle_backdrops.json`을 따른다.

`tests/test_league_backdrops.gd`는 현재 후보 전체·타입·지방·파일/셀·조회 불변과 실제 경로의 리그 연결을 검사한다. 화면 품질과 원작 룸 재현 정확성을 자동 규칙 검사만으로 판정하지 않는다.
