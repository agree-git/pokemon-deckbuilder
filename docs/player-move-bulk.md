# 기술 일괄 조정 · 원정 v23 / 플레이어 효과15

다음 기술 작업은 이 문서의 계약과 필요한 기술ID만 조회한다. 큰 JSON/아래 전체 목록을 통째 읽지 않는다. 사용자는 소수 기술마다 작업을 종료하지 말고 일괄 구현 뒤 모아서 검사하도록 요청했다.

## 적용 범위

- 전체919개 설정을 기존 버전별 정의와 대조해 분류하고156개 기술을 하나의v23에 조정했다. 개별 특징/명시 각색을 기록한 기술은586개,기존 기본 공격/상태/능력 변화로 처리하는 기술은333개다. 이 수치는919개 원작 효과의 완전 복제를 뜻하지 않는다.
- 임시 보호막5만 있던 변화 기술29개는 전부 교체했다. 축하606은 원작처럼 효과 없는 비용0 메시지다. 상금/PP/새 특성/더블배틀/전투 전용 폼 시스템은 도입하지 않는다.
- 새 원정에만 적용하며 게시된v1~v22 정의/전용 엔진과 기존 원정의 현재·미래 전투/경로/RNG/학습 슬롯/카드UID·강화를 보존한다. 원작 물건55종·영구 소비/리사이클/소유권 복구도 유지한다.

## 주요 효과와 각색

- 변신144은 전투 능력치5종/현재 능력 단계/타입을 복사하고 중앙 스프라이트를 바꾼다. 자신의 기존 소유 기술 카드를 상대 기술 슬롯에 대응시키며 카드UID/원래 키·비용·강화를 유지한다. HP/영구 종/영구 학습/장비는 그대로이고 교대하면 복구한다. 복사한 기술 구성은 상대가 바뀌어도 유지한다.
- 원한180은 PP 감소 대신 직전 상대 기술2턴 봉인,원념288은 직접 공격에 기절하면 해당 상대 기술을 이 전투 동안 봉인한다. 봉인286은 출전 중 자신의 습득 기술과 일치하는 상대 기술을 막으며 교대/기절에 해제한다.
- 매직코트277은 지원하는 대상 상태/능력 저하를 반사하고 가로채기289는 상대 자기 강화/회복을 취소해 사용자가 받는다. 필드/공격 부가효과 전체를 반사하지 않는다. 대상 변화 효과 중 기존 상태·능력 및 도발/구속/회복봉인 경로를 사용한다.
- 날따름266/분노가루476은 단일 출전 체계에서 실제 표적 변경 대신 파티의 이번 상대 직접 피해½로 각색한다. 분노가루는 풀 상대에 무효다. 마룻바닥세워막기561은 첫 턴 공격만 막고 변화 효과는 허용한다. 스포트라이트671/드래곤옐913은 다른 동료의 다음 공격 확정 급소,손에손잡기607은 살아 있는 동료 전원HP⅛ 보호막이다.
- 역할272/스킬스왑285/동료만들기494/배껴그리기867은 새 특성 대신 양수 능력 단계/전투 강화의 복사·교환·전달로 각색한다. 위액380/코어퍼니셔687은 상대 양수 강화를 제거한다. 고민씨388은 수면 치료/3턴 수면 방지,심플빔493은3턴 상대 능력 단계 변화량2배다. 음수 단계는 제거·복사 대상에서 제외한다.
- 초승달의기도849는 살아 있는 파티 전원HP¼ 회복/상태 치료,회생의기도863은 첫 기절 동료HP½ 회생이다. 회생은 사용자당 전투1회/카드 소진이며 기절 때문에 소진된 기술만 버린 더미로 돌린다. 기존 부상과 이전에 자발 소진한 카드는 유지한다. 회복 감소/회복봉인 정책은 기존 함수로 처리한다.

- 미래예지248/파멸의소원353은 두 번째 상대 행동 종료까지 기다렸다가 그때 출전 상대에 발동한다. 시전자의 현재 전투 능력치로 계산하며 기절해도 발동한다. 타입/보호·대타를 적용하고 원래 상대가 교체되면 새 상대를 맞힌다.
- 난동 계열은3회 같은 기술을 사용한 뒤 혼란,분노99는 직접 피해에 공격+1,프레젠트217은 위력40→80→120→상대 회복의 공개 주기로 각색한다. 맹세/크로스/돌림노래는 같은 턴 조합을 추적하며,맹세의 무지개는 확률 대신 부가 상태 지속+1이다. 프리폴507은 비행/200kg 제한을 유지하고 동시 들어올리기 대신 공격 후 엄호를 준다.
- 칼등치기/적당히손봐주기는HP1로 제한하고 사이코쇼크 계열은 특수 공격력으로 물리 방어를 계산한다. 장막 파괴/보호 관통은 순수 미리보기와 실제 피해에 같은 규칙을 적용한다. 소금절이/시럽봄/사이코노이즈/블러드문,연타/흡수/반동/급소와 다이 기술의 날씨·필드·파티 강화도 묶어서 연결했다.
- 최신 세대의 CSV에 효과/접촉 플래그 등이 없는 기술은 명시 각색을 사용한다. 원작의 모든 명중·부가 확률/접촉 반응·특성·폼별 예외를 완료했다고 해석하지 않는다. 정확한 적용 내용은 카드 설명 및 아래 해당ID를 기준으로 한다.

## 코드 / 저장 / 재생성

- `player_move_bulk.gd` / `data/player_move_bulk_v23.json`:156개 정의와 전체919개 `audit` 분류,준비/거절/피해·행동/턴/교대/기절 훅을 한 버전에 모았다. `PlayerTechniques`가 효과15를 선택한다.
- 선택 `bulk_context`:변신 슬롯/사용·직전 기술/난동·분노/봉인·원념/수면·단계 배율/소금·시럽/회생·기절 카드/소모 이력/지연 공격/이번 행동 엄호·반사·가로채기/턴 조합과 맹세 필드를 저장한다. UID/기술/카드 소유자/기간/개수/중복/버전을 검증한다. 순간 `bulk_action`은 저장하지 않고 알림 전 정리한다.
- `BattleFrame`은 문맥을 복제하고 UI는 변신 스프라이트·새 지속 상태 배지를 표시한다. 기존 전투 종/학습 슬롯을 실제로 변경하지 않는다. 교대/기절 시 해당 문맥을,전투 종료 시 전체 문맥을 정리한다.
- `PokemonStats.damage`는 선택 `defense_stat`만 추가 지원하며 이전 정의에는 필드가 없으므로 기존 계산이 유지된다. 기존 전용 엔진/입력은 수정하지 않는다.
- 이전 실제v22 지문 `ad23ee2629e963b3b145761aec17f9b9f9d78df333028031deef652fd27c582f`를 수용한다. 이전 원정은 빈 `bulk_context` 주입도 거절한다.
- `tools/import_player_move_bulk.py --game-dir .`는 고정된12개 기존 입력 SHA를 확인해 일괄 정의/각색/분류를 재생성한다. 원본 CSV/기록/캐시는 추가 커밋하지 않는다. 특정 기술은 Python으로 `moves[str(id)]`/`audit[str(id)]`만 조회한다.

## 검증 출발점

`tools/check.py --suite player-bulk`는 변경156개 미리보기/강화/실행·변화29개/과거 정의·효과 계열/실제 저장·기존 실제v22 입력과 경계 사례를 모은다. 일괄 구현 뒤 실행하며 이미 통과한 범위를 반복하지 않는다. 실제 결과는 [HANDOFF](../HANDOFF.md)/[검증 기록](validation.md)의v23 절을 따른다. 실제 창/native/X11·EXE/export/Windows CI는 계속 보류한다.
