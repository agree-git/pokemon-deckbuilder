# 능력치와 스피드 에너지

정식 원정은 1~3세대 386종의 **3세대 당시 종족값**을 사용한다. 기술별 물리·특수 분류와 18개 타입·복합타입 상성은 기존 현대 분류를 유지한다. 종족값까지 최신 변경치를 섞지 않도록 과거 종족값 표에서 3세대 값을 복원한다. 예를 들어 라이츄의 스피드 종족값은 100, 피카츄의 방어는 30이다.

## 여섯 능력치

모든 포켓몬은 개체값 31, 노력치 0, 성격 보정 1.0을 사용한다. 종과 레벨에 따른 차이를 먼저 적용하며 개체값 뽑기·노력치 육성·성격 시스템은 도입하지 않는다.

- `기초 = floor((종족값 × 2 + 31) × 레벨 / 100)`
- HP: `기초 + 레벨 + 10`. 껍질몬은 모든 레벨에서 HP 1.
- 공격·방어·특공·특방·스피드: `기초 + 5`.
- 예: Lv.100 리자몽은 HP 297 / 공격 204 / 방어 192 / 특공 254 / 특방 206 / 스피드 236.

레벨업과 진화 때 여섯 능력치를 다시 계산한다. 최대 HP가 바뀌어도 잃은 체력의 절대량을 유지하고, 체력이 가득 찼다면 새 최대 HP로 유지한다. 살아 있는 포켓몬은 최소 HP 1, 기절한 포켓몬은 HP 0을 유지한다. 기존 레벨당 HP +1·진화 HP +12·레벨/진화 공격 가산은 제거했다. 관장·사천왕·챔피언도 동일한 공식과 기존 진행 순서별 레벨을 사용한다. 챔피언은 여섯 마리 모두 Lv.100이다.

## 물리·특수 피해

물리는 공격/방어, 특수는 특공/특방을 사용한다. 원작 형태의 공식에 카드 전투용 공통 배율 **0.6**을 적용한다. 아군과 적이 같은 공식을 사용한다.

```
레벨 계수 = floor(2 × 레벨 / 5) + 2
원본 피해 = floor(floor(레벨 계수 × 기술 위력 × 공격 능력치 / 방어 능력치) / 50) + 2
피해 = floor((원본 피해 × 0.6 × 전술 보정 × 화상 보정 + 추가 피해) × 자속 × 상성 × 강공격 보정)
```

- 자속: 자신의 두 타입 중 하나와 일치하면 1.5배.
- 상성: 복합타입 두 개를 곱한다. 4배·1/4배·무효를 적용한다. 무효는 추가 피해가 있어도 0이며 몸부림은 무타입으로 처리한다.
- 적의 예고된 강공격은 1.2배, 일반 공격은 1.0배다.
- 무효 외 최종 피해는 최소 1. 보호막은 계산 완료 후 피해를 흡수한다.
- 급소·난수 피해·명중 확률은 넣지 않았다. 카드의 피해 표시와 적 의도는 동일 계산 결과다. 대기 멤버의 기술 미리보기는 그 멤버가 출전했을 때의 피해다.
- 기존 기술의 확률·다단 공격·날씨·특성·PP·고정 피해 등은 아직 개별 원작 규칙을 모두 재현하지 않는다. 기존 카드 효과의 변환 규칙을 유지한다. 껍질몬의 불가사의부적도 아직 없다.

울음소리·칼춤·고속이동 등 원본 기술의 능력치 증감은 해당 능력치의 **-6~+6단계**로 적용한다. 양수 단계는 `(2+단계)/2`, 음수는 `2/(2-단계)` 배율이다. 고속스핀·원시의힘의 부가 상승과 오버히트·엄청난힘의 반동 감소는 사용자에게 적용한다. 능력치 단계는 교대·기절·전투 종료 시 해제한다. 마비는 현재 스피드를 절반으로 만들고 화상은 물리 피해를 절반으로 만든다.

트레이너·도구·유물의 기존 범용 강화는 원본 능력치 단계와 구분한다. `strength` 1당 물리·특수 피해의 **위력 보정 +10%**, 약화는 -10%이며 최저 배율은 40%다. 예를 들어 배틀 강화제는 교대 전까지 +40%, 에이스 육성은 출전 유지 시 +20%다. 카드와 툴팁에 이 보정을 표시한다.

## 스피드와 에너지

**플레이어 턴 시작 시 한 번만**, 그때 출전한 아군과 상대의 현재 스피드를 비교한다.

| 비교 | 턴 시작 에너지 |
|---|---|
| 아군이 더 빠름 | 4 (기본 3 + 스피드 1) |
| 같거나 더 느림 | 3 |

첫 턴에도 적용한다. 마비·스피드 단계도 비교에 반영한다. 턴 도중 기술 사용으로 교대하거나, 수동 교대하거나, 적을 쓰러뜨려 다음 적이 나와도 이미 지급한 에너지는 바꾸지 않는다. 턴 도중 고속이동을 사용했다면 다음 턴부터 효과를 볼 수 있다. 강제 교대는 보류된 적 행동을 처리하고 실제 다음 플레이어 턴이 시작할 때 한 번 지급한다.

에너지 구슬 아래에 `스피드 +1` 또는 `기본 에너지 3`을 표시한다. 구슬 툴팁에는 이번 턴 시작 당시 양쪽 스피드와 지급량을 표시하므로 교대 후 현재 스피드와 달라도 근거를 확인할 수 있다. 이미 받은 에너지·비교값·출전 UID를 저장해 이어하기로 에너지를 다시 받지 않는다. 포켓몬 이름과 파티 목록 툴팁에서 여섯 능력치를 확인한다.

## 보호막·회복·추가 피해

기존 효과의 기준 HP 48에서 차지하던 비율을 유지한다. 내부 효과값 `n`은 `round(최대 HP × n / 48)`로 계산하며 양수 효과는 최소 1이다. 카드 전투 화면에는 실제 수치, 보상·유물 설명에는 최대 HP 비율을 표시한다.

| 효과 | 비율 |
|---|---|
| 방어 지시 8 | 사용자 최대 HP의 16.7% 보호막 |
| 응급 회복약 16 | 사용자 최대 HP의 33.3% 회복 |
| 강화 지시 7 | 다음 공격자의 최대 HP의 14.6% 추가 피해 |
| 탐험 구급함 5 | 각 동료 최대 HP의 10.4% 보호막 |
| 화상·독·씨앗 2 | 대상 최대 HP의 4.2% 피해/회 |
| 상태 회수 4 | 남은 횟수마다 대상 최대 HP의 8.3% 피해 |
| 야영지 상처약 20 | 대상 최대 HP의 41.7% 회복 |
| 야영지 좋은상처약 50 | 대상 최대 HP의 104.2% 회복 (최대 HP에서 제한) |

씨앗은 실제로 잃은 HP만 흡수한다. 지닌 물건·지속 작전의 보호막·회복·추가 피해도 같은 비율 기준이다. 휴식 50%와 치유의 샘 25%, 기력의조각 50%는 기존 비율을 유지한다.

## 검증과 저장

`test_pokemon_stats.gd`에서 알려진 능력치·피해 공식·물리/특수 차이·자속·상성·보호막·체력 보존·능력치 단계·첫 턴/동률/교대/적 교체/강제 교대 스피드 에너지·저장 복원을 검사한다. 공유 덱·성장·포획·원정·파일 복구·실제 창 포인터 검사를 함께 실행한다.

`test_campaign.gd`는 보상과 장비를 선택하는 기본 정책으로 30개 시드를 진행한다. 모든 시드에서 정상 승리/패배에 도달하고 최소 25개를 완주하는 기준이며, 패배가 발생하면 실제 전멸인지 검사한다. 불리한 상성의 초반 관장에게 질 수 있으며 자동 정책의 결과가 모든 빌드의 난도를 보장하지 않는다. 별도 `test_deck_run.gd`는 고정 시드 3개의 69전투 완주와 저장 복원을 요구한다.

능력치 규칙 변경으로 저장 규칙 버전은 `campaign-69-species-stats-speed-v3`다. 이전 전투 수치로 만든 원정 저장은 이어하지 않고 새 원정을 시작한다. 영구 포획 도감과 스타팅 해금은 유지한다. 런타임 네트워크 없이 `data/base_stats.json`을 읽으며 `python3 tools/build_stats.py`로 고정 출처에서 재생성한다.
