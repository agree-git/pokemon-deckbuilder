# 포켓몬 연구: 버튼 폭 줄이기

main `1f97aed`.

사용자가 실제 연구 화면을 보고 좌우로 긴 버튼이 읽기 불편하다고 지적했다. 화면 폭에 비례해 늘어나던 버튼을 기능에 맞는 폭으로 바꾸고, 동료 선택과 연구 내용을 두 열로 나눴다. 게임 규칙·연구 비용·기술/진화/폼 조건은 바꾸지 않는다. 새 버전/EXE/Release는 재요청까지 보류한다.

## 파일과 배치

수정 엔트리는 `scripts/ui/pokedex_workshop.gd` 하나다. 공용 버튼 도구와 다른 화면은 그대로다.

- 창:1280×920, 위치(320,80). 왼쪽 동료 목록과 오른쪽 연구 본문. 기존1600×952 화면보다 폭을 줄였다.
- 동료:232×88 세로 카드, 24px 간격. 포켓몬 스프라이트/이름/레벨을 표시한다. 선택 시 기존처럼 대상 변경/기술 슬롯 초기화만 한다.
- 탭:진화·준비160px, 나머지144px, 높이48px/사이24px. 본문 전체 폭으로 늘리지 않는다.
- 검색:528×48. 교체할 기술4개는176×56/사이24px로 별도 줄에 둔다.
- 목록:936px 스크롤 영역. 행 최소896×144, 설명 오른쪽에184×56 실행 버튼을 둔다. 설명과 버튼 사이24px를 유지한다. 제목/이름은 기존 fit/전체 툴팁을 쓰며 설명은 줄바꿈한다.
- 행동 문구:`준비하기`, `훈련하기`, `배우기 · 1개`로 줄였다. 야영 행동 비용은 기존 안내에, 기술머신 소모량은 버튼과 안내에 표시한다. 실제 callback/disabled 조건/소모는 유지한다.
- Esc는 검색 초점과 관계없이 연구창을 닫고 야영으로 돌아간다. 음악 메뉴를 동시에 열지 않는다.

## 해당 범위 검사

`tests/native_workshop_compact.gd`를 기존 `tools/native_pointer.py`로 실행한다. 격리한 XDG 경로, Godot4.7.2 실제 X11/1920×1080/Dummy 출력이다. 실제 동료/탭/검색·삭제/Esc 입력, 버튼 경계/간격/설명 분리, 진화·훈련·보유TM 화면, 실제 원정/fixture snapshot·UID/RNG·저장 바이트 보존을 한 묶음으로 확인한다. 구매·훈련/진화 실행이나 전체 게임 회귀는 레이아웃 변경에 필요하지 않아 반복하지 않는다.

기존 `native_ui_spacing.gd`의 기술 버튼 폭 조건도 최신176px로 수정했지만, 전체 UI 묶음을 다시 실행하지는 않는다. 최신 증거는 `/tmp/pokemon-workshop-compact/`, 로그는 `/tmp/pokemon-workshop-compact-native.log`다.

실제 결과: **한 묶음36검사/0실패·8 OS클릭**. 처음 실행에서 통과해 재실행하지 않았다. 진화·기술 훈련·기술머신 PNG3장을 모두 시각 확인했다. 로그에 SCRIPT ERROR/ERROR/누수가 없으며 기존 소프트웨어 VSync 안내만 있다. 실제 원정/검사용 야영의 전체 snapshot과 UID/RNG·저장 바이트도 유지됐다. 기술머신2개 보유는 검사 fixture이며 실제 저장에는 반영하지 않았다. 새 버전/EXE/빌드/CI/Release는 생성·실행하지 않았다.
