# 자동 진화와 제한된 기술 훈련

2026-10-20 사용자: 야영지 진화 분기 선택 제거·자동 진화, 기술 배치를 쉽게 완성하는 훈련 제한. 이번 수정은 새 빌드/릴리스 요청이 아니다. 게시된 v0.28.5 소스 태그/입력은 동결한다.

## 파일 지도·계약

- `scripts/tactics/national_evolution.gd`: 레벨·성별·낮밤·친밀도·필수 기술·아름다움 확인. 외부 장소/통신/특수 조작을 위한 준비 플래그/야영 행동 요구 제거. 페어리 기술의 님피아 우선, 나머지 겹치는 분기는 UID 기반 고정 순서. 성향 마스크/희귀 개체 분기도 게임 RNG를 쓰지 않는 고정 개체값으로 판정한다. 성격/개체값/노력치 전투 시스템은 추가하지 않았다.
- `special_evolution.gd`: 배루키는 종·레벨의 공격/방어 비교로 자동 결정한다. 현재 능력치 규칙에서 배루키는 동률→카포에라. 이전 선택 필드는 저장 호환을 위해 남지만 판정에 쓰지 않는다. 개무소의 기존 개체 분기/빈티나 아름다움/토중몬·껍질몬 조건 유지.
- `evolution_items.gd`, `tactical_journey.gd`: 재료 진화는 여전히 가방에서 1개 소비하며, 현재 시간과 개체 조건으로 분기를 자동 결정한다. 기존 `prepare_evolution`/`choose_evolution`은 안내 오류만 반환하고 무변경. 이전 저장의 준비 플래그가 다른 자동 진화를 막지 않는다.
- `camp_move_training.gd`: 현재 레벨까지의 자력 습득 기술만 정렬한 뒤 seed/step/UID 전용 RNG로 순서를 정한다. 배운 기술을 제외하고 동료별 최대3개 제안. UI 재개/로드로 재추첨하지 않는다. 기존 습득표와 모든 JSON은 불변.
- `tactical_journey.gd::training_offers/train_move_reason/train_move`: 일반 훈련은 제안 기술만,100골드+공유 야영 행동1회. 휴식/강화/조사와 상호 제한. phase·생존·소유자·슬롯·기술·자금 검증 후에만 원자적으로 변경. 지출은 기존 gold_events와 결정 기록에 포함하여 통계 저장 형식을 보존한다.
- 기술머신은 별도 호환성+보유 수량 검사 후1개 소비, 제안 목록/훈련비/야영 행동을 요구하지 않는다. 교배/가르침/TM 전용 기술을 무료 훈련으로 선택할 수 없다. 자연 레벨업 습득/교체 제안은 유지.
- `pokedex_workshop.gd`: 진화 안내는 읽기 전용, 훈련은 backend 제안·사유와 동일. 긴 상세는2줄 말줄임/툴팁으로 겹침 방지. `tactical_journey_ui.gd` 특수 진화 패널도 안내만 표시한다. PLAY_GUIDE 동기화.
