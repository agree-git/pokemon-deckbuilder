# 자동 진화·기술 가르침·야영 경제

표시 명칭은 기술 가르침이며 습득 기술을 먼저 표시합니다. 현재 검색 입력은 [검색 교체 지도](workshop-search.md)가 우선합니다. 가격·법적 경로·경제 계약은 유지합니다.

최신 사용자 지시가 우선한다. 야영지 진화 분기 선택은 제거 상태를 유지한다. 훈련은 전체 자력기100/그 외 호환기200골드,공유 야영 행동/횟수 제한 없음. 획득·일반 지출은 **지역이 아니라 야영지 출발마다 이전 금액 대비×1.1**(100→110→121→133.1%)다. 훈련비/TM 가격·소모는 고정. 새 빌드 요청이 아니다.

## 파일 지도

- `scripts/tactics/camp_move_training.gd`: `offers`는 `NationalEvolution.teachable_moves` 전체(알려진 기술 포함),`level_moves`는 현재 레벨까지 자력기. 자력기는100/그 외 법적 습득 기술200. 미래 자력기라도 현재 별도 TM/교배/가르침 경로가 없으면 불가. RNG·재추첨 없음.
- `tactical_journey.gd::training_offers/train_move_price/train_move_reason/train_move`: REST/파티·생존/법적 경로/슬롯/중복/골드 검증 후에만 변경. 야영 행동(rested_steps)에 접근하지 않으며 돈만 지출. 다른 동료 카드 불변,교체 기술의 기존 소유 사본 동시 변경. TM은 호환성·보유1개 소비,훈련비/야영 행동 없음. 통계는 기존 gold_events/결정 기록.
- `gold_progression_percent/scale_gold/battle_gold_reward`: 선형 route의 현재 step 앞에 있는 rest 개수=출발 횟수. `100*1.1^출발횟수`%,일반 금액은 부동소수점 미세 오차를 정리한 뒤 올림. 현재 야영지에 머물기/refresh/load/중복 출발 실패는 증가시키지 않는다. 새 저장 카운터·경로/RNG 변경 없음. 68회 출발 뒤 약65268.3435%.
- 전투 정산과 야영 이벤트 골드 보상,보급품·진화 재료 가격,상인 카드,카드 제거,전술 수업에 동일 배율. 초기 소지금·기존 획득/지출 기록은 소급 변경하지 않는다. 훈련100/200과 TM 판매100/소비1개는 제외. 기존 상인 기본 카드의 지역 가산은 화면 견적에서 제외하여 지역 경계에서 별도 인상이 없고,제거 의뢰 횟수 가산은 유지한다.
- `shop_cards`는 저장된 기본 진열을 deep copy해 배율 견적을 만든다. 구매는 표시한 금액을 쓰고 원본 sold만 변경. `items`도 deep copy라 정적 아이템 데이터는 불변. 저장의 원래 MerchantContent 가격 검증을 유지한다.
- `pokedex_workshop.gd`: 자력기/기타 습득·가격 표시,이미 알려진 기술은 비활성,전체 검색 가능. `tactical_journey_ui.gd`: 수업/부품 판매 선택지·안내·실제 금액 일치. PLAY_GUIDE 동기화.

## 자동 진화 유지

`national_evolution.gd`는 레벨·성별·낮밤·친밀도·필수 기술·아름다움 확인,외부 조작 준비 요구 없음. 님피아 우선/고정 개체 분기. `special_evolution.gd`의 배루키는 종·레벨 공격/방어 비교(현재 동률→카포에라),개무소 기존 분기·빈티나/껍질몬 조건 유지. `evolution_items.gd`는 재료1개 소비와 시간/개체 자동 분기. 준비/선택 저장 필드는 호환용이며 강제하지 않고 폐기 API는 안내 오류만 반환. 진화 UI는 읽기 전용,상시 폼 UI 유지.
