# 9세대 희귀 확장

일반 포켓몬은 기존 **1~3세대 386종 범위**를 유지하고, 희귀 대상만 **기본 종 100 + 가라르 프리져/썬더/파이어 3폼 = 103개 항목**으로 확장했다. 기존 희귀 21종 외 82개 항목을 추가했으므로 런타임 도감은 468개다. 전체 9세대 일반 도감 확장이 아니다.

사용자 답변에 따라 지역폼을 포함하고 울트라비스트와 일반 패러독스는 제외한다. 굽이치는물결·무쇠잎새·꿰뚫는화염·날뛰는우레·무쇠암석·무쇠감투는 **준전설**로 포함한다. 직접 지정한 코라이돈·미라이돈은 초전설이다. 합체폼·일반 전투 폼은 추가하지 않았다. 기본 형태를 사용하므로 자시안/자마젠타는 역전의 용사, 버드렉스는 기승 전, 우라오스는 일격, 지가르데는 50%다.

## 조우·포획

| 분류 | 대상 | 조사/배지 | 볼 | 에너지 | HP |
|---|---:|---:|---:|---:|---:|
| 준전설 | 53 | 3 | 3 | 2 | 10% 이하 |
| 환상 | 23 | 5 | 3 | 2 | 10% 이하 |
| 초전설 | 27 | 7 | 5 | 3 | 10% 이하 |

코스모그·코스모움도 초전설 계열로 묶어 7개 문턱을 적용한다. 미진화체의 이른 포획과 진화로 초전설 조건을 우회하지 않게 했다. 고유 등장 효과는 요청한 최종 25종에 적용하고 이 두 미진화체는 일반 희귀 도입을 사용한다.

일반 야생 포획은 25%를 유지한다. 희귀는 조사·예약·지도·다음 전투 준비·이동에서 이름과 그림을 `?`로 숨긴다. 이미 얻은 마지막 단서만 보여 주며, 단서에는 종명을 직접 쓰지 않는다. 예약은 `???`로 기록하고 예전 저장의 예약 이름은 표시할 때 가린다. 발견 전 도감의 희귀 실루엣·타입·번호도 숨기고 이름/번호 검색으로 정체를 추측할 수 없게 했다. 현재 원정에서 만난 대상이나 이미 포획한 종은 표시한다. 포획만 영구 도감에 남으며 미포획 조우 이력을 별도 영구 수집 요소로 추가하지 않았다.

원정당 1회 도전, 조사와 휴식/강화의 선택, 기존 야생 1전투 대체, 일반 경로·보상·경험치·관장 파티는 유지한다. 103종 각각 조사 장소·소문·단서(총 463개)·등장 문구를 갖는다. 장소는 기존 타입 배경과 사용자 보정 좌표를 재사용한다.

## 데이터·육성

추가 82개 항목 모두 앞/뒤 도트·울음소리·6종족값·성장 곡선·레벨업 기술을 갖는다. 기존 386종/기술 정의는 JSON 항목 단위로 보존했다. 추가 희귀에는 고정 PokéAPI 데이터의 가장 최신 레벨업 버전 그룹을 사용한다. 기술 카드 총 정의는 490개이며, 원작 특수 능력/모든 기술 예외까지 새로 구현한 것은 아니다. 개체값·노력치·성격 보정은 적용하지 않는다.

포획한 진화체는 기존처럼 가장 미진화한 지원 종을 스타팅으로 해금한다. 새 계열은 다음과 같다.

- 코스모그 → Lv.43 코스모움 → Lv.53 낮 솔가레오 / 밤 루나아라. 야영지의 원정 시간을 사용한다.
- 타입:널 → 기존 원정 친밀도 220 이상으로 레벨업 → 실버디.
- 치고마 → 야영지 악의족자 → 우라오스(일격).
- 멜탄 → 야영지 멜탄의사탕 → 멜메탈. 원작 GO의 외부 사탕 조건을 혼자 진행 가능한 재료로 바꾼 원정용 규칙이다.

새 재료는 해당 진화 계열의 상인 후보에 추가하며 관계없는 파티의 기존 재료 추첨 후보는 유지한다. 신규 #1001 이상 스타팅과 포획 개체 UID가 겹치지 않도록 할당 시 이미 사용 중인 UID를 건너뛴다. 가라르 새 런타임 ID는 10169~10171이며 실제 도감 번호 144~146을 별도 보존한다. 일반 #387부터 전부 허용하는 범위 검사는 사용하지 않는다.

| 칠색조 / 루기아 | 일곱 빛 무지개 / 솟는 거품 |

효과는 4픽셀 격자 도형으로 그린다. 포켓몬 자리의 발밑 좌표를 기준으로 정렬한다. 등장 예고 중에는 포켓몬·상대 HUD·실명을 숨기고 조작을 잠근다. 효과가 모인 뒤 포켓몬과 울음소리가 나오고, 이름/등장 문구가 표시된 다음 조작을 돌려준다. 기존 1/1.5/2배 연출 속도·즉시 마무리·같은 전투 화면의 재표시 방지 경로를 따른다. 전투/날씨 상태와 난수를 변경하지 않는다. 첫 행동 전의 저장을 다시 열면 도입은 다시 나올 수 있으며, 행동 후 저장은 도입을 반복하지 않는다.

## 저장 호환

새 조사 상태는 `pool_version:2`를 저장한다. 예전 네 필드 조사 상태는 v1의 21종 목록으로 같은 시드 추첨을 유지한다. 현재 원정이 새 목록으로 바뀌어 기존 목표를 잃지 않는다. 아직 조사를 시작하지 않아 상태 자체가 없는 원정은 첫 조사 때 새 목록을 사용한다.

콘텐츠 JSON 확장으로 fingerprint가 바뀌므로 바로 이전 `07b0c41`의 정확한 fingerprint `1f49586798419ec8b34b5e1698a3d7b470905520caed012674308eec391001c2`만 추가 호환한다. 임의의 다른 fingerprint 허용은 하지 않는다. 일반 스냅샷 구조/해시/종·기술 ID·경로 검증은 계속 적용하고 다음 저장은 새 fingerprint로 기록한다. 알려지지 않은 풀 버전/일반 후대 종/비지원 폼은 거부한다.
