# 원정 덱과 소유자 필터

원정의 **덱 조회·카드 강화 선택·상인 카드 제거 선택**은 같은 카드 그림 목록을 사용한다. 상단에서 **전체 / 공용 / 각 동료**를 선택해 원하는 소유자의 카드만 확인한다. 숫자는 묶음 수가 아니라 실제 카드 사본 수이며, 동료의 기절 여부와 관계없이 영구 덱에 있는 카드를 표시한다.

- 같은 소유자·강화·내용의 카드는 겹친 카드와 `×N`으로 묶는다. 기본 카드와 강화 카드는 따로 표시한다.
- 일반 덱 조회의 카드는 사용되지 않는다. 강화·제거에서는 묶음을 눌러 대표 사본 **한 장**을 선택한 뒤 기존 확인 화면으로 이동한다.
- [강화 비교](camp-upgrade-preview.md) 또는 [제거 확인](camp-removal-preview.md)을 취소하면 같은 소유자 필터의 목록으로 돌아간다. 덱 창을 닫고 다시 열면 전체 필터로 시작한다.
- 강화된 카드·부상 등 강화 불가능한 카드나 제거 제한에 걸린 카드는 흐리게 표시하고 툴팁으로 사유를 안내한다. 필터에서 제외하거나 실제 카드 수를 줄이지 않는다.
- 강화하면 선택한 한 UID만 강화되고 같은 묶음의 다른 사본은 기본 상태로 남는다. 다시 조회하면 기본/강화 카드로 나뉜다. 제거도 실제 선택한 한 UID만 처리한다.
- 카드가 없는 필터는 사본을 새로 만들지 않고 빈 목록 안내를 보여 준다. 필터·조회·취소는 골드·야영지 행동·난수·자동 저장을 바꾸지 않는다.

필터는 UI 상태이며 저장 형식에 추가하지 않는다. 실제 카드 사용은 손패의 개별 인스턴스 단위로 유지한다. 출발 덱 미리보기의 기존 필터와 별도로, 현재 원정의 실제 덱을 보여 주는 기능이다.

## 검증

Godot 4.7.2에서 실행한다.

```bash
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tests/test_deck_filters_ui.gd
godot --headless --path . --script res://tests/test_upgrade_preview_ui.gd
godot --headless --path . --script res://tests/test_removal_preview_ui.gd
# DISPLAY / XTest 환경의 실제 OS 입력
python3 tools/test_native_pointer.py --probe native_deck_filters_probe
```

실제 X11 검사 85개·포인터 입력 72회·Esc 3회로 세 창 비율의 필터 버튼·카드 얼굴 위/중간/아래 클릭, 실제 사본 수·소유자·강화 구분·빈 필터·조회 불변성·모달 차단·필터 보존·한 장 강화/제거·자동 저장을 확인했다. 1920×1080의 강화 필터와 빈 목록 화면을 검토했다. 장소·자금·덱은 명시적인 UI 경계 상태이며 해당 지점까지 수동 공략했다는 뜻은 아니다. Windows 실행 검증은 별도다.
