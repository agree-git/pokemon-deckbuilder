# 자기 능력 기술 · 원정 v22 / 플레이어 효과14

새 원정에서만 적용한다. 이전v1~v21의 정의/효과/진행 중 저장/미래 전투와 RNG는 유지한다. 기술919개 중 특징 보완430개(+4),나머지489개에는 정상 기본 공격도 포함한다. 임시 보호막5 변화 기술은29개 남았다.

| 기술 | 적용한 특징 |
|---|---|
| 경혈찌르기367 | 자신의 공격·방어·특공·특방·스피드 중 +6 미만인 능력 하나를 동일 확률로 골라 +2,최대+6. 미리보기는 후보만 표시하고 실제 사용 때 전투 RNG로 추첨한다. 모두 최고 단계면 교대/에너지/카드/RNG를 바꾸지 않고 거절한다. 원작의 명중/회피 능력은 기존 게임 체계에 없으므로 제외한다. |
| 승리의춤837 | 자신 공격·방어·스피드 각+1. 스칼렛/바이올렛 효과를 사용하며 레전드 아르세우스의 별도 피해/행동 순서 효과는 추가하지 않는다. |
| 농성842 | 자신 방어+2. 스칼렛/바이올렛 효과를 사용하며 회피 추첨은 추가하지 않는다. |
| 파워시프트829 | 자신의 공격↔방어 및 특공↔특방 전투 능력치를 교환한다. 능력 단계/HP/스피드는 유지하며 지닌 물건 보정은 교환 뒤 계산한다. 다시 쓰면 원래 값으로 돌아오고 교대/전투 종료 시 해제한다. |

4개 모두 임시 보호막을 제거했다. 기본 비용1,강화 비용0이며 강화가 능력 상승량을 추가로 늘리지는 않는다. 소유 카드 자동 교대,잠꼬대/복사의 기존 공격 기술만 호출 규칙,구애 고정/돌격조끼 등의 기존 제한을 보존한다. 승리의춤/농성의 단계는 기존 단계 실행 경로를,파워시프트는 기존 `exchange_context.stats` 저장/복원/교대 정리를 사용한다. 새로운 문맥 필드는 없다.

## 필요한 파일

- `scripts/tactics/player_move_training.gd`: 정의/호출된 기술 준비/후보·사용 거절/추첨·교환/짧은 카드 문구.
- `data/player_move_training_v22.json`: 새4개 오버레이. 기존 게시된 JSON/전용 엔진은 수정하지 않는다.
- `scripts/tactics/player_techniques.gd`: 새 효과14 분기. 기술효과/장비효과의 이전 순서는 유지한다.
- `campaign_route.gd`,`journey_save.gd`,`journey_snapshot.gd`: 원정22/새 지문/기존 선택 문맥의14 허용. 실제 이전v21 지문 `0f77fb493cb20ec6a587c6b4118ff2cb1bfa194c5690ce7eb1c59ebc0b8c9a8d` 수용.
- `tools/import_player_move_training.py --game-dir . --csv-dir /path/to/csv`: v10/v20 입력 SHA와 기존 고정 PokeAPI CSV4종을 확인하고 재생성한다. CSV에 빠진 레전드/최신 기술의 효과는 위 각색 표와 JSON의 기술별 참조를 따른다. 캐시는 커밋하지 않는다.

## 최소 검사

`tools/check.py --suite player-training` 한 스크립트로 변경4개·미리보기/RNG·최대 단계/자동 교대 거절·실제 강화/교환과 피해·물건 제한·잠꼬대·실제 저장과 다음 동일 입력/추첨·기존 실제v21 체크포인트/다음 입력·교대/전투 종료 복구를 검사한다. `/tmp/player-v21-before.bin`은 구현 전 실제 게임에서 저장한 선택 검사 입력이며 없으면 현재 지문/이전 정의 검사는 항상 실행한다. 전체919기술/전체69전/전체 회귀는 반복하지 않는다. 실제 창/native/X11·EXE/export/Windows CI는 계속 보류한다.
