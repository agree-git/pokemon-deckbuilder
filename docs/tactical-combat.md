# 통합 카드 전투

F5의 정식 원정은 기술·도구·트레이너 카드가 한 덱에서 나오는 전투를 사용한다. 고정 기술 버튼과 브레이크·빈틈·격파 환급을 제거했다. 설계 의도와 확장 후보는 [슬더스라이크 설계](deckbuilder-direction.md)를 참고한다.

## 기본 규칙과 조작

- 턴 시작 기본 에너지 3, 출전 아군이 상대보다 빠르면 +1. 카드 5장, 손패 최대 10장. 남은 에너지는 다음 턴에 이월하지 않는다.
- 기술 카드에는 소유 포켓몬의 초상·이름·타입을 표시한다. 대기 중인 포켓몬의 기술을 사용하면 즉시 교대하고 기술을 사용한다. 자동 교대에는 추가 비용이 없다.
- 1/2/3은 파티의 수동 교대이며 에너지 1을 쓴다. 강제 교대는 무료다. Q/W/E/R은 현재 손패의 왼쪽 네 장을 사용한다. 다섯 번째 이후는 마우스로 선택한다. R로 재시작하지 않는다.
- Enter는 턴 종료, C는 야생 포획, F1은 도움말, Esc는 메뉴 또는 창 닫기, F11은 전체 화면이다.
- 일반 카드는 사용 후 버린다. 소진 카드는 해당 전투에서 다시 뽑지 않고 다음 전투에 돌아온다. 지속 작전 카드도 사용 후 소진 더미로 가며 효과는 전투 내내 유지한다.
- 보존된 카드는 다음 턴까지 손패에 남는다. 뽑을 카드가 부족하면 버린 더미만 재섞는다. 더미 확인은 카드 구성만 보여주고 숨은 드로우 순서를 공개하지 않는다.
- 비용 부족·기절한 소유자·손패에 없는 카드 등 실패한 요청은 교대·자원·카드·난수 상태를 바꾸지 않는다.

[종족값·물리/특수 피해·스피드 에너지 규칙](pokemon-stats.md)을 적용한다. 보호막·회복·추가 피해는 아래 기준값을 최대 HP/48로 환산하며 전투 카드에는 실제 값을 표시한다.

보호막과 포켓몬 강화는 각 포켓몬에게 귀속된다. 마지막 출전 포켓몬이 상대의 예고 행동을 받는다. 보호막은 다음 플레이어 턴 시작에 초기화한다. 배틀 강화제의 공격 보너스는 해당 포켓몬이 교대하면 해제된다.

적 파티는 한 마리씩 등장한다. 적 교대에도 현재 턴·에너지·손패·지속 작전을 유지하며 추가 즉시 공격은 하지 않는다. 관장의 여섯 마리는 하나의 전투다. 수면 등 개별 기술 효과로 행동을 취소할 수 있지만 공통 브레이크는 없다.

적의 공통 역할과 기술 선택·행동 예고는 [적 전술](enemy-tactics.md)을 따른다. 관장·사천왕·챔피언은 [보스 전술](boss-tactics.md)의 방벽·회복·상태·연타 등을 인물별로 조합한다. 전투 중 교대해도 적이 숨겨진 기술로 바꾸지 않는다.

## 덱과 성장

초기 덱은 방어 지시 2장, 전술 정리·강화 지시·응급 회복약·전장 분석 각 1장과 소유 기술 카드로 구성된다. 1~3마리 선택에 따른 기술 카드 배분을 보정해 보통 15~18장으로 시작한다. 공격 기술을 아직 배우지 않은 종은 기술 카드 몸부림을 제공받으며 몸부림은 타입 무효로 막히지 않는다.

레벨업으로 빈 슬롯에 기술을 배우면 기술 카드 한 장을 추가한다. 네 기술이 찬 뒤 슬롯을 교체하면 그 포켓몬의 기존 기술 사본을 새 기술로 바꾸며 강화는 유지한다. 카드 제거는 기술 자체를 잊게 하지 않는다. 배운 기술을 무료로 덱에 다시 넣는 기능은 없다. 보상으로 배운 기술의 추가 사본을 얻을 수 있다.

기절하면 소유 카드가 현재 전투의 소진 더미로 이동하고 부상 한 장이 추가된다. 소유 카드가 원정 덱에서 영구 삭제되지는 않는다. 다음 전투에서 살아 있는 소유자의 카드가 다시 뽑힌다. 포획 합류는 배운 기술의 카드를 제공한다. 파티 교체 시 떠난 멤버의 기술·부상을 제거하고 지닌 물건은 장비 가방에 돌려준다.

순수 회복 기술 카드도 소진된다. 야영지 가방의 회복 아이템은 전투 중 사용할 수 없으므로 드로우 없이 반복 회복하지 못한다. 몬스터볼은 별도의 포획 자원으로 유지한다.

## 유물과 지닌 물건

원정은 탐험 구급함으로 시작한다. 유물은 전투 시작부터 파티 전체에 적용되며 중복 획득하지 않는다. 비교용 씬의 생성자는 다른 시작 유물을 받을 수 있지만 일반 메뉴에서 무료로 교체하지 않는다.

| 유물 | 효과 |
|---|---|
| 탐험 구급함 | 전투 시작 시 모든 아군 보호막 5 |
| 씨앗 전이 | 적 기절 시 남은 씨앗을 다음 적에게 전달 |
| 교대 배턴 | 기술로 교대한 멤버의 다음 공격 기본 피해 +3, 턴 종료 시 해제 |
| 릴레이 수첩 | 턴에 서로 다른 세 멤버가 기술을 쓰면 2장 드로우, 턴당 한 번 |
| 에이스의 깃발 | 교대 없이 턴을 마치면 다음 턴 출전 멤버 위력 보정 +10% |
| 보급 벨트 | 턴 첫 도구 사용 시 1장 드로우 |
| 릴레이 발전기 | 턴 첫 기술 자동 교대 시 에너지 +1 |
| 집중 문장 | 같은 멤버가 한 턴 두 번째 기술 사용 시 1장 드로우, 파티 전체 턴당 한 번 |
| 잔류 시약 | 턴 첫 화상·독·씨앗 부여 카드의 지속 횟수 +1 |
| 상태 관측경 | 턴 첫 새로운 상태이상 부여 시 에너지 +1 |

지닌 물건은 힘의 머리띠·수호 부적·교대 리본·집중 밴드·생명의 부적·치유의 방울 6종이다. 공격, 방어, 교대, 출전 유지, 상태이상, 도구 회복을 각각 지원한다. 야영지의 장비·유물 탭에서 포켓몬당 하나씩 장착하고 자유롭게 교환한다. 전투 중에는 교환하지 않는다.

## 보상과 야영지

전투 한 판이 끝나면 카드·유물·지닌 물건으로 구성된 선택지 세 개 중 하나를 얻거나 넘긴다. 경험치와 기본 돈·기존 전리품은 별도로 정산한다. 일반 전투는 카드 중심이며 엘리트 트레이너·관장·사천왕은 아직 얻지 않은 유물을 우선 제시한다. 매 화면에 세 종류를 하나씩 반드시 제시하지는 않는다. 마지막 챔피언은 엔딩으로 이어진다.

첫 공용 카드 후보는 현재 덱·유물의 조합을 지원하는 풀과 전체 풀을 각각 50% 확률로 사용한다. 이미 표시·저장된 보상은 재추첨하지 않는다.

각 야영지에서 휴식 또는 카드 한 장 강화를 선택한다. 휴식은 기존처럼 전원 최대 HP 50% 회복·부활·부상 제거를 제공한다. 강화는 카드 종류에 따라 피해·보호막·회복·드로우·비용 등을 개선한다. 한 장을 반복 강화하지 못한다. 가방·장비 정리·무작위 만남은 별도 이용 가능하다.

[상인 야영지](merchant.md)는 현재 조합 지원 공용 카드·다른 조합의 공용 카드·파티가 배운 기술 사본을 각 한 장 판매하고 한 장을 20골드 할인한다. 진열은 첫 도착에 확정되며 구매 시 매진된다. 일반 공용 카드는 60골드부터, 기술은 70골드부터 시작해 지역마다 5골드씩 오른다.

상인 야영지는 방문당 한 장을 영구 제거할 수 있다. 비용은 50골드부터 누적 제거당 25골드씩 증가한다. 최소 덱 5장과 동료의 마지막 기술 한 장은 보호한다. 방문 재진입이나 저장 복구로 휴식·강화·제거·보상을 재사용하거나 재추첨하지 못한다.

## 원정 기록

지도·야영지·결과 화면의 파티 아래 `원정 기록`에서 전투별 실제 HP 피해·기절, 카드/유물 사용과 카드·보상·골드 선택을 확인한다. 실제 행동에서 집계하고 정산 시 한 번 합산한다. 보호막 흡수·초과 회복·포획·이어하기의 기준은 [원정 기록](run-records.md)을 따른다.
