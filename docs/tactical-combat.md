# 전술 전투 시험판

F5 기본 실행은 새 전투 방식의 **아군 3마리 대 적 2마리** 시험판이다. 기존 9개 장소 원정은 F3로 오갈 수 있다. 두 모드는 진행 상태를 따로 유지한다. 새 규칙을 포획·성장·배지 원정에 연결하는 작업은 다음 단계다. 이번 시험판에는 관장·배지·리그 보상을 넣지 않았다.

## 조작과 첫 연계

- 1 / 2 / 3: 출전 포켓몬의 고정 기술. Q / W / E: 파티 교체.
- 손패 클릭: 트레이너 지시. 추가 손패는 가로 스크롤.
- Enter: 턴 종료. R: 같은 시드·선택 특성으로 재시작.
- 메뉴(`…` / Esc)의 특성 선택: 같은 시드로 전투를 새로 시작한다.
- 상단 ? / F1: 전투 도움말. … / Esc: 메뉴 열기·닫기. 기록 아이콘: 전투 기록.
- 뽑기·버림 아이콘 클릭: 더미의 카드 구성 확인. 소진된 카드는 메뉴에서 확인한다. 카드 확인은 드로우 순서를 공개하거나 변경하지 않는다.
- F2: 아트 랩에 갔다가 현재 전투로 복귀. F3: 기존 원정과 전술 시험 전환. F11: 전체 화면.
- 전투 기록에서 빈틈 증가·환급·행동 취소·기절 순서를 확인한다. 실행 중 네트워크 연결은 필요 없다.

시작 시 이상해씨로 **씨뿌리기 → 분석 → 턴 종료**를 사용한다. 다음 턴 **파이리로 무료 교체 → 불꽃세례**를 사용하면 상태·약점·분석 세 가지가 합쳐져 브레이크가 발생한다. 이어 **화염방사**로 2배 피해를 주면 첫 적을 쓰러뜨리고 에너지·손패를 환급받는다. 추가 교체 비용 1을 내고 꼬부기의 물대포로 바로 다음 적을 공격할 수 있다. 적의 씨앗·화상은 적 행동 이후 발동한다.

## 화면 구성

기본 화면에서 규칙 설명과 특성 선택 패널을 숨겼다. 포켓몬 기술은 아군 옆 왼쪽 세로 패널로, 트레이너 손패는 하단 카드 테이블로 분리했다. 중앙에는 포켓몬·체력·의도·빈틈을 표시한다. 이미 쓴 기술은 체크 아이콘으로 표시한다. 방어·화상·씨앗·분석·강화는 아이콘과 수치, 상세 툴팁으로 제공한다.

트레이너 카드는 186×266 프레임, 색상별 84×48 도트 일러스트(2배 확대), 둥근 비용 배지, 종이색 효과 칸으로 구성한다. 뽑힐 때 순서대로 등장하고 호버 시 들어 올리며 사용한 카드는 버린 더미로 날아간다. 전술 정리는 소진되므로 사용 후 사라진다. 턴 종료 시 남은 손패도 버린 더미로 이동한다. 사용하지 않은 카드는 같은 턴 동안 UI 인스턴스를 유지해 호버와 연출이 불필요하게 초기화되지 않는다.

일반 버튼은 밝기 반응, 교체는 짧은 페이드, 체력바는 모델 수치로 부드러운 보간, 에너지·턴·드로우 수·빈틈은 변화 강조를 사용한다. 메뉴·도움말·기록·결과창은 페이드와 짧은 이동으로 열린다. 닫는 동안에도 전투 입력을 막고, 즉시 다시 열면 이전 닫기 연출을 취소한다. UI 연출이 전투 수치나 난수 순서를 변경하지 않는다.

도움말·메뉴·기록·더미 확인창은 전투 클릭과 단축키를 차단한다. 바깥을 누르거나 닫기·Esc로 닫는다. 각 아이콘은 직접 작성한 16×16 SVG이며 최근접 필터를 사용한다. 화면·글자는 1920×1080 기준을 유지하고 포켓몬 초상은 투명 여백을 제외해 정수 배율로 표시한다.

## 기술과 덱

| 구분 | 시험판 규칙 |
|---|---|
| 파티 | 이상해씨 HP48, 파이리 HP45, 꼬부기 HP52. 이상해씨부터 출전 |
| 적 | 뚜벅쵸 HP40 → 가디 HP48. 모두 쓰러뜨려야 승리 |
| 고정 기술 | 출전 포켓몬마다 3개. 각각 포켓몬당 턴 1회, 에너지 소비. 교체로 사용 횟수를 초기화하지 않음 |
| 이상해씨 | 덩굴채찍 1 / 씨뿌리기 1 / 성장 0 |
| 파이리 | 불꽃세례 1 / 화염방사 2 / 웅크리기 1 |
| 꼬부기 | 물대포 1 / 껍질에숨기 1 / 몸통박치기 1 |
| 에너지 | 턴 시작 3. 기술·카드·추가 교체가 공유. 환급으로 3을 넘을 수 있음 |
| 교체 | 턴 첫 자발적 교체 무료, 이후 각각 1. 강제 교체는 무료이며 횟수도 소비하지 않음 |
| 트레이너 덱 | 분석×2, 방어 지시×3, 전술 정리×2, 강화 지시×2, 견제 지시×1 |
| 손패 | 턴 시작 5장, 최대 10장. 턴 종료 시 버리고 필요하면 버린 더미를 재섞음 |
| 전술 정리 | 비용 0, 드로우 2, 전투 동안 소진. 무한 순환 방지 |
| 분석 / 강화 지시 | 다음 공격에 적용. 같은 효과를 여러 번 걸어도 중첩하지 않음. 강화는 교체해도 유지 |
| 기절 | 부상 카드 1장 추가. 살아 있는 아군을 선택한 뒤 진행. 전원 기절 즉시 패배 |

첫 손패에는 분석 한 장이 포함되도록 보정한다. 나머지 손패와 재섞기는 시드로 재현한다. 상성은 기존 시험 수치(불→풀→물→불 1.5배, 역방향·같은 원소 0.75배, 노말 중립)를 사용한다. 고정 기술마다 원작 전체 규칙을 재현한 것은 아니다.

## 빈틈과 폭발 턴

- 적 한 마리마다 빈틈 0/3에서 시작한다. **약점 공격 / 상태 활용 / 분석 후 공격 / 강공격 견제**가 각각 1점을 준다. 같은 방법으로 한 적의 빈틈을 반복해서 채울 수 없다. 화상과 씨앗은 같은 ‘상태 활용’ 방법이다.
- 분석은 현재 적의 다음 공격에 빈틈을 예약한다. 견제 지시는 다음 행동이 강공격이면 즉시 빈틈 +1, 그 외에는 보호막 4다. 상태 전이도 새 적의 상태 활용 1점을 만든다.
- 3점이면 브레이크: **해당 적의 다음 행동 1회 취소 + 다음 공격 기술 피해 2배 + 에너지 1 환급**. 적마다 한 번만 발생한다. 브레이크를 만든 공격은 원래 피해를 주고, **그다음** 공격에 2배가 적용된다. 방어·성장 같은 기술은 2배를 소모하지 않는다.
- 브레이크한 적을 직접 공격으로 쓰러뜨리면 **에너지 1 + 드로우 1**을 추가 환급한다. 상태 피해로 기절하면 격파 환급은 없다.
- 브레이크와 격파 환급은 **합쳐서 턴당 2회**까지만 적용한다. 제한 뒤에도 브레이크의 행동 취소·2배는 정상 작동한다. 브레이크 특성의 드로우는 에너지 환급과 별개다.
- 적 교체는 즉시 일어나며 **현재 턴·손패·에너지·아군 HP·기술 사용 횟수**를 유지한다. 새 적은 출전 순간에 추가 공격하지 않으며, 현재 플레이어 턴을 종료하면 자신의 첫 행동을 한다. 상태 피해로 적이 교체되는 경우 새 적의 행동은 다음 적 턴부터다.
- 적의 빈틈·강화·화상·보호막은 다음 적에게 기본 이월하지 않는다. 씨앗 전이 특성만 남은 씨앗을 전달한다. 마지막 상태 피해로 쓰러졌다면 이미 사용한 횟수는 전달하지 않는다. 씨앗 회복은 살아 있는 원래 사용자에게만 적용하며 부활시키지 않는다.
- 마지막 아군이 적 공격에 기절하면 이후 적 상태 피해를 기다리지 않고 패배한다. 마지막 적까지 쓰러뜨리면 승리하고 상태를 정리한다.

## 시험 특성 세 가지

| 특성 | 전투 방식 변화 |
|---|---|
| 씨앗 전이 (기본) | 적 기절 시 남은 씨앗을 다음 적으로 전달. 빈틈 준비와 회복을 연속 적 전투에 연결 |
| 교체 연계 | 자발적 교체 후 그 포켓몬의 다음 공격 기본 피해 +3. 지원 기술에는 소모하지 않으며 다음 턴에 해제 |
| 절정의 집중 | 브레이크 시 1장 드로우, 다음 유료 트레이너 카드 비용 0. 부상 제외·중첩 없음. 원래 비용 0인 전술 정리는 무료권을 소비하지 않음 |

세 특성은 비교용 선택지이며 실제 성장 보상으로 획득하는 흐름은 아직 연결하지 않았다. 긴 전투의 성장·교체·회복 효율과 적 6마리 밸런스는 후속 조정 대상이다.

## 구현과 검증

`TacticalContent`는 정의, `TacticalBattle`은 UI와 독립된 상태·규칙, `TacticalUI`는 화면과 연출을 담당한다. 기존 `RunState` / `BattleState` 원정은 F3 비교용으로 유지한다. 새 전투 모델은 적 배열을 받아 순차 교체하며, 6마리 배열도 규칙 검사에 포함한다. 실제 관장 6마리 콘텐츠·원정 정산이 구현되었다는 뜻은 아니다.

```bash
godot --headless --path . --script res://tests/test_tactics.gd
godot --headless --path . --script res://tests/test_tactical_ui.gd
# DISPLAY와 지정 Godot 4.7.2 활성화 후 Linux X11 실제 OS 포인터 검사
LIBGL_ALWAYS_SOFTWARE=1 python3 tools/test_native_pointer.py --probe native_tactical_probe
# 실제 렌더러로 1920×1080 화면 캡처 (출력 경로 지정 가능)
godot --path . --rendering-method gl_compatibility --script res://tests/capture_tactics.gd -- /tmp/tactics-previews
```

`TrainerActionCard`는 안정된 손패 슬롯 안에서 카드 면만 움직이며, 원래 카드 자리와 떠오른 면의 입력 영역을 유지한다. `UiMotion`은 중복되는 연출을 취소하고 새 목표로 이어간다. 재시작은 진행 중인 카드 비행과 오래된 콜백을 정리한다.

규칙 검사는 잘못된 입력의 무변경, 기술별 턴 제한, 교체·카드 비용, 브레이크의 발생·소모·행동 취소, 공통 환급 상한, 적 교체 자원 유지, 상태 전이·만료·기절·승패, 카드 보존과 시드별 완결 전투를 다룬다. UI 검사는 4개 창 크기의 위·중앙·아래 입력 영역, 연출 중 입력 차단, 특성 선택, 전체 승리·패배와 결과 재시작을 다룬다. 별도의 XTest 검사에서는 OS 마우스로 3개 창 크기와 한 판을 검사한다.
