# 기술 교체 전후 비교

기술 습득 화면의 **교체 전후 비교**를 열고 잊을 기술을 선택하면, 현재 카드와 학습 후 카드를 나란히 확인한다. 빠르게 결정할 때는 습득 화면의 기존 기술 버튼 또는 Q/W/E/R로 바로 배우면 된다.

- 위쪽 네 기술 버튼 또는 **Q/W/E/R**로 비교 대상을 바꾼다. 비교 창 안의 단축키는 선택만 바꾸며 배우지 않는다.
- 왼쪽에는 실제 옛 기술 사본을, 오른쪽에는 변환 후 사본을 표시한다. 카드별 비용·효과·소유 포켓몬과 강화 상태를 보존해 비교하며, 같은 소유자·강화·내용의 사본은 겹친 테두리와 `×N`으로 묶는다. 기본 카드와 강화 카드는 따로 표시하며, 상단 장수는 실제 사본 수다.
- 옛 기술 카드가 0장이면 왼쪽에 사본 없음, 오른쪽에 새 기본 카드 한 장과 덱 장수 증가를 표시한다. 없는 강화나 사본을 만들어 보여 주지 않는다.
- **선택한 기술 대신 배우기**를 누르면 현재 비교 중인 기술만 실제로 교체한다. **목록으로**, 닫기, 바깥 클릭, **Esc**는 학습 대기로 돌아간다. 비교 창에서 Enter로 습득하지 않는다.

확정은 기존 [기술 습득 규칙](growth.md#레벨별-기술과-교체)을 사용한다. 이미 있는 사본은 고유 ID·소유자·강화를 유지하고, 사본이 없을 때만 새 ID의 기본 카드 한 장을 지급한다. 조회와 취소는 기술·덱·고유 ID·경험치·자원·난수·보상을 바꾸지 않는다. 비교 창을 열지 않고 직접 기술을 선택하는 흐름도 이용할 수 있다.

## 다음 상대에게 미치는 영향

아래에는 다음 전투의 실제 상대별 **현재 → 교체 후** 카드 수를 표시한다.

| 항목 | 의미 |
|---|---|
| 공격 | 직접 타격 상성이 0보다 큰 카드 사본 수 |
| 약점 | 그중 상성 배율이 1보다 큰 사본 수 |
| 지속·조건 | 화상·독·씨앗·혼란, 보호막 전환·상태 회수 등 지속 피해 또는 준비가 필요한 카드 수 |

증가는 초록, 감소는 붉은색으로 표시한다. 예를 들어 마지막 물 공격을 노말 공격으로 바꾸면 고스트 상대의 `공격 1 → 0`을 확인할 수 있다. 보조 기술을 물대포로 바꾸면 물에 약한 상대의 공격·약점 사본 수가 함께 늘 수 있다. 이것은 기술 추천 점수나 피해량·승률 예측이 아니다. 비용·위력·회복·방어·드로우의 가치는 실제 카드 얼굴과 함께 판단한다.

[다음 전투 준비](encounter-preparation.md)와 같은 실제 덱·복합 상성 규칙을 사용한다. 현재 파티의 살아 있는 동료만 집계하며, 학습 중인 동료가 기절했다면 회복 후 사용할 수 있다고 안내한다. 미래 야영지 회복·영입 교체·아직 결정하지 않은 다른 학습은 예측하지 않는다. 지금 선택한 한 건만 바꾼 덱을 비교한다.

전투 후 야영지를 지나 다음 실제 상대를 조회한다. 관장·리그는 그 전투의 전체 파티를, 예약한 희귀 조우가 있으면 대체된 종·레벨을 사용한다. 챔피언전 정산처럼 다음 전투가 없을 때에는 새 상대를 만들지 않고 카드 비교만 제공한다.

## 저장과 검증

열린 비교 창과 선택 기술은 UI 상태다. 재실행하면 원래 저장된 미확정 기술 습득으로 돌아오며 조회만으로 저장을 바꾸지 않는다. 확정한 기술과 실제 카드만 함께 자동 저장한다. 다음 학습 후보가 대기 중이면 비교 창을 닫고 그 후보를 보여 준다.

Godot 4.7.2 기준:

```bash
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tests/test_learning_comparison.gd
godot --headless --path . --script res://tests/test_learning_comparison_ui.gd
python3 tools/test_learning_deck_process.py
# DISPLAY와 XTest가 있는 환경
python3 tools/test_native_pointer.py --probe native_learning_comparison_probe
```

규칙 검사는 0/1/3사본과 네 교체 슬롯의 가상 덱이 실제 습득 결과의 키·소유자·ID·강화·부상 연결과 일치하는지 확인한다. 원본과 가상 카드의 분리, 조회 순수성·마지막 유효 공격 상실·기절·희귀 대상·다음 전투 없음도 다룬다. UI 검사는 세 창 비율에서 클릭·Q/W/E/R 선택·Enter 차단·사본 묶음/강화 분리·취소/Esc·확정·자동 저장을 확인한다. 위치·경험치·자금·긴 카드 목록은 명시적인 테스트 경계 상태이며 수동 전체 공략과 구분한다. 별도 세 프로세스로 미확정 저장 → 재실행/비교/습득 → 다시 재실행/실제 카드 사용·승리·경험치 정산을 확인한다.
