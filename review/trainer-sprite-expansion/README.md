# 가라르·팔데아와 칼로스 트레이너 도트 확장

게임 commit: [`49c967a`](https://github.com/agree-git/pokemon-deckbuilder/tree/49c967aaf96ea25889dfabd7bf8135d1bfbf2b17). **이번 추가 34대진 / 원본 PNG 33장**. 전체는 **원작 75 + 팬 제작 48 = 123대진 / PNG 120장**이며 시트론 1대진은 제작자 확인까지 공용 도트를 사용한다.

[전체 대진 CSV](trainer_sprites.csv) · [화면·원본·출처 ZIP](trainer-sprite-expansion.zip) · [적용 출처·검증](../../docs/trainer-sprite-expansion.md)

39장은 실제 Godot 4.7.2/Linux 전투 창을 1920×1080으로 촬영한 등장 34장·투척 5장이다. Lv.30 파티/상대는 외형 비교용 테스트 데이터다. 실제 챔피언은 기존대로 전원 Lv.100이며 이번에는 성장/난도를 바꾸지 않았다.

콘텐츠 검사 **3,849개**, 실제 렌더링 검사 **380개/34대진/세 연출 속도** 통과. [콘텐츠 로그](content.log) · [렌더링 로그](native.log) · [120 PNG 검증](sprites.log) · [import](import.log). 기존 87개 PNG와 그 메타데이터, 게임 데이터 12개, 사용자 전장 좌표를 유지했다.

아래 원본은 수정하지 않았다. 제작자 표기와 허락 없는 이미지 편집 금지 안내는 [필수 크레딧](TRAINER_FAN_CREDITS.txt)에 있다. GitHub의 공개 Showdown 컬렉션에서 내려받아 파일명·작가를 고정 갤러리 목록에 대응했으며, 이미지 서버 바이트를 직접 비교하지는 못했다.
