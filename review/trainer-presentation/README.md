# 트레이너 도트·대사 검토

원작 도트 **73장 / 75대진 적용**, 후대 **49대진은 공용 도트 유지**. 고유 대사는 124대진/372문장이다. 실제 Godot 4.7.2/Linux 1920×1080 창에서 촬영했다. 마지막 출전/승리는 HP 1 검토 fixture이며 정상 원정 난도 자료가 아니다.

[전체 CSV](trainer_sprites.csv) · [휴대용 갤러리 ZIP](trainer-presentation.zip) · [6세대 이후 후보 링크](https://github.com/agree-git/pokemon-deckbuilder/blob/development-materials/docs/trainer-sprite-links.md) · [출처/구현](https://github.com/agree-git/pokemon-deckbuilder/blob/development-materials/docs/trainer-presentation.md)

후대 후보는 파일명/제작자 등재 확인과 실제 이미지 검토/적용을 구분한다. Showdown 이미지 서버는 이 환경에서 403으로 차단되어 다운로드하지 않았다. 시트론은 파일명/제작자도 추가 확인이 필요하다.
