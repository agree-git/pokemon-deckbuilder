# Pokemon Deckbuilder

포켓몬의 포획·육성과 카드 전투를 연결하는 2D 로그라이트 덱빌딩 게임.

## 개발 기준

- 목표 엔진: **Godot 4.7.2** — 사용자가 지정한 기준. 현재 실행 검증은 하지 않음.
- 언어: GDScript
- 첫 실행 대상: Windows PC
- 게임 기획: [docs/game-design.md](docs/game-design.md)
- Codex 작업 기준: [AGENTS.md](AGENTS.md)

## 현재 상태

기획과 개발 기준을 준비한 상태. 아직 Godot 프로젝트와 실행 가능한 게임은 생성하지 않음.

## 첫 구현 목표

포켓몬 두 마리로 교체하며 기술을 사용하는 전투 한 판을 구현한다.

1. 카드 뽑기, 에너지 소비, 카드 사용과 턴 종료.
2. 적의 다음 행동 표시와 체력·방어 처리.
3. 공유 덱, 무료 교체 1회와 추가 교체 비용.
4. 승리·패배와 재시작.

지도, 포획, 진화, 상점은 교체 전투가 검증된 다음 구현한다.

## 데이터와 구조

화면 표시와 전투 규칙을 분리한다. 카드·포켓몬 정의와 원정 중 상태를 분리하고, 게임 콘텐츠를 코드에 반복해서 하드코딩하지 않는다. 상세 폴더 구조는 첫 Godot 프로젝트 생성 때 정한다.

## 저장소 관리

소스, 씬, 기획 문서, 필요한 원본 에셋을 추적한다. Godot 캐시와 빌드 결과는 커밋하지 않는다. 실행과 테스트가 가능한 환경에서 Godot 버전을 확인하고 결과를 기록한다.
